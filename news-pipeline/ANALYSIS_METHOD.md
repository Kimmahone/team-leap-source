# 뉴스 시각화·유사도 분석 방법

작성: 2026-09-10 · 대상: 대시보드 `학령인구 뉴스 분석 > 이슈 분석`

## 1. 회의 요구와 화면 대응

| 회의 요구 | 화면과 계산 |
|---|---|
| 뉴스 경향 | 최근 12주 전체 기사량 막대와 상위 3개 주제 추이선 |
| 키워드·워드클라우드 | 최근 30일 키워드 빈도에 따라 글자 크기 조절 |
| 다빈도 키워드 | 최근 30일 건수와 직전 30일 대비 증감 막대 |
| 글 벡터화·유사도 카테고리 | 제목과 BIG Kinds 특성추출 키워드의 TF-IDF 벡터, 코사인 유사도 0.28 이상 기사 묶음 |
| 지자체별 뉴스와 인구 변화 | 시군 뉴스 언급 증감과 EDSS 2016~2025 초·중·고 학생 수 변화율을 같은 행에서 나란히 비교 |
| 주간 이슈페이퍼 | 기사형 제목·리드·핵심 수치·차트·해설·근거 기사로 구성하고 최대 52호 누적 |
| 뉴스 기반 인구예측 | 현재는 제공하지 않음. 검증된 EDSS 코호트 전망과 뉴스 신호를 구분 표시 |

## 2. 분석 자료를 한 번 더 거르는 이유

빅카인즈 검색 결과에는 대학 입시, 일반 예산, 전국 사례처럼 학령인구 대시보드의 분석 대상과 거리가 있는 기사가 섞일 수 있습니다. 따라서 다음을 모두 만족한 기사만 `분석 적합 기사`로 사용합니다.

1. 경북 또는 경북 시군이 확인됨
2. 제목에서 학령인구, 학생 수, 소규모학교, 통폐합, 폐교, 교원, 통학, 돌봄, 교육재정 등 직접 신호가 확인됨
3. 제목에서 6대 주제 중 하나 이상이 확인됨
4. 대학 입시 중심 기사는 학령인구·초중등 직접 신호가 없으면 제외

원본 검색 결과와 6대 주제 1차 분류 건수는 manifest에 남겨, 정제 과정에서 얼마나 제외됐는지 추적합니다.

## 3. 벡터화와 유사도

기사 본문을 공개하거나 외부 AI 서비스로 보내지 않습니다. 기사 제목과 BIG Kinds가 제공한 특성추출 키워드를 토큰화하고, 자주 나오는 일반어를 제거한 뒤 TF-IDF 희소 벡터를 만듭니다.

두 기사 벡터의 코사인 유사도가 `0.28` 이상이면 같은 반복·유사 보도 묶음 후보로 분류합니다. 화면에는 다음을 표시합니다.

- 묶음 이름: 해당 묶음의 우세 주제와 중심 키워드
- 기사 수
- 묶음 내부 평균 유사도(0~100)
- 대표 기사 최대 2건

이 방식은 같은 사건을 다룬 반복 보도를 찾는 데 적합하지만, 문맥 전체를 이해하는 언어모델 임베딩과 같지는 않습니다. 향후 문장 임베딩을 도입하려면 내부망 또는 승인된 서버에서 수행하고, 기존 TF-IDF 결과와 사람이 표본 검증한 정확도를 비교한 뒤 교체합니다.

## 4. 학생 수와 함께 읽는 방법

기존 산점도는 서로 단위가 다른 값과 축을 한 번에 해석해야 해 의미가 어렵다는 사용자 피드백이 있었습니다. 현재 화면은 시군마다 다음 두 값을 별도 열에 나란히 표시합니다.

- 최근 30일 뉴스 언급 건수와 직전 30일 대비 증감
- EDSS 초·중·고 학생 수의 2016→2025 변화율
- `관심↑ · 학생↓`처럼 두 신호의 방향을 요약한 보조 표지

이 비교표는 정책 관심과 학생 변화가 함께 나타나는 지역을 찾기 위한 탐색 도구입니다. 상관관계, 인과관계 또는 인구예측 결과로 표현하지 않습니다.

## 5. 주간 이슈페이퍼 생성 기준

자동 주간호는 매일 축적한 네이버 뉴스 가운데 최근 7일의 경북·22개 시군 명시 기사만 사용합니다. 검색요약문에 질의어가 스친 것까지 주제로 세지 않도록, 주제 비중과 키워드는 기사 제목에서 직접 확인되는 단어를 기준으로 계산합니다.

BIG Kinds 원본을 다시 내려받아 `npm run build`를 실행하면 정밀 분석호가 갱신됩니다. 이때 이미 발행된 주간호는 지우지 않고 최대 52호까지 유지합니다. 두 자료는 출처와 분석기간을 각 호 머리말에 표시합니다.

## 6. 뉴스 기반 예측을 바로 만들지 않는 이유

기사량은 언론사 편집, 동일 보도자료의 반복 기사, 큰 사건 한 건의 집중 보도에 크게 흔들립니다. 뉴스량을 바로 학생 수 전망식에 넣으면 그럴듯하지만 검증되지 않은 숫자가 됩니다.

뉴스 신호를 전망에 활용하려면 최소한 다음 절차가 선행돼야 합니다.

1. 시군×월 단위 뉴스 특징량 구성
2. 같은 기간의 출생아·전입전출·EDSS 학생 수와 시차 결합
3. 과거 구간 학습과 이후 구간 검증 분리
4. EDSS 단독 모형보다 오차가 실제로 줄었는지 백테스트
5. 특정 언론사·보도자료 반복 효과 제거

검증 전에는 학생 수 전망은 기존 EDSS 코호트 모형을 사용하고, 뉴스는 설명·관심 신호로만 표시합니다.
