# 3D 지형 보정 및 지역 여건 제거

작성: 2026-09-13

## 요청 범위

- 7~8단계 지역 여건 UI, 도로 접근성 API, SGIS 학령인구 API 및 관련 카탈로그 항목 제거.
- ORS_API_KEY 설정은 더 이상 필요하지 않음. 운영 서비스의 비밀값은 변경하지 않음.
- 기존 학교 비교·직선거리 측정·학교 자료는 유지. 제거 파일은 Git 이력에서 복원 가능.
- 9~10단계 및 교육청 요청자료 문서는 참고자료로 보존하고, 취소된 7~8단계는 문서 상단에 명시.

## 지형 처리

이전에는 근접 확대 시 전체 고도 과장값을 낮추고 지형을 끄는 방식이어서 산까지 평평해졌다. 이번에는 과장값 1.5를 유지하고 고도 데이터의 작은 요철을 보정한다.

1. 기존 AWS Terrarium 타일을 미터 단위 고도로 디코딩한다. RGB 이미지를 직접 흐리게 하지 않는다.
2. 확대 단계 12~14의 고도 타일에서 인접 타일을 함께 읽어 경계에 충분한 여유 영역을 확보한다.
3. 약 90m 반경의 두 차례 평균과 지역 고도 표준편차로 보정 강도를 결정한다. 완만한 곳의 작은 요철은 강하게 완화하고 고도 변화가 큰 산 능선은 원자료를 유지한다.
4. Terrarium PNG로 다시 인코딩하여 기존 지도에 공급한다. 계산은 Web Worker에서 처리하고 원자료 캐시는 48개로 제한한다.
5. 요청 취소 및 15초 원자료 요청 제한을 적용한다. 새 API 키나 외부 라이브러리는 추가하지 않는다.

이는 시각화용 보정이다. 도로·운동장·논밭 경계를 분류한 측량 보정은 아니며 원자료 해상도, 영상 촬영 시점과 투영으로 인한 왜곡을 완전히 제거하지는 못한다. 완만한 실제 소규모 지형도 일부 매끄럽게 표현될 수 있다. 학교 수치와 원본 고도 파일은 수정하지 않는다.

## 검증 결과

- 합성 고도 테스트 4개 통과: 평면/경사면의 절대 고도, 평지 요철 감소, 고기복 산 정상 보존, 인접 타일 경계 일치.
- 기존 대시보드 테스트 731개 통과.
- 데이터 카탈로그 검사 통과: 데이터셋 11개, 서비스 6개 및 D1 스키마.
- 실제 Chrome/WebGL에서 VWorld 배경과 AWS 고도 타일을 이용해 같은 위치·확대·각도로 원본과 보정 화면을 비교했다.
- 광역 확인: 포항, 김천, 경주 산지. 근접 확인(확대 16.4): 포항양덕초, 황남초, 율곡초.
- 여섯 위치의 원본/보정 화면에서 타일 로딩 완료와 JavaScript 페이지 오류 없음을 확인했다. 평지 잔물결이 줄어들고 경주 산지 능선이 유지됨을 시각적으로 확인했다.
- 마지막 회귀 검사에서 비교 지도 표시 및 빠른 2D→3D 전환을 확인했다. 스타일 갱신 중 지형 적용이 생략되는 경우를 수정했으며, 다시 3D를 선택하면 과장값 1.5가 복원되고 페이지 오류가 없음을 확인했다.
