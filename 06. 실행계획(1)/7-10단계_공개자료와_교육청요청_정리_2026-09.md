## 2. 7단계 — 도로망 기준 통학 접근성

### 구현한 것

- 선택 학교 기준 자동차·도보 15·30·60분 도달권
- 지도에 목적지를 찍어 도로거리·예상시간·직선거리 비교
- 브라우저는 같은 출처의 `/api/route-access`만 호출
- `ORS_API_KEY`는 Cloudflare Pages Function에서만 사용하고 HTML·JavaScript·응답에 노출하지 않음
- API 장애·키 미등록·할당량 초과를 0분으로 표시하지 않고 오류 상태로 구분

구현 파일:

- `functions/api/route-access.js`
- `prototype/assets/map-context.js`
- `prototype/assets/map-context.css`

### 이 수치가 뜻하는 것

OpenRouteService의 **도로망 기반 예상치**다. 실제 학생의 주소, 등·하교 시간대 교통, 통학차량 노선·정류장, 좌석, 기상·계절 제약은 반영하지 않는다. 따라서 `실제 통학시간`이 아니라 `예상 이동시간`으로 표시한다.

### 사용자·인수자가 할 일

1. OpenRouteService에서 자신 명의의 키를 발급한다.
2. Cloudflare의 `team-leap`과 `team-leap-source` 프로젝트에 `ORS_API_KEY`를 **비밀값**으로 등록한다.
3. 미리보기와 운영을 모두 쓰면 Preview·Production 환경을 모두 설정한다.
4. 경북 표본 학교 10곳에서 서비스 결과와 일반 길찾기 결과의 큰 오류가 없는지 확인한다.
5. 발급자·월 호출량·장애 대응 담당자를 인수인계표에 기록한다.

## 3. 8단계 — SGIS 연령별 인구

### 구현한 것

- SGIS 인증과 연령별 인구 호출을 Pages Function으로 처리
- 2015~2022년, 현재 경북 22개 시군 단위 단계구분도(군위 제외, 포항 남·북구 합산)
- 0~4세, 5~9세, 10~14세, 15~19세, 5~19세 합계
- 낮은 값과 자료 없음을 다른 색과 문구로 표시
- 기존 `SGIS_CONSUMER_KEY`·`SGIS_CONSUMER_SECRET`을 서버에서만 사용

구현 파일:

- `functions/api/sgis-school-age.js`
- `prototype/assets/map-context.js`

### 중요한 제한

SGIS 인구 API의 연령 구간은 5세 단위다. 이번 구현은 6~11세, 12~14세, 15~17세를 정확히 나누지 않는다. `5~19세 합계`는 **학령기 근사치**이며 실제 재학생 수나 입학 예측값이 아니다. 화면에도 그 제한을 고정 표시한다.

연도 당시 경북이었던 군위는 2023년 대구 편입 뒤의 현재 지도와 범위를 맞추기 위해 제외한다. 포항 남구·북구가 별도 행으로 오면 포항 한 곳으로 합산한다. 따라서 화면 합계는 `해당 연도의 옛 경북 행정구역 전체`가 아니라 `현재 경북 22개 시군 비교 범위`다.

### 운영 확인

- 현재 키에 SGIS 인구 API 권한이 있는지 확인
- 임의 연도 2개와 시군 5곳을 SGIS 원응답과 대조
- 3개 5세 구간의 합이 5~19세 값과 일치하는지 검사
- API가 지원하는 최신 연도가 늘어나면 허용 연도·테스트를 갱신

## 4. 9단계 — 학구·교육권역·교통

### 지금 바로 구할 수 있는 공개자료

| 자료 | 출처 | 우선 활용 | 해석 제한 |
|---|---|---|---|
| 초등학교 통학구역 | 공공데이터포털 `전국초등학교통학구역표준데이터` | 학교·통학구역 연결, 기준일 표시 | 초등 중심. 필드에 실제 공간 경계가 있는지 표본 확인 필요 |
| 버스 정류소 | 공공데이터포털 국토교통부 TAGO 정류소 API | 학교 주변 일반 대중교통 접근 | 통학버스 정류장이 아님 |
| 버스 노선 | 공공데이터포털 국토교통부 TAGO 노선 API | 학교 주변 일반 버스 노선 | 실시간·결행·학생 탑승을 보장하지 않음 |

다음 구현은 `공개 통학구역` 시범 시군을 먼저 정하고, 학교코드·통학구역 ID·기준일이 안정적으로 연결되는지 확인한 뒤 경북 전체로 넓힌다. 경계 정보가 없다면 주소 목록으로 임의의 다각형을 만들어 `학구`라고 표시하지 않는다.

### 교육청에 요청할 것 — 실제 통학버스가 필요할 때만

| 필드 | 설명 |
|---|---|
| 기준연도·운행일 | 학기중/방학, 요일, 운행횟수 |
| 학교코드·노선 ID | 학교명 대신 학교알리미 기관코드로 연결 |
| 정류장 | 정류장 ID·위경도·순서, 학생 주소 제외 |
| 운행 | 수단, 예정 출발·도착, 편도 거리·시간 |
| 수요 | 노선별 탑승 학생 수·좌석 수. 개인별 기록 금지 |
| 비용 | 연간 운영비, 단 소수인원은 마스킹 |

## 5. 10단계 — 안전·생활시설 복합 시범

### 교육청 요청 없이 시작할 공개자료

| 레이어 | 공개 출처 | 표시할 것 | 표시하지 않을 것 |
|---|---|---|---|
| 산사태 | 산림청 산사태위험지도 | 자료 기준일과 위험등급 | 실시간 재난, 학교 폐쇄 여부 |
| 도서관 | 전국도서관표준데이터 | 위치·유형·운영시간 등 공개 필드 | 자료에 없는 좌석·프로그램 여력 |
| 청소년시설 | 전국청소년수련시설표준데이터 | 위치·시설유형·기준일 | 실제 돌봄·교육 수용 여력 |
| 일반 대중교통 | TAGO 정류소·노선 | 주변 정류소·노선 유무 | 통학차량 운영 여부 |

첫 시범은 **산사태 + 도서관 + 청소년시설** 3개를 권장한다. 레이어별 투명도·표시 순서·출처·기준일을 따로 관리하고, 서로 단위가 다른 값을 합성 점수 하나로 만들지 않는다.

교육청 자료는 다음 기능을 실제로 만들 때만 요청한다.

- 교육청 지정 임시 대피소·대피학교·주요 대체 동선
- 겨울철 통행 제한·휴업·통학차량 단축 구간의 집계
- 학교 안전점검 우선순위·조치 상태의 공개 가능한 항목

## 6. 사용자 메모 3가지 확인

### 6.1 다문화 학생 시군별

교육통계연보·경북교육청 교육통계 공개 파일을 **먼저 확인할 가치가 있다.** 다만 현재 대시보드에 연결한 값은 도 단위이고, 공개 파일에 모든 연도의 시군×학교급×유형이 있다고 확정하면 안 된다. 다음 순서를 따른다.

1. 당해 교육통계 원파일에서 `시군`, `시군구`, `행정구역`, `학교 소재지` 필드가 있는지 확인
2. 시군×학교급×다문화 유형 표가 있으면 공개자료로 가공
3. 시도 합계만 있거나 연도별 구조가 달라 연결하지 못하면 교육청에 부족 항목만 요청

### 6.2 다문화 학생 여러 해

교육통계 공개 시계열로 **경북 도 단위 추세**는 우선 보완할 수 있다. 하지만 `어느 시군이 늘었나`를 말하려면 동일 기준의 시군 시계열이 필요하다. 공개 원파일에 없으면 2016년~최신년 시군 자료를 교육청에 요청한다.

### 6.3 한국어 지원 프로그램 운영 학교

경북교육청 다문화교육 기본계획·한국어학급 운영계획 첨부파일에서 **현재 지정·운영교 이름**을 먼저 확인한다. 하지만 `필요한 곳과 있는 곳이 맞는지`를 수치로 비교하려면 다음이 추가로 필요하다.

- 연도별 학교코드·사업유형·지정시작/종료일
- 운영 학급·강사·수업시수·수용가능 인원
- 참여 학생 수(소수 마스킹, 개인정보 없음)
- 프로그램 미운영교의 지원 수요를 판단할 수 있는 공식 지표

공개 첨부파일은 `어디에 있는가`를 시작하는 데 충분할 수 있지만, 역량·참여·미충족 수요까지 보장하지는 않는다.

## 7. 교육청 최소 요청 목록

### 우선순위 1 — 현재 화면의 핵심 공백

### 우선순위 2 — 정책 비교의 정확도 향상

3. **특수교육 시군 시계열**
   - 배치유형, 학교급, 완전통합, 특수교육지원센터, 특수교사 정원·현원, 통학·치료지원 인원

   - 노선·정류장·시간·좌석·탑승인원·비용, 개인별 기록 제외

### 우선순위 3 — 공개자료 검증 후에만

6. 공개 자료에서 누락된 학구·공동학구 변경이력
7. 교육청 지정 대피소·겨울철 통행제한·학교 안전점검 집계
8. 프로그램 수요·공급 비교에 쓸 수 있는 공식 KPI

## 8. 요청 파일 표준 스키마

모든 표는 **1행 = 1레코드**로 받는다. CSV 또는 XLSX를 사용하고 셀 병합·색상만으로 구분·소계행을 제거한다.

```text
reference_date,school_year,region_code,region_name,school_code,school_level,
category,sub_category,value,unit,masked,source_department,source_document,
created_at,updated_at,note
```

- `school_code`: 학교알리미 기관코드
- `region_code`: 행정표준코드나 교육청이 계속 유지하는 공식 코드
- `masked`: 마스킹 여부. 마스킹 값을 0으로 대체하지 않음
- `value`: `0`은 실제 없음, 빈칸은 미집계·미확인
- 기준일·출처문서·생성/갱신일을 반드시 분리
- 시군×학년 등 소수집단은 교육청의 공개 기준 `N`명 이하를 빈칸 또는 별도 부호로 마스킹
- 학생 이름·생년월일·주소·개인별 통학경로는 요청하지 않음

## 10. 인수인계와 다음 순서

1. 인수자가 VWorld·SGIS·OpenRouteService·공공데이터포털의 **자신 명의 키**를 발급한다.
2. 저장소에는 `.dev.vars.example`의 변수 이름만 유지하고 실제 키는 넣지 않는다.
3. Cloudflare Pages Preview·Production에 동일한 변수 이름으로 등록한다.
4. 7단계 키 등록 후 표본 10교, 8단계 표본 5개 시군×2개 연도를 검증한다.
5. 9단계는 공개 통학구역 시범 후 경북 전체로 확대한다.
6. 10단계는 위험·시설 레이어를 각각 표시하고, 불투명한 통합점수는 만들지 않는다.
7. 교육청에는 공개자료 잔여 공백인 **다문화 시군 시계열·한국어 지원 운영·특수교육 시군 집계·공식 전망·실제 통학버스**만 요청한다.
