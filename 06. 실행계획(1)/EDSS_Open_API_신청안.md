# EDSS Open API 신청안

기준일: 2026-08-27  
목적: 경북 초·중·고 학교별 2016~2026 학생·학급 시계열과 기관 기준정보 확보

## 먼저 신청할 4개

| 우선 | EDSS API명 | 필요한 이유 | 반드시 확인할 출력 필드 |
|---|---|---|---|
| 1 | 학교속성[교육통계][EDSS] | 다른 통계표를 학교별·연도별로 연결할 기준키 | 조사연도, 학교/기관코드, 학교명, 시도·시군구, 학교급, 설립유형, 본교/분교, 운영상태 |
| 2 | 유초중등학교개황[교육통계][EDSS] | 연도별 학교 수·전체 학생·학급 개황 교차검증 | 조사연도, 학교/기관코드, 학교급, 학교수, 학생수, 학급수. 시도 합계만이 아닌 학교단위 자료인지 확인 |
| 3 | 유초중등학급현황[교육통계][EDSS] | 학교·학년별 학급 수와 학급당 학생 수 계산 | 조사연도, 학교/기관코드, 학교급, 학년, 일반학급수, 특수학급수, 합계 |
| 4 | 유초중등학생현황[교육통계][EDSS] | 학교·학년별 학생수 시계열의 핵심 | 조사연도, 학교/기관코드, 학교급, 학년, 남학생수, 여학생수, 합계, 특수교육대상 구분 여부 |

## 필요할 때만 추가할 API

| API명 | 신청 조건 |
|---|---|
| 유초중등시설현황[교육통계][EDSS] | 교실 수·수용가능인원·시설면적과 학생 수를 함께 보여 과밀·수용여건을 분석할 때. `교사(校舍)현황` 중복 필드를 먼저 비교 |
| 교사(校舍)현황(EDSS) | `교사`는 교원이 아니라 학교 건물이다. 위 시설현황에 없는 연면적·용도별 면적이 필요할 때만 신청 |
| 교원현황·직위/자격/표시과목별 교원 API | API 목록에서 별도 검색. 교원 수 시계열과 결원·순회교사 분석을 할 때 |
| 전입·전출·학업중단 관련 API | 시군 인구이동이 아닌 학교·학년별 이동을 예측 모형에 반영할 때 |

## 지금은 신청하지 않아도 되는 API

- 교복구매현황(EDSS): 학령인구·학교배치 분석과 직접 관련이 없음
- 교육운영특색사업계획(EDSS): 정책사업 원문이 필요할 때 다시 검토. 현재 핵심 시계열에는 불필요
- 유치원 공시 대체용: EDSS를 유치원알리미 대체제로 가정하지 않고 유치원알리미 API와 교육청 운영상태 명부를 사용

## 신청 범위

- 지역: 경상북도
- 기간: 2016~2026(가능한 최초 연도부터 최신 조사연도까지)
- 단위: 학교단위·학년단위 연간 집계
- 개인자료: 불필요
- 필수 연결키: 조사연도+학교/기관코드
- 출력형식: JSON. 코드북·필드 정의서도 함께 확보

## 복사용 신청 목적

> 경상북도 초·중·고 학교의 2016~2026 학교별·학년별 학생수·학급수와 학교속성·학교개황을 조사연도와 기관코드로 연결하여 학령인구 감소 추이와 학교규모 변화를 분석하고, 대시보드의 임시 예측모형을 검증하고자 합니다. 개인단위 자료는 필요하지 않으며 학교단위·학년단위 집계자료만 요청합니다.

## 도움말에서 거부해야 할 경우

아래 중 하나라도 학교단위 연결이 불가능하면 해당 API는 현재 목적에 부족합니다.

- 학교/기관코드가 없고 시도 합계만 제공
- 조사연도가 없어 여러 해 자료를 연결할 수 없음
- 학년 코드가 없어 출생 코호트 검증이 불가능
- 통폐합·교명변경 코드 이력이 없는데 단일 학교 시계열로 간주해야 함
