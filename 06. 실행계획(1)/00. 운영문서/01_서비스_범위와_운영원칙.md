# 서비스 범위와 운영 원칙

## 한 문장 목표

경북 학령인구의 현재와 장래 인구 흐름을 공개 데이터로 이해하기 쉽게 보여 주고, 시군·학교급별 모의 비교를 빠르게 제공한다.

## 핵심 기능

1. 실제 위치 지도와 간편 지도에서 학교·학생·학급 분포를 군집으로 탐색
2. KOSIS 학령인구 실적·장래인구와 학교알리미 재학생 실적 비교
3. 시군·학교급별 학생수·학급수·학교수 모의 비교
4. 현재 조건의 표·Excel·인쇄 결과 제공
5. 집계값을 쉬운 말로 정리하는 변화 읽기 도우미

## 공개 시뮬레이터의 범위

- 공간 단위: 경북 전체 또는 시군 한 곳·여러 곳
- 학교 단위: 초등학교·중학교·고등학교 학교급 집계
- 기준자료: 공개된 학교알리미 실적
- 모의자료: 공개 실적에 화면에서 선택한 계산 가정을 적용한 참고값
- 제공하지 않는 것: 학교별 미래 학생수, 개인별 자료, 확정적인 개폐교·통폐합 판단

모의값은 ‘예측 결과’가 아니라 조건을 바꾸어 차이를 살펴보는 값입니다. 화면·출력물에는 공식 장래 학생수 추계가 아니라는 설명을 항상 함께 표시합니다.

## 현재 범위에서 제외

- 부서별 정책·사업 실적과 홍보자료
- 내부 검토 대상학교 명부
- 학생 개인·거주지·통학경로 자료
- 내부 전입·전출과 시설자료
- 학교별 미래 학생수 확정값

공개 API로 핵심 기능을 구현할 수 없는 구체적인 문제가 확인될 때만 최소 필드와 용도를 적어 별도 자료를 요청합니다.

## 화면 문구 원칙

- `예측`보다 `모의전망`, `모의비교`, `참고값`을 우선 사용
- `정책 검토`보다 `변화 읽기`, `비교 질문`, `해석 주의사항`을 사용
- 실적·장래인구·모의값을 색과 설명으로 구분
- 자료가 없으면 추정해 채우지 않고 `자료 미확보` 표시
- 모든 주요 수치에 출처·기준연도·마지막 갱신일 제공
