# 디자인팀 안내 — 색과 치수를 어디서 고치나

작성: 2026-09-02

먼저 [공동작업 협업 규칙](./07_공동작업_협업규칙.md)을 읽고 오세요.
이 문서는 그중 **디자인팀이 실제로 손댈 자리**만 자세히 적은 것입니다.

---

## 0. 30초 요약

| 하려는 일 | 고칠 곳 |
|---|---|
| 브랜드 색·글꼴·모서리·그림자 | `prototype/index.html` 맨 위 `:root` **네 곳** |

**절대 하지 말 것**: 파일 전체 포매터(Prettier 등). 4,600줄이 통째로 충돌해
다른 팀 작업이 멈춥니다.

## 1. ⚠️ 색 하나가 다섯 군데에 있습니다

이 프로젝트의 색은 **CSS 변수(토큰)** 로 되어 있습니다. 토큰 하나를 고치면
그 색을 쓰는 모든 곳이 함께 바뀝니다 — 여기까지는 편합니다.

문제는 **같은 토큰이 여러 벌 적혀 있다**는 점입니다.

### 한 파일 안에 네 벌

`prototype/index.html` 의 12~120줄 사이:

```
① :root { ... }                              ← 라이트 기본
② @media (prefers-color-scheme: dark) { ... } ← 기기 설정이 어두울 때
③ :root[data-theme="light"] { ... }           ← 사용자가 «밝게»로 고정했을 때
④ :root[data-theme="dark"]  { ... }           ← 사용자가 «어둡게»로 고정했을 때
```

화면 오른쪽 위 「어두운 화면으로」 단추가 ③④를 켭니다.
**①만 고치면** 어두운 화면과 고정 모드에서 옛 색이 그대로 남습니다.
바꾸려는 토큰이 몇 번에 나오는지 반드시 확인하고 **함께** 고치세요.

### 저장소 전체로는 열일곱 벌

같은 토큰이 다른 앱들에도 복사돼 있습니다.

```
08. 실행계획(3)/apps/kit/leap.css      ← 원본
08. 실행계획(3)/apps/a-circuit/index.html
08. 실행계획(3)/apps/b-classboard/index.html
   … 앱 12개 …
06. 실행계획(1)/prototype/index.html   ← 이 대시보드
index.html                             ← 첫 화면
```

대시보드만 고치면 **대시보드만 색이 갈립니다.** 브랜드 색을 바꾸는 일이라면
`apps/kit/leap.css` 부터 고치고 사본들을 맞춰 주세요.
이 대시보드 화면만의 조정이라면 대시보드만 고쳐도 됩니다 — 어느 쪽인지 먼저 정하세요.

### 학교급 5색

`--lv-유` `--lv-초` `--lv-중` `--lv-고` `--lv-특수`
(각각 `-mark` 짝이 있습니다 — 글자용/도형용)

> 다섯 색은 **명도가 비슷해 색만으로는 구분되지 않습니다.**
> 그래서 모든 마커와 범례에 학교급 글자나 모양(● ▲ ■)을 함께 적습니다.
> 색을 바꾸더라도 이 원칙은 유지해 주세요.

### 규모·밀도 3색

`--over`(과밀·빨강) `--fit`(기준 이내·초록) `--under`(과소·노랑)
및 각각의 `-bg` 짝.

## 3. 명암비를 지켜 주세요 (검사가 막습니다)

토큰 옆 주석의 숫자가 **명암비**입니다.

```css
--leap-blue: #1B4FA0;  /* 7.45:1 */
```

- 글자로 쓰이는 색: **4.5:1 이상**
- 도형·아이콘으로만 쓰이는 색: **3:1 이상**

`test.js` 가 학교급 색의 라이트·다크 대비를 **실제로 계산**합니다.
기준을 못 넘기면 검사가 실패하고 **배포가 멈춥니다.**
색을 바꿨다면 주석의 숫자도 새 값으로 고쳐 주세요.

명암비 계산은 [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) 같은 도구를 쓰면 됩니다.

## 4. 요소 하나의 생김새만 바꾸려면

`</style>` 바로 위 **「디자인팀 구역」** 에 새 규칙을 씁니다.

```css
/* 여기부터 씁니다 ↓ */
.card{ border-radius:14px }
.stat .v{ letter-spacing:-.03em }
```

위쪽의 원래 규칙을 **지우지 말고 덮어쓰세요.** 같은 선택자라면 뒤에 있는 것이
이깁니다. 이렇게 하면 다른 팀과 같은 줄에서 부딪히지 않습니다.

## 5. 바꾼 뒤 반드시 볼 네 화면

1. **밝은 화면** (기본)
2. **어두운 화면** — 오른쪽 위 「어두운 화면으로」
3. **인쇄 미리보기** — 「현재 화면 인쇄」 (종이는 흑백이라 색이 아니라 모양으로 구분돼야 합니다)
4. **좁은 화면** — 브라우저 폭을 720px 아래로 (사이드바가 위쪽 띠로 바뀝니다)

여기에 더해 **지도 크게 보기**(전체 화면)와 **메뉴 접기** 상태도 한 번씩 봐 주세요.
이 둘은 레이아웃이 크게 달라집니다.
