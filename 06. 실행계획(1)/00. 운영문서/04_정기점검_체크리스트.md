## 배포 직전 한 줄 검사

프로젝트 루트에서 다음 명령을 실행합니다.

```bash
./사이트\ 굽기.command
```

실패한 검사가 있으면 배포하지 않습니다. 새 API 수집이 실패해도 직전 정상 화면을 유지하는 것이 원칙입니다.
