# 자료요청 범위 정리

## 현재 결론

경북교육청 부서별 정책·사업 실적이나 별도 내부 원자료를 일괄 요청하지 않습니다. 핵심 지도·현황·시뮬레이터는 학교알리미, EDSS, KOSIS, SGIS, 유치원알리미 등 공개 API로 구현하고 정기 갱신합니다.

## 현재 요청·대기 중인 것

| 자료 | 상태 | 다음 행동 |
|---|---|---|
| EDSS Open API | 신청 완료·승인 대기 | 승인 뒤 인증정보와 출력필드 확인 |
| 학교속성 | EDSS 승인 후 사용 | 학교코드·학교급·소재지 등 학교알리미와 비교 |
| 유초중등학교개황 | EDSS 승인 후 사용 | 학교 수와 기준연도 교차검증 |
| 유초중등학급현황 | EDSS 승인 후 사용 | 학교알리미 학급수와 차이 검증 |
| 유초중등학생현황 | EDSS 승인 후 사용 | 학교알리미 학생수와 차이 검증 |

## 요청하지 않는 것

- 학생별·거주지별·통학경로 자료
- 부서별 정책과 사업 실적
- 내부 통폐합 검토 명부
- 조직도·홍보 이미지·내부 계획 원문
- 담당자가 별도 데이터 파일로 가공해야 하는 자료

## 예외적으로 다시 요청할 조건

다음 세 가지를 모두 만족할 때만 담당자와 사전 협의합니다.

1. 구현할 핵심 기능이 구체적으로 정해져 있음
2. 공공 API에 해당 필드가 없음을 확인함
3. 필요한 최소 필드·기준연도·공개범위·사용 목적을 한 장으로 설명할 수 있음

요청문에는 “AI가 필요하다고 제안했다”는 표현을 사용하지 않고, 실제 화면 기능과 공개 데이터의 부족 부분을 담당자가 검토할 수 있는 형태로 설명합니다.
