## 0. 결론 먼저 — 세 문장

1. **지도 엔진은 바꾸지 않습니다.** 다른 팀 지도와의 차이는 엔진이 아니라 상호작용 설계입니다.
2. **학교별 과거 자료는 이미 받고 있습니다.** EDSS 에서 받아서 **굽는 과정에서 버리고 있었습니다.**
   새로 신청할 API 가 없습니다. 굽는 스크립트에서 내보내기만 하면 됩니다.
3. **왼쪽 요약 칸을 연도 슬라이더에 반응하는 자리로 바꿉니다.** 회의에서 말씀하신 구조가 맞습니다.

## 1. 다른 팀 지도와의 차이 — 엔진이 아니라 상호작용

### 1-1. GIS 와 SGIS 의 관계

**GIS 는 분야 이름이고, SGIS 는 그 분야의 서비스 하나입니다.** 다른 팀이 「GIS 를 쓴다」고
말한 것은 엔진을 특정한 말이 아닙니다. 네이버 부동산은 네이버 지도를, 우리는 통계청 SGIS 를
쓰고 있을 뿐 둘 다 GIS 입니다.

그리고 **우리가 쓰는 SGIS 는 Leaflet 계열 API** 입니다. 코드에서 이미 이렇게 부르고 있습니다.

| 지금 쓰고 있는 것 | 하는 일 |
|---|---|
| `sop.markerClusterGroup` | 가까운 학교를 하나로 묶기 |
| `sop.divIcon` | 말풍선 안에 값 적기 |
| `map.on('zoomend')` | 확대·축소에 반응하기 |
| `map.getBounds()` | 지금 보이는 범위만 세기 |
| `map.setView()` | 특정 학교로 날아가기 |

**네이버 부동산이 하는 동작 대부분이 이 다섯 개 위에서 만들어집니다.**
값이 적힌 말풍선도, 숫자가 든 묶음 원도 우리 지도에서 이미 돌고 있습니다.

### 1-2. 그래서 실제로 없는 것은 둘뿐입니다

| 없는 것 | 네이버 부동산에서 무엇에 해당하나 |
|---|---|
| **줌 단계별 집계 전환** | 시·도 → 구 → 동 → 단지로 바뀌는 것 |
| **연도 축** | 「5년 평당가 추이」 토글 |

나머지 차이(배경지도 미감, 정보 밀도)는 취향과 다듬기의 영역입니다.

### 1-3. 엔진을 바꾸지 않는 이유

| | 바꿀 때 잃는 것 | 얻는 것 |
|---|---|---|
| CSP | `/dashboard/*` 의 `style-src`·`img-src`·`connect-src` 를 새 도메인으로 다시 씀 | — |
| 인증키 | `functions/api/sgis-map.js` 프록시를 새로 만듦 | — |
| 오프라인 대비 | SGIS 실패 시 SVG 지도로 내려앉는 이중화를 다시 검증 | — |
| 행정경계 | SGIS 는 **통계 경계에 강합니다.** 읍면동 단계를 만들 때 이게 필요합니다 | — |
| 배경지도 | | 미감이 나아짐 |

**얻는 것이 미감 하나뿐입니다.** 회의에서 미감이 실제 지적사항으로 올라오면
그때 VWorld(국토부, 무료, 행정경계 제공)를 후보로 다시 봅니다. 지금은 아닙니다.

## 2. ★ 학교별 과거 자료 — 이미 받고 있고, 버리고 있습니다

**이번 점검에서 가장 중요한 발견입니다.**

### 2-1. 무슨 일인가

EDSS 의 `유초중등학생현황` · `유초중등학급현황` 두 API 는
**학교(`opnId`) × 학년 × 연도** 단위로 옵니다. 2016~2025 열 해치 **97,134행**을
이미 받고 있습니다.

그런데 `open api/bake-edss.mjs` 의 `aggregate()` 가 이렇게 접습니다.

```
학교 × 학년 × 연도   →   시군 × 학교급 × 연도
```

접고 난 뒤 **학교 단위 원자료는 어디에도 저장되지 않습니다.**
`edss-series.json` 에도 시군별·학년별 집계만 들어 있습니다.

코드 주석은 이렇게 적고 있습니다.

> 학교·학년 단위를 시군×학교급×연도로 접습니다. 대시보드가 필요한 것은 여기까지입니다 —
> 학교별 여러 해치를 화면에 넣으면 400KB 가 됩니다.

**그때는 맞는 판단이었습니다.** 화면에 넣을 데가 없었으니까요.
이제 연도 슬라이더가 그 자리입니다.

### 2-2. 그래서 무엇을 하면 되나

| | |
|---|---|
| 새로 신청할 API | **없습니다** |
| 고칠 곳 | `bake-edss.mjs` 에 내보내기 한 벌 추가 |
| 나오는 것 | `open api/data/school-series.json` |
| 담을 것 | 학교코드 → 연도별 학생수·학급수 (2016~2025) |

### 2-3. 크기와 싣는 법

| 방식 | 크기 어림 | 판단 |
|---|---|---|
| 학교 × 연도 **합계**만 (학생수·학급수) | 약 60~90KB | **인라인 가능** |
| 학교 × 연도 × **학년별**까지 | 약 400KB | 별도 파일 + 지연 로딩 |

**별도 파일도 문제없습니다.** `/dashboard/*` 의 CSP 는 `connect-src 'self'` 라
같은 출처 파일은 부를 수 있습니다. 이미 `/api/ai-analysis` 를 그렇게 부르고 있습니다.

> 권고: **합계는 인라인, 학년별은 별도 파일**로 나눠 슬라이더를 처음 만질 때 불러옵니다.
> 첫 화면이 무거워지지 않고, 안 쓰는 사람은 받지 않습니다.

### 2-4. 그래도 못 채우는 자리

| | 왜 |
|---|---|
| 2026년 학교별 | EDSS 조사연도가 아직 2025 까지입니다. 2026은 학교알리미 공시로 한 해만 |
| 유치원·특수학교 과거 | EDSS 유초중등 두 API 가 초·중·고 중심입니다. 확인 필요 |
| 폐교의 과거 학생수 | 폐교 시점 이전 자료를 EDSS 가 주는지 확인 필요 |

**슬라이더를 만들 때 이 세 자리를 화면이 스스로 말하게 해야 합니다.**
없는 해에 선을 이으면 그것이 곧 지어낸 자료가 됩니다.

## 3. 새 구조 — 왼쪽 칸을 연도 슬라이더에 붙입니다

### 3-1. 회의에서 말씀하신 구조가 맞습니다

네이버 부동산의 왼쪽 칸은 **지도에서 고른 것의 상세**입니다.
지금 우리 왼쪽 칸은 **지도와 무관한 고정 요약**입니다. 이것을 바꿉니다.

| 지금 왼쪽 칸 | 바뀐 뒤 |
|---|---|
| 경북 학령인구 현황 (고정값) | **선택 지역 × 선택 연도**의 학생수·학급수 |
| 경북 학생수 현황 (고정값) | **연도별 추이 꺾은선** — 슬라이더를 끌면 함께 움직임 |
| 학령인구 지표 (고정값) | 선택 지역의 학교당·학급당 평균 |
| 주간 AI 뉴스 요약 | **아래로 내리거나 뉴스 화면으로 옮김** (아래 설명) |

### 3-2. 뉴스 요약은 슬라이더에 붙이지 않습니다

**뉴스에는 2016~2036 축이 없습니다.** 연도 슬라이더를 2018년에 놓았을 때
「2018년의 주간 뉴스」는 존재하지 않습니다. 슬라이더 옆에 두면 사용자는
당연히 연동될 것으로 기대하고, 연동되지 않으면 고장으로 읽습니다.

> 뉴스 요약 카드는 **왼쪽 칸 맨 아래로 내리고 슬라이더 영역 밖에 둡니다.**
> 시각적으로도 구분선을 넣어 「이 위는 연도에 반응하고, 아래는 아니다」를 보이게 합니다.

### 3-3. 줌 단계와 화면의 대응

| 줌 | 지도에 보이는 것 | 왼쪽 칸 | 연도 슬라이더 |
|---|---|---|---|
| 경북 전체 | **시군 22개 원** — 안에 학생수 | 경북 합계 + 추이 | **작동** |
| 시군 | **읍면동 집계 원** | 그 시군 + 추이 | **작동** |
| 읍면동 | **학교 말풍선** — 학생수와 증감률 | 그 지역 학교 목록 | 2026 고정 |
| 학교 클릭 | 말풍선 상세 | 그 학교 상세 | **2-2 완료 후 작동** |

### 3-4. 네이버 부동산에서 그대로 가져올 것

| 저쪽 | 우리 |
|---|---|
| 하단 「매물 212 · 단지 31」 | 하단 「학교 N곳 · 학생 N명」 |
| 「용흥동만 보기」 | 「이 시군만 보기」 |
| 오른쪽 세로 레일(교육·편의·개발) | 레이어 토글(폐교·유치원·특수·통학반경) |
| 상단 필터 칩 | 학교급·규모·증감률 |

## 4. 단계와 기한

| 단계 | 무엇 | 자료 준비 | 크기 |
|---|---|---|---|
| **1** | 줌 문턱 세 개로 집계 단위 전환 (시군 원 ↔ 학교 말풍선) | **지금 있는 것으로 됨** | 2일 |
| **2** | 왼쪽 칸을 지도 선택에 동기화 · 뉴스 카드 분리 | 지금 있는 것으로 됨 | 1일 |
| **3** | **연도 슬라이더 — 시군 단위** | `EDSS_SGG` 로 **지금 됨** | 2일 |
| **4** | `bake-edss.mjs` 에 학교별 시계열 내보내기 추가 | **코드 완료** · Actions 1회 실행 남음 | 1일 |
| **5** | **연도 슬라이더 — 학교 단위** | **코드 완료** · 4단계 자료 오면 켜짐 | 2일 |
| **6** | 읍면동 단계 (좌표를 행정동으로) | `kakao-geocode.mjs` 재사용 | 1.5일 |
| **7** | 레이어 토글 · 하단 집계 표시 · 다듬기 | — | 2일 |

**1·2·3 단계는 지금 심어진 자료만으로 끝납니다.** 시군 단위 연도 슬라이더가
먼저 돌아가는 것을 보고 나서 학교 단위로 내려가는 순서입니다.

### 4-1. 4단계는 왜 따로인가

EDSS 인증키가 **GitHub Actions Secrets 에만** 있고 로컬에는 없습니다.
그래서 학교별 시계열은 로컬에서 굽지 못하고 Actions 에서 한 번 돌려야 합니다
(`workflow_dispatch` 의 `edss`).

### 4-2. 〔2026-09-09〕 코드는 끝났습니다 — 남은 것은 Actions 1회

키 없이 검증한 방법과 결과입니다.

| 무엇 | 어떻게 | 결과 |
|---|---|---|
| 굽는 쪽 순수 함수 | `schoolSeries` · `toSchoolBlock` 을 지어낸 records 로 검사 | 검사 통과 |
| 굽기→화면 한 바퀴 | SCHOOL_RAW 917곳에 **가짜 열 해치**를 심어 사본을 만듦 | **917곳 전부 붙음 · 못 붙임 0** |
| 크기 | 심기 전후 비교 | 672KB → **737KB (+65KB)** — 인라인으로 충분 |
| 화면의 «심은 뒤» 갈래 | 그 사본으로 대시보드 검사를 다시 돌림 | 285개 전부 통과 |

**Actions 를 돌리는 순간 켜집니다.** 그 전까지 화면은 예전 그대로 돌고,
지난 해를 물으면 «없다»고 답합니다. 검사가 양쪽 갈래를 모두 지킵니다.

굽는 쪽에 **관문**을 하나 두었습니다 — 학교 이름이 **90% 미만**으로 붙으면
심지 않고 멈춥니다. 절반만 붙어도 화면은 조용히 그려지고, 사람은
「어떤 학교는 슬라이더가 안 먹네」로만 느낍니다. 원인을 찾을 수 없는 종류의 고장입니다.

회의에서 나온 질문에 대한 답입니다.

### 6-2. Public 으로 바꾸면

**추가 설정은 필요 없습니다.** 그리고 덤이 셋 있습니다.

| | |
|---|---|
| Collaborator 초대 | **불필요해집니다** — 링크만 주면 누구나 읽습니다 |
| Actions 사용량 | 공개 저장소는 **무제한 무료** |
| 브랜치 보호 규칙 | 공개 저장소는 **무료** — 9/9 회의의 A안/B안 월 $4 논의가 사라집니다 |
| Secret scanning | 공개 저장소는 **무료로 켜집니다** |

**Actions Secrets 는 공개해도 노출되지 않습니다.** 암호화되어 있고 로그에도 가려집니다.

### 6-3. 다만 바꾸기 «전에» 확인할 것

- [ ] `배포/site/` 쪽 저장소(`team-leap`)도 같은 검사를 한 번 돌릴 것
- [ ] 문서에 적힌 내부 정보(부서명·담당자·미공개 계획)를 공개해도 되는지 판단
- [ ] 바꾼 직후 **Secret scanning 경고를 한 번 확인**

> 코드에는 문제가 없습니다. 판단이 필요한 것은 **문서 쪽**입니다.
> `98. 노션/` 과 `2. 깃허브 미탑재 (참고자료)/` 는 애초에 저장소 밖이라 해당 없습니다.

## 7. 회의에서 나온 나머지 항목 — 가능 여부

| 항목 | 가능한가 | 언제 |
|---|---|---|
| 뉴스 키워드 빈도·워드클라우드·다빈도 | **가능** — 굽는 단계에서 순수 JS | 지도 다음 |
| 기사 벡터화·유사도 묶기 | **가능** — TF-IDF + 코사인, 의존성 0 | 〃 |

| 이슈페이퍼 생성·아카이브 | **가능** — Gemini 초안 + 사람 검토 | 〃 |
| 시군별 대응 진단지수 | **가능** — 지금 자료만으로 하위지표 5개 | 10월 |
