## 구성안과 다른 점 — 그리고 그 이유

### 1. 지도 API 를 쓰지 않습니다 (VWorld 도 아닙니다)

원래 계획은 VWorld 였습니다. 그런데 **앱 E 가 외부 호출 없이 위경도를 화면 좌표로 옮기는 것만으로
지도를 그리고 있었습니다.** 같은 방식을 가져왔습니다.

- 외부를 부르지 않으므로 **보안성 검토에 걸릴 것이 없습니다** (원칙 1번)
- 인터넷 없이 그려집니다
- 도메인 등록·호출 쿼터·상용 라이선스 문제가 없습니다

울릉군은 본토에서 동쪽으로 1.5도 떨어져 있어, 같은 축척에 넣으면 나머지 21개 시군이
왼쪽 구석에 뭉칩니다. **축척이 다른 별도 상자**에 넣고 화면에 그렇게 적었습니다.

### 2. 학교급을 **색이 아니라 모양**으로 나눕니다

● 초등학교 · ▲ 중학교 · ■ 고등학교.

색도 함께 쓰지만 색은 보조입니다. 학교급 5색은 명도가 서로 비슷해
**색만으로는 구별되지 않습니다** — 흑백 인쇄와 색각 이상에서 그렇습니다 (원칙 4번).

### 3. 학교 수는 **실데이터**를 씁니다 — 구성안 예시표가 아니라

구성안 5쪽 예시표의 시군별 중학교 학교수와 실데이터를 대조했더니:

```
합계는 260 으로 같은데, 22개 시군 중 14개가 다릅니다.
  경주 25→20  ·  구미 25→30  ·  경산 17→15  ·  울릉 2→1  ·  청송 6→8 …
```

**합계만 맞아서 아무도 몰랐던 종류의 어긋남입니다** (마스터 함정 12번).
실데이터를 기준으로 삼고, 중학교 상세 화면에서 구성안과 다른 시군에는 차이를 적어 둡니다.

기준일 차이인지 분교장·각종학교 셈법 차이인지는 **기획예산관 확인이 필요합니다.**

### 4. 유치원·특수학교는 고르지 못하게 두었습니다

공공데이터로 받은 917곳은 초·중·고뿐입니다. 구성안 지도에는 유·특수가 나오므로
**범위를 기획예산관에 확인해야 합니다.** 없는 것을 있는 척하지 않습니다.

### 5. 방송통신중학교를 뺐습니다

`apiType=09` 는 918곳을 주는데 그 중 **포항중학교부설방송통신중학교**가 있습니다.
학령인구 분석 대상이 아니라고 보아 뺐습니다. 그래서 중학생 계가
API 원값 63,324 가 아니라 **63,119** 입니다. 이 판단도 확인 대상입니다.

### 6. 산출 기준을 "둘 중 하나만 활성"으로

구성안 5쪽의 `● 학교 수` / `○ 학급당 학생 수`는 상위 라디오이고 각각 하위 3개 옵션을 가집니다.
2030년 표에서 **파란 숫자(학급수·학교수)는 입력한 기준, 빨간 숫자(학급당 평균)는 산출 결과**입니다.
즉 두 그룹은 동시에 적용되는 게 아니라 **무엇을 고정하고 무엇을 결과로 볼지**를 고르는 구조입니다.

이 해석이 맞는지 **기획예산관 확인이 필요합니다.**

### 7. 예측 패널을 진한 파랑 바탕에서 옅은 바탕으로 바꿨습니다

구성안은 진한 파랑에 흰 글자입니다. 두 가지 이유로 바꿨습니다.

- **인쇄하면 배경이 빠져 흰 종이에 흰 글자만 남습니다** (마스터 함정 1번)
- 다크 모드에서는 주색이 밝아져 흰 글자의 대비가 무너집니다 (함정 3번)

테두리와 옅은 바탕으로 구분하고 글자는 본문 색을 씁니다.

### 8. 확보하지 못한 데이터의 필터는 비활성

`교육혁신선도지역`(D8), `도서·벽지`(D4)는 눌리지 않게 두고 사유를 툴팁에 적었습니다.
있는 척하는 것보다 낫습니다.

## 접근성

12월 누리집 탑재 조건에 웹 접근성 인증이 있어 처음부터 반영했습니다.
**v0.2 에서 색을 전부 다시 계산했습니다** — v0.1 의 색은 기준에 미달했습니다.

| 항목 | v0.1 | v0.2 |
|---|---|---|
| 학교급 5색 (도형 3:1) | 2.20 ~ 3.26 — **4색 미달** | 3.85 ~ 7.86 전부 통과 |
| 밀도 태그 글자 (4.5:1) | 2.73 / 3.66 / 3.67 — **전부 미달** | 5.36 ~ 5.74 통과 |
| 포커스 표시 (3:1) | `#ff8c00` **2.33 미달** | `#1B4FA0` 7.86 통과 |
| 다크 모드 | 없음 | 있음 (양쪽 다 기준 통과) |
| 인쇄 | 없음 | 있음 |

- 색상만으로 정보를 전달하지 않음 — 학교급은 **모양**, 밀도는 **색 + 텍스트 라벨**
- 모든 차트에 **대응하는 데이터 표** 제공 (`aria-describedby` 연결)
- 전체 키보드 조작 가능 — 지도의 시군도 `tabindex` + Enter/Space
- 의미 있는 마크업 (`nav`, `main`, `table` + `caption`, `fieldset` + `legend`)
- 토글 버튼에 `aria-pressed`, 현재 메뉴에 `aria-current`
- 버튼 최소 높이 44px, 포커스 표시 3px
- `prefers-reduced-motion` 존중

※ 자동 검사 도구(K-WAH 등)로 정식 진단하는 것은 11월 과제입니다.
