경북 학령인구 데이터 플랫폼

갱신: 2026-08-28

경북 학령인구의 현재와 장래 인구 흐름을 공개 데이터로 쉽게 보여 주는 대시보드입니다. 지도에서 학교·학생·학급 분포를 탐색하고, 시군·학교급별 현재 실적과 조건별 모의값을 비교할 수 있습니다.

주요 기능

  • 실제 위치 지도와 간편 지도에서 학교 수·학생 수 군집 확인
  • 경북 전체와 22개 시군의 학교급별 학교·학생·학급 현황 비교
  • KOSIS 학령인구 실적·장래인구와 학교알리미 재학생 실적 확인
  • 시군·학교급별 학생수·학급수·학교수 모의 비교
  • 현재 조건의 Excel 저장과 인쇄·PDF 출력
  • 집계값을 쉬운 말로 설명하는 변화 읽기 도우미
  • 주간·월간·주제별 관련 뉴스 클리핑

시뮬레이터 해석

시뮬레이터의 공간 범위는 경북 전체 또는 시군 한 곳·여러 곳이며, 학교급은 초·중·고입니다. 기준연도는 공개된 학교알리미 실적입니다.

모의연도 값은 화면에서 선택한 계산 가정을 적용한 참고값입니다. 공식 장래 학생수 추계, 학교별 미래 학생수 또는 개폐교 판단 결과가 아닙니다.

  • 뉴스는 매주 자동 갱신합니다.
  • KOSIS는 매월 개정 여부를 확인합니다.
  • 학교·유치원·좌표는 분기별로 확인하고 새 공시연도는 운영자 확인 후 반영합니다.
  • 합계·중복·누락·좌표·기준연도·키 유출 검사를 통과한 자료만 공개합니다.
  • 수집이나 검사가 실패하면 빈 값으로 덮지 않고 직전 정상 자료를 유지합니다.
