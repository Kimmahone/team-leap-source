## 배포 전에 해야 할 일

1. 대화에 노출된 모든 API 키를 각 발급기관에서 재발급 또는 폐기 후 재발급한다.
2. [Cloudflare Pages 프로젝트](https://dash.cloudflare.com/)의 **Settings → Variables and Secrets**에서 `GEMINI_API_KEY`와 `SGIS_CONSUMER_KEY`를 우선 암호화 Secret으로 등록한다. 나머지 키도 같은 이름으로 등록해 다음 데이터 갱신에 대비한다. 등록·교체 뒤에는 반드시 새 배포를 만든다.
3. Google Cloud의 해당 키를 **Generative Language API(Gemini API)로만 제한**하고 결제 계정을 연결하지 않는다. 무료 한도 초과 시 앱은 오프라인 요약으로 전환한다.
4. 무료 등급에서 전송 데이터가 Google 제품 개선에 사용될 수 있으므로 AI에는 집계값만 보내고 개인자료·학교 내부 비공개자료는 보내지 않는다.
5. 배포 후 `/dashboard/#sim`에서 `이 결과로 정책 검토안 만들기`를 눌러 응답과 한도 초과 메시지를 확인한다.

로컬 개발 키는 저장소 루트의 `.dev.vars`에 이미 정리했다. 이 파일은 커밋되지 않으며, 공유용 이름만 `.dev.vars.example`에 있다.

6. Cloudflare Pages를 GitHub `Kimmahone/team-leap`의 `main` 브랜치와 연결한다. 연결 전에는 GitHub Actions가 배포 저장소를 갱신해도 라이브 사이트가 자동으로 바뀌지 않는다.
