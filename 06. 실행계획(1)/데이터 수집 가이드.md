# 데이터 수집 가이드 (T1)

- 목적: 「경북 학령인구 데이터 플랫폼」 프로토타입에 필요한 데이터 9종(D1~D9)을 **어디서, 어떤 형태로, 어떤 컬럼을** 받아야 하는지 정리
- 원칙: **공개데이터만으로 전체 파이프라인을 먼저 완주한다.** 내부 데이터는 나중에 같은 컬럼으로 교체한다.
- 작성: 2026. 8. 1.

> ⚠ 사이트 메뉴 경로와 파일명은 개편으로 바뀔 수 있습니다. 아래는 "무엇을 찾아야 하는지"의 지도이며, 실제로 받은 파일은 `data/raw/D*` 폴더에 넣고 이 문서 맨 아래 **수집 대장**에 기록하세요.

## 폴더 구조

```
06. 실행계획/
├─ GBE-AI Lab 학령인구 대응 실행계획(마스터).md
├─ 데이터 수집 가이드.md              ← 이 문서
├─ data/
│  ├─ raw/                            ← 받은 원본을 손대지 말고 그대로
│  │  ├─ D1_장래인구/    D2_학생학급/   D3_학교위치/
│  │  ├─ D4_학교속성/    D5_교원/       D6_학급편성기준/
│  │  └─ D7_인구감소지역/ D8_교육혁신선도지역/ D9_뉴스/
│  ├─ master/                          ← 기준 정보 (시군 코드 등)
│  │  ├─ sigungu.json                  ← ✅ 완성 (T2)
│  │  ├─ schools.schema.md             ← ✅ 완성 (T2, 컬럼 정의)
│  │  └─ schools.template.csv          ← ✅ 완성 (T2, 빈 양식)
│  └─ processed/                       ← 정제 결과 JSON (프로토타입이 읽는 것)
└─ prototype/                          ← T3 산출물
   └─ index.html
```

**원본은 절대 수정하지 않습니다.** 받은 그대로 `raw/`에 두고, 가공은 `processed/`에 새 파일로 만듭니다. 나중에 "이 숫자 어디서 나왔냐"는 질문에 답하려면 이게 필요합니다.

**파일명 규칙**: `D2_KESS_시군구별학생수_2016-2026_수집20260801.xlsx`
→ `D번호_출처_내용_대상연도_수집일`

## D1. 장래인구 · 학령인구

| 항목 | 내용 |
|---|---|
| **1순위 출처** | **KOSIS 국가통계포털** (kosis.kr) |
| 찾을 통계 | ① 「장래인구추계」 시도편 — 경북 연령별(1세 단위) 추계인구<br>② 「장래인구추계시군구편」 — 시군구 단위 (있으면 최우선)<br>③ 「주민등록인구현황」(행정안전부) — 연령별 실적, 코호트 모델 검증용<br>④ 「인구동향조사」 출생 — **시군별 연도별 출생아수** (초1 신입생 추정에 필수) |
| 받는 법 | KOSIS 상단 검색 → 통계표 선택 → 조회 조건(지역=경상북도 하위, 연령=0~18세 각세, 기간=2016~2036) → **Excel 다운로드**. 또는 KOSIS 공유서비스 OpenAPI 인증키 발급 |
| 필요 컬럼 | `연도, 시군코드, 시군명, 연령(만), 인구수, 성별(선택)` |
| 참고 | 구성안 4쪽 출처가 **"국가데이터처 장래인구추계"** 이므로 동일 통계를 쓰는 것이 맞습니다. 학령인구 정의도 구성안과 동일하게 **6~18세, 대학(19~24세) 제외** |

> 🔎 **핵심 확인 사항**: 장래인구추계가 시군 단위로 제공되는지. 시도 단위만 있으면 시군 배분을 우리가 해야 하고(주민등록 연령별 인구의 시군 점유율로 배분), 그 가정을 반드시 문서에 남겨야 합니다.

## D2. 학교별 학생수 · 학급수 (가장 중요)

| 항목 | 내용 |
|---|---|
| **1순위 출처** | **학교알리미** (schoolinfo.go.kr) — 학교 단위 |
| 찾을 자료 | 공시정보 > **공시자료 다운로드(일괄 다운로드)** > 「학생 현황」·「학급 편성 현황」 |
| 받는 법 | 지역=경상북도, 학교급 전체, 연도별로 엑셀 일괄 다운로드. **Open API**(정보공시 API)도 제공 — 인증키 신청 후 학교코드 단위 조회 가능 |
| 필요 컬럼 | `학교코드, 학교명, 학교급, 시군, 연도, 학년, 학생수(남/여), 학급수, 특수학급수, 특수학생수` |
| **2순위 출처** | **교육통계서비스 KESS** (kess.kedi.re.kr) — 시군구 집계 |
| 찾을 자료 | 교육통계 > 유·초·중등 > 「시도별/시군구별 학교·학급·학생·교원 수」, 「교육통계연보」 엑셀 |
| 용도 | 학교알리미 합계와 **교차 검증**. 시계열(2016~2026)은 KESS가 받기 편합니다 |
| **3순위** | 경상북도교육청 교육통계연보 (gbe.kr 정보공개) |

> 🔎 **핵심 확인 사항**: **학년별** 학생수가 나오는지. 코호트 진급 모델은 학년 단위 데이터가 없으면 성립하지 않습니다. 학교급 총계만 있으면 모델이 학교급 단위로 거칠어집니다.

| 항목 | 내용 |

## D6. 학급편성 기준

| 항목 | 내용 |
|---|---|
| 1순위 | 경상북도교육청 **「학급편성 및 교원배치 기준」** — 매년 학년도 단위로 시행, 교육청 공고·정보공개 청구로 확보 가능 |
| 2순위 | **역산.** D2의 실적 데이터에서 `학급수 = ceil(학생수 / L)`을 만족하는 L을 시군·학교급별로 역추정 |
| 필요 값 | 학교급별 학급당 학생수 상한, 복식학급 편성 기준(학년별 학생수 하한), 최소 학급수 |
| **현실적 대응** | 정식 기준 확보 전에는 **2순위 역산값**으로 진행하고, 시뮬레이터 화면에 "가정값" 표기 |

> 구성안 5쪽의 시뮬레이터가 `학급당 __명 ± __명`, `학급당 __명 · 학년당 __학급`을 **사용자 입력**으로 받는 구조인 것은 다행입니다. 기준값을 몰라도 화면은 만들 수 있습니다.
