## 2. 손봐야 할 것 — 여덟 가지

### ⚠️ 먼저, 지금 화면이 «틀린» 곳 하나

현재 「특수교육 대상자」로 적고 있는 값은 **특수학교 + 특수학급 학생**입니다.
그런데 특수교육 배치는 셋입니다.

```
① 특수학교              ← 세고 있음
② 일반학교 특수학급      ← 세고 있음
③ 일반학교 일반학급(완전통합) ← 빠져 있음
```

③이 빠졌으므로 **지금 값은 실제 특수교육 대상자보다 적습니다.** 전국적으로 ③은
전체의 15~20% 안팎을 차지하는 것으로 알려져 있어(정확한 경북 수치는 확인 필요),
작지 않은 누락입니다.

> **당장 할 일**: 「특수교육 대상자」라는 이름을 그대로 두려면 ③을 채워야 하고,
> 채우기 전까지는 **「특수학교·특수학급 배치 학생」** 으로 이름을 바꾸고
> 「완전통합 학생은 자료 미확보로 빠져 있습니다」를 화면에 적어야 합니다.
> 이 프로젝트의 원칙(없는 값을 만들지 않는다)과 같은 이유입니다.

### 나머지 일곱 가지

| # | 무엇 | 왜 필요한가 | 필요한 자료 |
|---|---|---|---|
| 1 | **메뉴 이름 정리** | 메뉴는 「다문화 및 특수교육 모니터링」인데 화면 제목은 「특수교육 모니터링」 | 없음 |
| 2 | **연도별 추이** | 지금은 2026년 한 장뿐. **학령인구는 주는데 특수교육 대상자는 늘고 있는지**가 이 대시보드의 핵심 물음인데 볼 수 없음 | 공개자료 ✅ |
| 3 | **완전통합 학생** | 위 ⚠️ | 도교육청 또는 특수교육통계 |
| 4 | **학교급별 분해** | 초·중·고 어디에 몰려 있는지 | **이미 있음** (지금 데이터로 가능) |
| 5 | **특수학급 미설치 지역** | 특수학급이 없는 시군·학교는 학생이 멀리 가야 함 | **이미 있음** |
| 6 | **특수학교 접근성** | 특수학교가 경북에 8곳뿐. 어느 시군 학생이 얼마나 멀리 다니는지 | **이미 있음** (좌표 보유) |
| 7 | **특수교사 정원·현원, 학급당 학생 수** | 법정 기준 대비 과밀 여부 — 정책 판단에 가장 직접적 | 도교육청 |
| 8 | **다문화 학생 전부** | 메뉴 이름의 절반이 비어 있음 | 공개자료 ✅ |

> **4·5·6번은 자료를 새로 받지 않아도 지금 만들 수 있습니다.**
> 학교별 `sped`, `lv`, 시군, 좌표가 이미 앱 안에 있습니다.

## 5. 받은 자료를 앱에 어떻게 심나

이 프로젝트에는 이미 정해진 길이 있습니다. **새 방식을 만들지 마세요.**

```
공개 API 로 받는 것 (KOSIS·학교알리미·EDSS)
   open api/bake-*.mjs 가 받아서 index.html 안에 «구워» 넣습니다
   → 이후 GitHub Actions 가 매월·분기 자동 갱신
   → 다문화(KOSIS)는 여기로 가야 합니다

손으로 받는 것 (PDF·엑셀·공문)
   data/master/ 에 CSV 로 정리 → bake 스크립트가 읽어 심습니다
   → schools.schema.md 와 같은 형식의 «스키마 문서»를 먼저 쓰고 받으세요
   → 특수교육통계·도교육청 자료는 여기로
```

**자료를 받기 전에 스키마부터 정하는 이유** — 형식을 정하지 않고 받으면
매년 다른 모양으로 오고, 그때마다 사람이 손으로 맞추게 됩니다.
`data/master/schools.schema.md` 가 그 본보기입니다.

---

## 6. 함께 지킬 것

1. **없는 값을 만들지 않습니다.** 자료가 없으면 「자료 없음」이라고 적습니다.
   이 화면은 한 번 지어낸 값(12%)으로 실제(2.1%)의 여섯 배를 보여 준 이력이 있습니다.
2. **기준일이 다른 수를 나란히 놓을 때는 그 사실을 적습니다.**
   학교알리미(공시 시점)와 교육기본통계(4월 1일)는 같은 날의 수가 아닙니다.
3. **개인이 식별될 수 있는 소수값은 올리지 않습니다.**
4. **다문화 학생은 「지원 대상」이 아니라 「학생」입니다.** 표현을 고를 때
   결핍이나 문제로 읽히지 않게 합니다. 유형 구분(중도입국 등)은 지원 설계에
   필요한 만큼만 씁니다.
