# 경북교육청 자료요청 최종 발송안

> **발송 취소·보관 문서(2026-08-28 결정)**
> 부서별 정책·사업자료와 별도 가공자료를 요청하지 않습니다. 현재 실행안은 [운영문서의 자료요청 범위 정리](./00.%20운영문서/05_자료요청_범위_정리.md)이며, EDSS 승인 결과와 공개 API만 우선 사용합니다.

기준일: 2026-08-27  
목적: 경북 학령인구 데이터 플랫폼의 지도·정책·예측 기능을 공식 자료로 완성하기 위한 1차 요청서

## 먼저 알려 드릴 점

- 이 문서는 기존 요청 목록의 요청 범위를 줄인 `실제 발송용` 문서입니다.
- EDSS·학교알리미·KOSIS·SGIS에서 얻을 수 있는 공개자료는 원칙적으로 중복 요청하지 않습니다.
- 학생 이름·주민등록번호·개인 주소 등 개인식별자료는 요청하지 않습니다.
- 담당 부서가 다를 경우 자료 보유 부서로 이송·전달해 주시기를 함께 요청합니다.

## 1차 필수 요청 자료

| 번호 | 요청 묶음 | 꼭 필요한 내용 | 기간·형식 | 활용 |
|---|---|---|---|---|
| 1 | 학교 기준정보·코드 이력 | 기관표준코드, 기관명, 학교급, 설립유형, 본교/분교, 운영·휴교·폐교, 주소, 행정동·법정동 코드, 위·경도, 교명변경·통폐합 이전/신규 코드와 적용일 | 최신 1건+변경이력, CSV UTF-8 또는 XLSX | 읍면동 지도, 연도별 연결, 통폐합 전후 비교 |
| 2 | 학구·공동학구·통학 지원 | 학교코드, 학구코드·명, 적용지역, 경계 GeoJSON/SHP, 공동학구 연결학교, 적용일·변경이력, 노선·정류장, 편도 거리·시간, 탑승 학생 수, 운행일, 지원비 | 최신+최근 5년 변경이력 | 통학 접근성과 학교배치 분석 |
| 3 | 2026 적정규모학교 육성 실제 적용자료 | 결재본, 별첨 기준표, 최소·소규모·적정규모 정의, 학교급·도농별 적용기준, 대상 기관코드, 추진유형·단계·일정, 학부모 동의율, 의견수렴일 | 2026 계획 원문 PDF/HWP+대상표 XLSX | 현재 임시로 표시한 학교 규모 분류를 공식 기준으로 확정 |
| 4 | 공식 학생 수 전망·검증자료 | 전망 기준일, 기관코드/시군, 전망연도, 학교급·학년, 전망 학생 수, 출생 코호트·전입전출·지역 간 이동 반영 여부, 산출방법, 과거 예측 오차 | 최신 전망~2035 이상, XLSX/CSV+방법론 문서 | 임시 감소율 모의값을 공식 기준선으로 교체 |
| 5 | 통폐합·신설·이전·휴교·폐교 이력과 예정 | 대상 기관코드, 유형, 추진단계, 결정·시행·예정일, 통합교·존치교, 신설·이전 위치, 학생배치계획, 이전/신규 코드 | 전체 이력+진행·예정 사업 | 시계열 단절 방지, 정책 일정 표시 |
| 6 | 교육혁신선도지역 공식 명부 | 정식 사업명, 지정근거, 기준연도, 대상 시군코드·학교코드, 지정·해제일, 사업기간, 담당부서 | 최신+변경이력 | 현재 비활성 필터를 공식 명부 기반으로 활성화 |

## EDSS 승인 결과를 보고 2차로 요청할 자료

아래는 교육청이 보유하고 EDSS에서 필요한 수준으로 받지 못했을 때만 2차로 요청합니다.

| 자료 | 필요 조건 |
|---|---|
| 2016~최신 학교·학년별 학생 수 | 기관표준코드, 조사연도, 학교급, 학년, 남·여·합계. 학교단위 집계, 개인자료 불필요 |
| 2016~최신 학교·학년별 학급 수 | 기관표준코드, 조사연도, 학교급, 학년, 학급 수, 특수학급 구분 |
| 교원 현황 | 기관코드, 연도, 학교급, 정원·현원·결원, 직위·자격·표시과목, 순회 여부 |
| 유치원 운영·원아·학급·교원 | 운영·휴원·폐원 상태를 포함한 여러 해치를 유치원알리미로 충분히 확보하지 못했을 때 |
| 전입·전출·학업중단 학교 집계 | 기관코드, 연도·학년, 전입·전출·학업중단 인원. 시군 전입전출은 KOSIS와 중복 요청하지 않음 |
| 학교 수용여건·시설 | 보통교실·특별교실, 수용가능인원, 연면적, 노후도, 증개축·공간재구조화 계획. 학생 수만으로 과밀을 판정하지 않기 위함 |
| 다문화·특수교육 집계 | 시군·학교급·학년별 집계와 지원실적. 공개는 소수값 마스킹 기준 적용 |

## 교육청에 중복 요청하지 않을 공개자료

| 자료 | 우선 확보처 |
|---|---|
| 출생아수, 연령별 인구, 장래인구, 시군구간 전입·전출 | KOSIS |
| 시군·읍면동 행정경계·중심좌표 | SGIS. 단, 학교와 행정동을 연결할 정식 코드는 1번에 포함 |
| 최근 3년 학교기본·학생·학급·교원 공시 | 학교알리미 Open API |
| 3년 이전 교육통계 시계열 | EDSS 심사 신청. 학교 수준의 연도·학년·기관코드가 나오는지 반드시 필드 정의서 확인 |
| 유치원 기본현황·공시 | 유치원알리미. EDSS 신청대상으로 가정하지 않음 |
| 인구감소지역 공식 명부 | 행정안전부 지정 문서 |

## 복사해서 보낼 요청문

> **제목: 경북 학령인구 데이터 플랫폼 구축 관련 원자료·기준문서 제공 요청**
>
> 경북 학령인구 데이터 플랫폼의 지도·정책·예측 기능을 공식 자료로 구현하기 위해 아래 자료를 요청드립니다.
>
> 1. 학교 기준정보·행정동/법정동 코드·기관코드 변경이력  
> 2. 학구·공동학구 경계와 통학지원 노선·거리·시간·탑승인원  
> 3. 2026 적정규모학교 육성 계획 결재본·별첨 기준표·대상학교표·추진일정  
> 4. 공식 학생 수 전망값·산출방법·전입전출 반영 여부·과거 예측 검증결과  
> 5. 학교 통폐합·신설·이전·휴교·폐교 이력과 진행·예정 계획  
> 6. 교육혁신선도지역 공식 시군·학교 명부·지정근거·기준연도  
> 7. 2026 주요업무계획 인포그래픽·조직도 원본과 과제별 담당부서·성과지표  
> 8. 교육행정데이터 연계 목록, 컬럼 정의서, 공통키, 갱신주기, 공개 가능 범위
>
> 가능하면 PDF 요약본보다 CSV UTF-8 또는 XLSX 원자료와 컬럼 정의서를 함께 부탁드립니다. 자료마다 기준일·단위·출처시스템·최종 갱신일·담당부서·공개 가능 범위를 포함해 주십시오. 학교 통폐합·교명변경으로 코드가 바뀐 경우 이전 코드·신규 코드·적용일 매핑표도 부탁드립니다.
>
> 학생·교직원의 성명, 주민등록번호, 개인 주소는 요청하지 않습니다. 소수 인원은 기관의 공개 기준에 따라 마스킹하거나 상위 집계단위로 제공해 주셔도 됩니다. 수신 부서가 자료 보유 부서가 아닌 경우 해당 부서로 이송·전달을 부탁드립니다.

## 발송 전 첨부·확인 목록

- [ ] 본문에 1차 필수 요청 8개 표 첨부
- [ ] `CSV UTF-8/XLSX+컬럼 정의서` 요청 명시
- [ ] 기관표준코드·행정구역코드·기준일·갱신주기 포함 명시
- [ ] 개인식별자료 불필요와 소수값 마스킹 허용 명시
- [ ] 담당 부서가 다르면 보유 부서로 이송·전달 요청
- [ ] 공문·업무메일 회신 기한과 수령방법 입력
