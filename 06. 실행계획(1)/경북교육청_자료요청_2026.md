# 경상북도교육청 자료 요청 — 2026년 9월

작성: 2026-09-03
공개자료 우선 재검토: 2026-09-12

---

## 한 장 요약

**공개 원파일과 연도별 운영계획을 먼저 확인한 뒤, 남는 공백만 교육청에 요청합니다.** 현재 핵심 요청 범위는 아래 다섯 가지입니다.

| | 무엇 | 어느 부서 | 무엇이 막혀 있나 |
|---|---|---|---|
| **1** | 다문화 학생 **시군·학교급·학년별 시계열** | 학생생활과 · 행복교육지원과 | 현재 연결본은 도 단위라 **시군 추세 비교 불가** |
| **2** | **한국어 지원 운영교·용량·참여** | 행복교육지원과 | 운영교 명단만으로는 **수요·공급 비교 불가** |
| **3** | 특수교육 **시군·배치유형별** | 유초등교육과 · 학생생활과 | 경북 전체만 있어 **시군 비교 불가** |
| **4** | **공식 학생 수 전망** | 기획예산관 · 정책연구소 | 시뮬레이터에 **공식 기준선이 없음** |
| **5** | **실제 통학버스**(노선·인원·비용) | 행정과 · 교육지원청 · 체육건강과 | 도로망 예상치는 구현했지만 **실제 운영 비교 불가** |

> 초기 24개 항목 대부분은 공개자료로 해결했습니다. 2026-09-12 재검토에서 다문화 시계열·한국어 지원 운영정보를 분리했으며, 세부 근거는 [7~10단계 공개자료와 교육청 요청자료 정리](./7-10단계_공개자료와_교육청요청_정리_2026-09.md)를 보십시오.

## 1. 요청 자료 — 상세

### ① 다문화 학생 시군·학년별 〔학생생활과 · 행복교육지원과〕

**지금 상태** — 교육통계연보로 **경북 전체 13,158명**(2025. 4. 1. 기준)까지는 채웠습니다.
초 6,578 · 중 3,529 · 고 3,051, 유형별로 국내출생 10,957 · 중도입국 455 · 외국인가정 1,746.

**막혀 있는 것** — 현재 대시보드에 연결한 공개 통계는 **시도까지**입니다. 시군을 나눌 수 없어 「어느 시군이 어떻게 변했는가」를 지도에 올리지 못합니다. 다만 교육통계연보·경북교육청 공개 원파일에 시군 표가 있는지 먼저 다시 확인하고, 없는 연도·필드만 요청합니다.

| 항목 | 필요한 값 |
|---|---|
| 구분 | 기준연도, **시군**, 학교급, **학년** |
| 대상 | 국내출생 / 중도입국 / 외국인가정 / 북한이탈 |
| 인원 | 구분별 학생 수 |
| 기간 | **2016~최신** |
| 부가 | **유치원**도 함께 (공개 통계에서 초·중·고만 받았습니다) |

---

### ② 한국어 지원 프로그램 운영교 〔행복교육지원과〕

**지금 상태** — 경북교육청 다문화교육 기본계획·한국어학급 운영계획의 공개 첨부파일에서 당해 지정·운영교 명단을 먼저 확인합니다.

**막혀 있는 것** — 명단만으로는 다문화·한국어 지원이 필요한 지역과 실제 운영 용량이 맞는지 비교할 수 없습니다.

| 항목 | 필요한 값 |
|---|---|
| 기본 | 연도, 학교코드, 사업유형, 지정시작·종료일 |
| 운영 | 운영 학급·강사·시수, 수용 가능 인원 |
| 이용 | 참여 학생 수(소수인원 마스킹, 개인정보 제외) |
| 수요 | 미운영교 지원 필요도를 판단하는 공식 지표 |
| 기간 | **2016~최신**, 가능한 연도부터 동일 스키마 |

---

### ③ 특수교육 시군·배치유형별 〔유초등교육과 · 학생생활과〕

**지금 상태** — 국립특수교육원 「2026 특수교육통계」로 **경북 전체 6,902명**을 채웠습니다.

| 배치 | 학생 | 비율 |
|---|---:|---:|
| 특수학교 | 1,614 | 23.4% |
| 특수학급 | 3,925 | 56.9% |
| 일반학급(완전통합) | 1,348 | 19.5% |
| 특수교육지원센터 | 15 | 0.2% |

**막혀 있는 것** — 이 통계도 **시도까지**입니다.
시군별로는 학교알리미로 특수학교·특수학급만 셀 수 있어, **완전통합 1,348명이 빠진 채**
시군 비교를 하게 됩니다. 화면에도 그 사실을 적어 두었습니다.

| 항목 | 필요한 값 |
|---|---|
| 구분 | 기준연도, **시군**, 학교급 |
| **배치유형** | 특수학교 / 특수학급 / **일반학급(완전통합)** / 특수교육지원센터 |
| 인원 | 배치유형별 학생 수 |
| 장애영역 | 영역별 학생 수 (가능한 범위) |
| 교원 | **특수교사 정원·현원** (공개 통계에는 시도 합계만) |
| 지원 | **통학 지원 인원 · 치료지원 인원** |
| 기간 | **2016~최신** |

---

### ④ 공식 학생 수 전망 〔기획예산관 · 행정과 · 정책연구소〕

**지금 상태** — 시뮬레이터는 교육통계 실적에서 잰 **학년 진급률로 굴린 모의값**입니다.
공식 예측이 아니며, 화면에도 그렇게 적어 두었습니다.
장래**인구**추계(KOSIS, 경북 시·군, 2022~2042)는 이미 쓰고 있으나
**학령인구와 실제 재학생은 범위가 다릅니다.**

**막혀 있는 것** — 시군 단위 학생 수 공식 전망은 **공개본이 없습니다.**

| 항목 | 필요한 값 |
|---|---|
| 기준 | 전망 기준일, **산출 모형**, 전입·전출 반영 여부, 작성일 |
| 범위 | 시군 또는 기관코드, 학교급·학년 |
| 값 | 전망연도별 학생 수 (**2035년 이상까지**) |

> 「어떻게 셈했는가」를 함께 주셔야 합니다. 산출 모형을 모르면 화면에서
> 우리 모의값과 나란히 놓을 수 없습니다.

---

### ⑤ 실제 통학버스 운영 〔행정과 · 교육지원청 · 체육건강과〕

**지금 상태** — 직선거리와 별도로 OpenRouteService 도로망을 따른 예상 거리·시간·도달권을 구현했습니다. **통학구역**과 일반 버스 정류소·노선도 공개자료로 보완할 수 있습니다.

**막혀 있는 것** — 실제 통학 부담(시간·비용·인원)은 공개자료가 없습니다.

| 항목 | 필요한 값 |
|---|---|
| 노선 | 학교코드, 노선·정류장, 운행수단 |
| 부담 | 편도 거리·시간, 탑승 학생 수, 좌석 수 |
| 비용 | 연간 운영비, 학생 1인당 비용 |
| 기간 | 최근 3년 |

## 2. 자료를 주실 때 함께 정해 주실 것

받고 나서는 되돌리기 어렵습니다. **회신 전에** 정해 주시면 좋겠습니다.

1. **소수값 마스킹 기준**
   시군·학년까지 쪼개면 한 칸이 1~2명이 되는 자리가 생깁니다.
   이 대시보드는 개인이 식별될 수 있는 값을 화면에 올리지 않습니다.
   → 「N명 이하 마스킹」의 N을 정해 주시고, 마스킹한 칸은 **0이 아니라 빈칸**으로 주세요.
   **0은 「없다」이고 빈칸은 「모른다」입니다.** 섞이면 화면이 거짓말을 합니다.

2. **기준일**
   4월 1일 기준인지, 학년도 초인지, 공시 시점인지 적어 주세요.
   기준일이 다른 수는 빼서 증감을 말할 수 없습니다.

3. **연도 시계열**
   한 해치만 오면 「늘고 있나 줄고 있나」를 못 봅니다.
   학령인구 감소 대응 대시보드에서는 추이가 값의 절반입니다.

4. **형식**
   CSV 또는 엑셀. **셀 병합·소계 행·색으로만 표시한 구분**은 빼 주세요.
   1행 = 1레코드가 가장 좋습니다.

5. **기관코드**
   학교를 가리킬 때는 **학교알리미 기관코드**로 주세요. 학교명만으로는 같은 이름을 못 가릅니다.

6. **갱신 주기**
   해마다 같은 형식으로 받을 수 있는지 알려 주세요.
   형식이 매년 바뀌면 매년 사람이 손으로 맞춰야 합니다.

## 3. 요청에서 뺀 것 — 공개자료로 해결했습니다

처음 요청 목록(24개 항목) 가운데 아래는 **더 요청하지 않아도 됩니다.**

| 무엇 | 어떻게 해결했나 |
|---|---|
| 학교·학생·학급·교원 현황 | 학교알리미 OpenAPI (917교, 분기 자동 갱신) |
| 유치원 운영·원아 | 유치원알리미 (자동) |
| 학년별 학생·학급 실적 | 교육통계 EDSS (자동) |
| 학령인구·출생아·인구이동 | KOSIS (월 자동) |
| **특수학급 학급 수** | 경북교육청 「2025년 각급학교 일람표」 — 759학급 |
| **다문화 학생 (도 단위)** | 교육통계연보(KEDI) — 13,158명 |
| **특수교육 배치유형 (도 단위)** | 국립특수교육원 「2026 특수교육통계」 — 6,902명 |
| **폐교재산 현황** | **지방교육재정알리미 폐교정보 — 경북 750곳** (아래) |
| 초등 통학구역 | 학구도안내서비스·공공데이터포털 표준데이터 |
| 일반 버스 정류소·노선 | 국토교통부 TAGO API — 실제 통학버스와 구분 |
| 도서관·청소년수련시설 | 공공데이터포털 전국 표준데이터 |
| 산사태 위험도 | 산림청 산사태위험지도 공개 파일 |
| 한국어학급·다문화 당해 운영교 | 경북교육청 연도별 기본계획·운영계획 첨부파일 먼저 확인 |

### 폐교는 공개자료로 화면을 채웠습니다

지방교육재정알리미에서 **경북 폐교 750곳**을 받아 시군·활용현황·폐교연도별로 그렸습니다.

| 활용현황 | 곳 | 비율 |
|---|---:|---:|
| 매각 | 495 | 66.0% |
| 대부 | 108 | 14.4% |
| 자체활용 | 77 | 10.3% |
| **미활용** | **70** | **9.3%** |

> 매각한 폐교는 교육청 재산이 아니므로 활용 정책의 대상이 아닙니다.
> **정책이 다룰 수 있는 것은 255곳**이고, 그중 **70곳이 비어 있습니다.**

**다만 이 자료에는 주소만 있고 위경도가 없어** 지도는 시군 단위로만 그립니다.
학교마다 핀을 찍으려면 주소를 좌표로 바꾸면 되고, 그것은 우리가 할 수 있습니다.
교육청 자료가 있으면 더 좋을 것은 **활용 계약기간·미활용 사유·향후 계획**입니다
(알리미에는 없습니다). 핵심 다섯 자료보다 급하지 않으므로 여유가 될 때 별도로 요청합니다.
