## 0. 이 문서의 목적

현재 전면 지도는 **VWorld WMTS를 배경으로 사용하고 MapLibre GL JS가 화면을 그리는 구조**다.
이미 일반·위성·위성+지명·야간 지도, 2D·3D 지형, 연도 슬라이더, 시군 경계,
폐교 겹쳐 보기, 거리 재기, 학교 검색과 학교급 필터가 구현되어 있다.

이 문서는 다음 세 가지를 한 번에 정리한다.

1. VWorld를 활용해 추가할 수 있는 지도 형태
2. 지도 위에 추가할 수 있는 정책 데이터
3. 지도에서 구현할 수 있는 분석·비교·출력 기능

그리고 아래 우선순위 1~10 각각에 대해 다음을 기록한다.

- 무엇을 구현하는가
- 지금 가진 자료로 가능한가
- 추가로 필요한 데이터·API는 무엇인가
- 사용자가 준비하거나 결정할 것은 무엇인가
- 개발자가 수행할 작업은 무엇인가
- 완료 여부를 어떻게 확인하는가

> 이 문서를 만드는 단계에서는 소스 수정, 커밋, PR, 배포를 하지 않는다.

## 1. 현재 지도 기술과 보유 자료

### 1.1 지도 기술

| 구분 | 현재 구성 | 비고 |
|---|---|---|
| 지도 엔진 | MapLibre GL JS 4.7.1 | 저장소의 `prototype/vendor/`에서 필요할 때 불러옴 |
| 배경지도 | VWorld WMTS | 일반 `Base`, 위성 `Satellite`, 위성+지명 `Satellite+Hybrid`, 야간 `midnight` |
| 지형 | AWS Terrain Tiles | VWorld 배경 위에 3D 고도 표현 |
| 좌표계 | Web Mercator(EPSG:3857) | VWorld WMTS와 학교 좌표가 맞는 구조 |
| 인증 | `VWORLD_API_KEY` | `/api/vworld-key`를 통해 현재 사이트에 전달 |
| 행정경계 | SGIS 경북 시군 경계 가공본 | 앱 안에 구워서 사용 |

MapLibre는 래스터·벡터·GeoJSON·WMS 계열 자료를 지도 위에 겹칠 수 있고,
데이터 기반 색상, 열지도, 군집화, 지형, 애니메이션과 마우스 상호작용을 지원한다.

- MapLibre 공식 예제: <https://maplibre.org/maplibre-gl-js/docs/examples/>
- MapLibre 플러그인 목록: <https://maplibre.org/maplibre-gl-js/docs/plugins/>
- VWorld 공식 활용 예제 저장소: <https://github.com/V-world/Utilization-Model>
- SGIS OpenAPI 안내: <https://sgis.mods.go.kr/developer/html/newOpenApi/api/intro.html>

| 자료 | 기간·기준 | 활용 가능 범위 |

| 폐교 현황 | 2026년 확보 자료 기준 | 폐교 위치와 활용 상태 |
| 특수교육 배치·학급 | 2025·2026년 자료 혼재 | 출처·기준시점을 구분해 제한적으로 활용 |

## 2. 추가할 수 있는 지도 형태

지도 형태는 `VWorld가 직접 제공하는 배경`과 `기존 VWorld 배경을 가공한 표현`을
구분해야 한다.

| 지도 형태 | 만드는 방법 | 용도 | 판단 |
|---|---|---|---|
| 일반 | VWorld `Base` | 기본 탐색 | 구현됨 |
| 위성 | VWorld `Satellite` | 실제 지형·건물 확인 | 구현됨 |
| 위성+지명 | 위성 위에 VWorld `Hybrid` 중첩 | 영상과 지명 동시 확인 | 구현됨 |
| 야간 | VWorld `midnight` | 어두운 발표 화면 | 구현됨 |
| 회색 | VWorld `gray` WMTS 후보 | 데이터 색상 강조 | **가장 먼저 추가 권장** |
| 데이터 집중형 | 회색 지도의 밝기·채도를 더 낮추고 데이터 대비 강화 | 분석·발표 | 맞춤 스타일 |
| 지형·음영 | 2D hillshade 또는 현재 DEM 음영 | 산간 통학 여건 설명 | MapLibre 레이어 |
| 행정구역 강조 | 최소 배경에 시군·읍면동 경계를 강조 | 정책 비교 | 경계 데이터 필요 |
| 고대비 | 명도차·선 굵기·라벨 크기를 강화 | 접근성·대형 화면 | 맞춤 스타일 |
| 인쇄 전용 | 조작 버튼을 숨기고 범례·출처를 고정 | A4 보고서 | 별도 인쇄 CSS |

> 회색 지도 외의 `데이터 집중형·고대비·인쇄 전용`은 VWorld가 새로운 지도 상품을
> 하나 더 제공하는 개념이 아니다. VWorld 배경의 투명도·명도와 MapLibre 데이터
> 레이어의 색·두께를 조절해 만드는 앱 전용 보기 방식이다.

- 학교급·설립 유형·본교/분교 구분

- 폐교 위치·폐교연도·활용 상태
- 특수학교·특수학급 위치와 접근 취약지역
- 정책 시나리오별 필요한 학급·학교 규모

### 3.2 인구·생활 데이터

- 0~5세, 6~11세, 12~14세, 15~17세 인구
- 출생아 수 변화
- 읍면동 또는 격자별 인구 밀도
- 인구감소지역·생활인구
- 대중교통·정류장·통학버스
- 돌봄시설·도서관·청소년시설·의료·복지시설

### 3.3 지형·안전 데이터

- 고도·경사·산지 장벽
- 도로망과 실제 이동시간
- 침수·산사태·급경사지 등 재난 취약정보
- 울릉 등 도서지역의 해상 이동 특성

### 3.4 뉴스 데이터

- 시군별 최근 기사 언급량

뉴스 데이터는 학생 수 변화의 원인이나 예측값이 아니라 **정책 관심 신호**로 표시한다.
뉴스량과 학생 수가 함께 변하더라도 인과관계라고 설명하지 않는다.

# 5. 우선순위 1~10 상세 준비계획

## 1단계. 회색 지도 추가

### 구현 내용

현재 `일반·위성·위성+지명·야간` 옆에 `회색` 배경을 추가한다. 학교급 색상,
증감률 색상과 시군 경계가 배경에 묻히지 않도록 하는 분석용 기본 배경이다.

### 필요한 것

- 현재 사용 중인 `VWORLD_API_KEY`
- VWorld WMTS `gray` 레이어 응답 확인
- Preview·Production·로컬 도메인의 VWorld 허용 여부 확인
- 기존 MapLibre 래스터 소스 교체 로직 재사용

### 사용자가 할 일

- [ ] VWorld 개발자센터에서 현재 키의 허용 도메인 확인
- [ ] 운영 주소와 미리보기 주소에서 회색 지도를 쓸 것인지 결정
- [ ] 회색 지도를 기본값으로 할지, 일반 지도를 계속 기본값으로 둘지 결정

권장 기본값은 `일반`, 데이터 분석 시 권장 배경은 `회색`이다.

### 개발 작업

- `MV_BASES`에 `gray` 항목 추가
- 타일 확장자와 응답 형식 확인
- 선택 상태·야간 모드·3D 지형과 조합 검사
- 키가 없거나 타일 응답이 실패하면 기존 일반 지도 또는 배경 없음 상태로 안전하게 전환

### 완료 기준

- 다섯 배경을 바꿔도 학교·폐교·경계·거리 표시가 유지됨
- 지도 이동·확대 후에도 선택 배경이 유지됨
- 모바일과 전체화면에서 배경 선택 단추가 넘치지 않음

### 예상 부담

낮음. 새 데이터 수집은 없다.

## 2단계. 학교별 학생 수 증감 레이어

### 구현 내용

원 크기는 기준연도 학생 수, 색은 비교연도 대비 증감률로 표현한다. 예를 들어
`2016→2025`, `2025→2026`, `2026→모의연도`처럼 비교 기준을 선택한다.

### 필요한 것

- `EDSS_SCHOOL`·`EDSS_SCHOOL_YEARS`: 2016~2025 학교별 실적
- `SCHOOL_RAW`: 2026 학교알리미 학교별 공시
- 학교코드 또는 학교명 기반 연도 간 연결표
- 폐교·신설·교명변경 학교 처리 규칙

### 사용자가 할 일

- [ ] 첫 화면의 기본 비교기간 선택: 권장 `2016→2025`
- [ ] 증감률 등급 선택: 권장 `20% 이상 감소 / 10~20% 감소 / 10% 미만 변화 / 증가`
- [ ] 폐교·신설 학교를 별도 기호로 보여줄지 결정
- [ ] `학생 수 0명`과 `자료 없음`을 반드시 다르게 보여주는 원칙 승인

### 개발 작업

- 학교별 기준연도·비교연도 값을 연결
- 절대 증감과 증감률 계산
- MapLibre 원·기호 레이어로 전환해 라벨 겹침 최소화
- 범례, 마우스오버 수치, 클릭 상세 추이 추가
- 데이터가 한쪽 연도에만 존재하는 학교는 `신설·폐교·연결 안 됨`으로 분리

### 완료 기준

- 표시된 증감의 표본을 원자료와 대조해 일치함
- 지도 범례만 읽어도 원 크기와 색의 뜻을 알 수 있음
- `0`과 `자료 없음`이 혼동되지 않음
- 학교급·시군·연도 필터를 바꾸면 즉시 다시 계산됨

### 예상 부담

중간. 추가 API 신청은 없지만 학교 연결 품질검사가 중요하다.

## 3단계. 2016년과 2025년 좌우 비교

### 구현 내용

하나의 화면을 세로 손잡이로 나누어 왼쪽은 2016년, 오른쪽은 2025년으로 표시한다.
두 지도의 중심·배율·기울기는 항상 함께 움직인다.

### 필요한 것

- 2단계의 학교별 증감·연도 표시 기능
- MapLibre 비교 플러그인 또는 두 지도 캔버스 동기화 코드
- 동일 학교 연결 결과

### 사용자가 할 일

- [ ] 기본 비교연도를 `2016 / 2025`로 확정
- [ ] 비교연도를 사용자가 바꿀 수 있게 할지 결정
- [ ] 왼쪽·오른쪽에 표시할 설명 문구 확정: `실적`과 `공시/모의`를 명확히 구분

### 개발 작업

- 두 지도 생성 또는 하나의 지도에서 클리핑 비교 구현
- 이동·줌·회전 동기화
- 손잡이에 연도 라벨 표시
- 저사양 기기에서는 2분할 대신 전환 단추로 내려가는 대체 동작 제공

### 완료 기준

- 손잡이를 움직일 때 같은 위치의 학교가 정확히 겹침
- 두 지도를 따로 움직여 위치가 어긋나지 않음
- 모바일 터치로 손잡이를 조작할 수 있음
- 키보드로도 비교 위치를 옮길 수 있음

### 예상 부담

중간. MapLibre 공식 플러그인 목록에는 좌우 스와이프 비교 기능이 안내되어 있다.

## 4단계. 현재와 시뮬레이션 결과 비교

### 구현 내용

보낸다. 현재와 모의결과를 나란히 보거나 전환해서 비교한다.

### 필요한 것

- 시뮬레이터의 선택 상태와 계산 결과
- 학교별 또는 시군별 모의값
- `학교 수 유지`, `학급당 N명`, `학년당 N학급`의 의미 구분
- 실적과 모의값을 구분하는 공통 데이터 구조

### 사용자가 할 일

- [ ] 지도에는 시군 규모까지만 표현할지 학교 규모까지 표현할지 결정
- [ ] 학교 단위 결과가 실제 폐교·신설 결정으로 오해되지 않도록 안내문 승인
- [ ] 기본 시나리오와 모의연도 결정

권장 문구는 `정책 조건을 적용한 필요 규모이며 실제 학교 조정 계획이 아닙니다`이다.

### 개발 작업

- 시뮬레이터와 지도 사이의 상태 전달 구조 작성
- 현재/모의 레이어 색과 기호 분리
- 모의연도 변경 시 지도·범례·통계 동기화
- 공유 URL에 시나리오 조건 포함

### 완료 기준

- 시뮬레이터와 지도의 학생·학급·학교 합계가 일치함
- 모의연도와 조건 변경이 지도에 즉시 반영됨
- 모든 모의값에 `공식 예측 아님` 표시가 붙음

### 예상 부담

중간. 추가 API는 없지만 화면 간 상태 연결과 문구 검증이 필요하다.

## 7단계. 도로 기준 통학시간·접근권

### 구현 내용

> 도로 경로와 이동시간이 계산되지 않으므로 별도의 경로탐색 API 또는 도로망 분석이 필요하다.

### 개발 전에 보완할 환경변수 문서

현재 `.dev.vars.example`에는 실제 값이 아닌 `VWORLD_API_KEY` 자리표시자가 들어 있다.
인수자는 아래 형식으로 본인의 도메인 제한 키를 로컬 비밀 파일과 배포 환경에 등록한다.
실제 키 값은 저장소에 넣지 않는다.

```text
VWORLD_API_KEY=your_domain_restricted_vworld_key
```

도로 경로 API를 도입하면 제공기관에 맞는 별도 환경변수를 추가한다. 경로 API 키는
VWorld처럼 브라우저로 내려보내지 않고 Cloudflare 서버 함수에서만 사용하도록 한다.

5. 여러 학교 비교함
6. 별도 A4 정책지도 출력 철회 · 공통 현재 화면 인쇄 사용

이 구간은 새로운 기관자료를 기다리지 않고 진행할 수 있다. 다만 2~4단계에서
학교 연결과 실적/모의 구분을 검증해야 한다.

### 2차 — 외부 API가 필요한 범위

7. 도로 기준 통학시간·접근권
8. 학령기 연령별 인구 밀도

API 선정, 발급, 호출 제한, 캐시와 공개 조건을 먼저 확인한다.

### 3차 — 교육청·유관기관 자료가 필요한 범위

9. 교육권역·학구·통학버스
10. 재난·생활시설 복합 분석

자료가 없는 상태에서 화면 모양부터 만들지 않는다. 출처·기준일·갱신 담당이
확정된 레이어만 추가한다.

---

## 8. 단계별 공통 검증 원칙

모든 단계는 다음 조건을 통과해야 한다.

- 기존 일반·위성·위성+지명·야간 지도 기능을 잃지 않음
- 2D·3D 전환, 회전·기울임, 확대·축소가 계속 작동함
- 학교 검색·학교급 필터·연도 슬라이더가 새 레이어와 동기화됨
- 시군 경계·폐교·거리 재기를 함께 켰을 때 충돌하지 않음
- 데이터가 없을 때 0으로 표시하지 않음
- 실적·공시·모의값을 색과 문구로 구분함
- 기준일과 출처를 지도와 출력물에 표시함
- 모바일 터치, 키보드, 큰 화면에서 조작 가능함
- 외부 API 장애 시 기존 지도와 저장된 데이터는 계속 보임
- 실제 API 키가 HTML·JavaScript·Markdown·Git 로그에 들어가지 않음

## 9. 구현 범위를 정할 때의 최종 권고

지도 배경 자체를 많이 늘리는 재미도 있지만, 사용자가 지도 종류와 데이터 레이어를
혼동하지 않게 해야 한다. 화면 구성은 다음처럼 나누는 것이 좋다.

```text
배경지도
  일반 | 회색 | 위성 | 위성+지명 | 야간

표현 방식
  2D | 지형·음영 | 3D

교육 데이터
  학생 수 변화 | 학급당 학생 수 | 폐교 | 특수교육 | 시뮬레이션

지역 여건
  연령별 인구 | 통학시간 | 학구·버스 | 생활시설 | 재난

비교·도구
  연도 비교 | 학교 비교함 | 거리 재기 | 공유 | 출력
```

먼저 완성할 핵심 조합은 다음과 같다.

> **회색 VWorld 지도 + 학교별 학생 수 변화 + 2016/2025 비교 + 현재·미래 비교**

이 조합은 현재 보유한 자료를 최대한 활용하면서도 학령인구 감소를 지도에서
직관적으로 설명할 수 있다. 실제 도로 통학시간과 학구·통학버스는 정책 가치가
높지만 외부 키와 내부자료가 필요하므로 2차 이후로 분리한다.
