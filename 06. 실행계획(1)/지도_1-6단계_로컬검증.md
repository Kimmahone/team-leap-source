# 지도 1~6단계 구현과 로컬 확인

2026-09-12 · 로컬 검증 기록

## 확인 주소

실행 중인 로컬 미리보기: <http://127.0.0.1:8770/06.%20%EC%8B%A4%ED%96%89%EA%B3%84%ED%9A%8D(1)/prototype/index.html#map>

이 임시 서버는 기존 운영 사이트의 VWorld 키 제공 API를 읽어 지도에 연결한다. API 키를 파일에 저장하지 않는다. AI 등 다른 API는 이 지도 전용 미리보기에서 연결하지 않는다. 서버를 종료하면 해당 주소는 사용할 수 없다.

## 확인 순서

1. 배경에서 **회색** 선택. 일반·위성·위성+지명·야간으로도 전환한다.
2. 지도 위 **비교**를 눌러 **학생 수 변화**를 선택한다. 2016년/2025년이 기본이며 두 연도를 바꿀 수 있다. 멀리서는 시군별 합계, 확대하면 학교별 실제 수치가 지도 위에 직접 표시된다.
3. **과거·현재 비교**를 선택한다. 하단 슬라이더를 움직여 같은 위치를 두 연도로 비교한다. 양쪽 연도와 학생 수 합계가 표시되고 슬라이더는 키보드 방향키도 지원한다.
4. **현재·미래 비교 → 조건 바꾸기**에서 학생수 시뮬레이터로 이동한다. 지역·학교급·연도·산출 기준을 바꾼 뒤 지도로 돌아오면 선택 조건을 다시 가져온다. **현재 조건 적용**으로도 새로 가져온다.
5. 학교를 눌러 상세 카드의 **학교 비교함에 담기**를 선택한다. 비교함은 지도 위 비교 패널 안에 있으며 최대 5곳까지 담는다. **학교 비교하기**에서는 기준·비교연도 학생 수, 증감, 2026년 학급·명/학급, 2016~2026년 추이를 보고 Excel용 CSV로 저장할 수 있다.
6. 별도 **A4 정책지도 출력은 제거했다.** 지도 화면에는 이미 전체 화면 인쇄 기능이 있고, 별도 출력물이 중복되면서 화면과 다른 디자인을 만들기 때문이다.

## 실제 데이터 처리

- 지도 학교 풀 1,539곳 중 기본 2016/2025 양쪽 자료가 연결된 학교는 검증 시점 879곳이다. 유치원·특수학교 및 연결되지 않은 학교까지 전체 연도 자료가 있다고 가정하지 않는다.
- 자료 없음과 0명은 다르게 처리한다. 한쪽 자료가 없으면 증감률을 계산하지 않는다. 기준 학생 수가 0명이면 증감 인원만 표시한다.
- 과거 위치·모든 폐교를 복원한 지도가 아니라 현재 학교 목록과 연결된 과거 실적 비교다. 결측을 신설·폐교로 단정하지 않는다.
- 시뮬레이터 지도는 `simExportRows`의 시군별 학생·학급·학교 결과를 재사용한다. 미래 학교별 배치 좌표를 생성하지 않는다.
- 시군별 학급·학교 수는 각각 반올림되는 계산이므로 시군 합산 결과라는 범위를 표시한다.
- 학교 비교함은 필터를 바꿔도 유지한다. 비교함에서 직접 빼거나 비우기로 해제한다.

## 회색 지도 확인에서 발견한 변경

VWorld 공식 과거 예제에는 `gray`가 있지만 실제 WMTS 응답은 유효한 레이어를 `Base, midnight, Hybrid, Satellite, white`로 안내하며 `gray`를 거절했다. 따라서 현재 회색 보기는 `Base`에 MapLibre 채도 -1과 불투명도 0.75를 적용했다. 학교·통계 레이어 색상은 그대로다. 키를 새로 발급할 필요는 없다.

## 파일

- `prototype/index.html`: 회색 배경 설정, 왼쪽 요약 폭·간격 조정, 기능 파일 연결
- `prototype/assets/map-policy.js`: 지도 위 비교 도구·학교 비교함·시뮬레이터 연결
- `prototype/assets/map-policy.css`: 떠 있는 비교 패널·수치 딱지·슬라이더·학교 비교표
- `.dev.vars.example`: 실제 값 없는 `VWORLD_API_KEY` 예시
- `prototype/test.js`: 회색 배경이 추가된 기대값 반영

기존 `사이트 굽기.command`는 `prototype/assets`를 배포 묶음에 포함하므로 새 기능 파일도 같은 경로를 따른다. 이번에는 굽기·원격 반영을 실행하지 않았다.

## 검증 및 범위

- 기존 대시보드 검사 731개 통과.
- Chrome에서 실제 VWorld 타일 PNG 응답과 회색 표시 확인.
- 비교 모드 변경 후 오른쪽 모의 데이터가 갱신되는지 확인.
- 학교 선택 5곳 제한, 결측·0명·증감 경계값 확인.
- 기성초등학교 2016년 28명 → 2025년 16명, -12명 표본 확인.
- 초등학교 전체 2030년 학교·학급 유지 조건에서 101,176 → 68,755명, 학급 6,021개·학교 474교 유지 확인.
- 390px 터치 화면에서 컨트롤 표시와 JavaScript 오류 없음 확인.
- 왼쪽 요약은 배경 → 보기 → 연도 → 통계 → 학교 찾기 순서를 유지하며, 비교 도구는 지도 위에서 필요할 때만 연다.
- 광역 3D는 산지 과장값 1.5를 유지하고, 근접 확대에서는 고도면을 자동으로 꺼 도로·운동장·논밭 왜곡을 줄인다.

아직 미검증: 다른 기관망에서 VWorld 도메인 제한. 7~10단계는 구현 대상에 포함하지 않았다.
