# 통학거리를 «직선»에서 «실제 도로»로 — 키 받는 법과 붙이는 법

작성 2026-09-20 · 선생님이 직접 하실 부분과 제가 할 부분을 갈라 적었습니다.

---

## 0. 왜 바꾸나

지금은 `haversineKm()` 으로 **직선거리**를 씁니다. 두 점 사이를 자로 잰 값이라
산과 강을 무시합니다. 경북처럼 산지가 많은 곳에서는 실제와 크게 어긋납니다.

| | 지금 (직선) | 바꾸면 (도로) |
|---|---|---|
| 울릉 → 가장 가까운 특수학교 | 210km | 배편 포함이라 **길 자체가 없음**을 밝혀야 함 |
| 울진 → 안동영명학교 | 74km | 실제 도로는 이보다 **1.3~1.6배**로 나오는 것이 보통 |

숫자가 정확해지는 것보다 **이야기가 달라지는 것**이 큽니다.
「직선 74km」는 멀다는 느낌만 주지만, 「도로 112km · 차로 1시간 47분」은
통학이 가능한지 불가능한지를 바로 말해 줍니다.

---

## 1. 어떤 API 를 쓰나 — 카카오모빌리티

| | |
|---|---|
| 이름 | **카카오모빌리티 길찾기 API** (Directions) |
| 주소 | https://developers.kakaomobility.com/product/naviapi.html |
| 무료 한도 | **하루 10만 건** |
| 우리가 쓸 양 | 한 번 구울 때 **약 5천 건** (한도의 5%) |
| 돈 | 무료 범위 안 |

### 왜 이것인가

- **무료 한도가 압도적**입니다. TMAP 도 되지만 한도가 훨씬 적습니다.
- 우리는 **미리 구워 두고 화면에서는 읽기만** 하므로, 학생이 많이 들어와도
  호출이 늘지 않습니다. 하루 10만 건은 사실상 무제한입니다.
- 응답에 **거리(m)와 예상 시간(초)** 이 함께 옵니다. 시간이 더 설득력 있습니다.

### 카카오맵 API 와 다릅니다

이미 다른 앱에서 쓰시는 **카카오맵(지도·좌표 변환)** 키와는 **별개 서비스**입니다.
개발자 콘솔도 다릅니다. 아래 2번을 그대로 따라 주세요.

## 2. 선생님이 하실 일 — 키 받기 (10분)

### ① 카카오디벨로퍼스에서 앱 만들기

1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인
2. 위쪽 **내 애플리케이션** → **애플리케이션 추가하기**
3. 앱 이름 `TEAM LEAP`, 사업자명은 `경상북도교육청` 정도로 적고 저장

### ② REST API 키 복사

1. 만든 앱을 열면 **앱 키** 항목에 네 가지가 보입니다
2. 그중 **REST API 키**를 복사합니다 (JavaScript 키 아닙니다)

> 이 키는 **비밀입니다.** 카카오톡·메일로 보내지 마시고,
> 아래 ④ 처럼 파일에 적어 두시면 제가 그 파일을 읽어 쓰겠습니다.
> 저장소에는 올라가지 않도록 `.gitignore` 에 이미 걸려 있습니다.

### ③ 카카오모빌리티 이용 신청

1. https://developers.kakaomobility.com 접속 → 오른쪽 위 **로그인**
   (②에서 쓴 **같은 카카오 계정**)
2. **길찾기 API** 를 고르고 **이용 신청**
3. ①에서 만든 앱을 고릅니다 — 그래야 그 앱의 REST API 키로 부를 수 있습니다

> 승인은 보통 즉시 또는 하루 안에 납니다.
> 승인 전에 부르면 `401` 이 옵니다 — 키가 틀린 게 아니라 아직 안 열린 것입니다.

### ④ 키를 적어 두실 곳

```
1. 깃허브 탑재 (배포)/open api/인증키.txt
```

이 파일에 아래 한 줄을 **더해** 주세요 (기존 내용은 두시고).

```
KAKAO_MOBILITY_REST_KEY=여기에_붙여넣기
```

## 3. 제가 할 일 — 구워서 심기

키가 들어오면 제가 아래를 만듭니다. 선생님이 하실 것은 없습니다.

### ① 굽는 스크립트

`open api/bake-road-distance.mjs` 를 새로 만듭니다. 기존 굽기 도구들과 같은 자리·같은 꼴입니다.

무엇을 재나:

| 쓰임 | 구간 수 |
|---|---:|
| 시군 22곳 → 특수학교 8곳 (접근성) | 176 |
| 소규모 특수학급 87곳 → 가장 가까운 같은 급 학교 3곳 | 261 |
| 초·중·고 917곳 → 가장 가까운 같은 급 학교 3곳 | 2,751 |
| 폐교 활용 대상 255곳 → 가장 가까운 학교 | 255 |
| **합계** | **약 3,400** |

하루 한도 10만 건의 **3.4%** 입니다. 실패한 구간만 다시 부르는 장치를 넣어
두 번 구워도 여유가 큽니다.

### ② 심는 자리

`index.html` 의 데이터 줄에 `ROAD_KM` 한 덩이를 심습니다.
지금 `haversineKm` 을 쓰는 자리에서 **도로 값이 있으면 그것을, 없으면 직선을**
쓰도록 바꿉니다. 도로 값이 없는 구간(섬 등)은 화면에 그렇게 적습니다.

### ③ 화면에 적는 말

숫자만 바꾸면 안 됩니다. **무엇을 잰 값인지**가 달라지므로 문구도 바꿉니다.

- 지금: 「울진 74km (직선거리)」
- 바꾼 뒤: 「울진 **112km · 차로 1시간 47분** (도로 기준)」
- 길이 없으면: 「울릉 — **육로 없음**(배편) · 직선 210km」

### ④ 한계도 함께 적습니다

- **승용차 기준**입니다. 통학버스·대중교통과 다릅니다.
- **평시 기준**이고 눈·비·공사는 반영되지 않습니다.
- 잰 날짜를 함께 적습니다. 길은 새로 나기도 합니다.

## 4. 순서 정리

| | 누가 | 무엇 |
|---|---|---|
| 1 | **선생님** | 카카오디벨로퍼스 앱 만들고 REST API 키 복사 |
| 2 | **선생님** | 카카오모빌리티에서 길찾기 API 이용 신청 |
| 3 | **선생님** | `open api/인증키.txt` 에 키 한 줄 추가 |
| 4 | 제가 | 굽는 스크립트 만들고 3,400구간 재기 |
| 5 | 제가 | 화면 붙이기 · 문구 고치기 · 검사 추가 |
| 6 | 함께 | 몇 구간을 카카오맵에서 손으로 확인 |

6번을 꼭 합니다. **자동으로 받은 값이 맞는지 사람이 몇 개는 눈으로 봐야**
합니다. 좌표가 학교 정문이 아니라 뒷산에 찍혀 있으면 엉뚱한 길이 나옵니다.

## 5. 막히면

- 이용 신청이 승인됐는데 `401` → 앱 키를 JavaScript 키로 잘못 복사한 경우가 많습니다
- `403` → 길찾기 API 이용 신청이 그 앱에 안 걸려 있습니다
- 키를 실수로 공개했다면 → 카카오디벨로퍼스에서 **키 재발급**을 누르면 옛 키가 죽습니다
