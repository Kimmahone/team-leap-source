# 학교 마스터 테이블 스키마 (T2)

프로토타입의 지도·시뮬레이터가 **이 한 장의 표**를 읽습니다. 컬럼 이름과 값의 형태를 여기 정의된 대로 맞춰 주세요.

- 파일: `data/master/schools.csv` (수집 후 생성) / 빈 양식은 `schools.template.csv`
- 1행 = 1학교 = 1연도. **같은 학교의 2016년과 2026년은 2행**입니다.
- 인코딩: UTF-8 (BOM 포함). 엑셀에서 열 때 한글이 깨지면 BOM이 빠진 것입니다.

## 파생 컬럼 계산 기준 (잠정)

구성안이 `과밀 / 적정 / 과소`, `대규모 / 소규모`로 색상 구분을 요구하므로 기준이 필요합니다. **아직 교육청 공식 기준을 확보하지 못했으므로 아래는 잠정값**이며, 프로토타입에서 사용자가 조정할 수 있게 만듭니다.

### density_class (학급당 학생수 기준)

| 구분 | 초등 | 중등·고등 |
|---|---|---|
| 과소 | < 15명 | < 18명 |
| 적정 | 15 ~ 25명 | 18 ~ 28명 |
| 과밀 | > 25명 | > 28명 |

### size_class (학교 학생수 기준)

| 구분 | 초등 | 중등 | 고등 |
|---|---|---|---|
| 소규모 | ≤ 60명 | ≤ 60명 | ≤ 100명 |
| 대규모 | 그 외 | 그 외 | 그 외 |

> 「소규모학교」 기준은 시도별로 다르고 통폐합 정책과 직결되는 민감한 수치입니다. **경상북도교육청 기준을 확보하기 전까지 이 값을 대외 자료에 확정 수치처럼 쓰지 마세요.** 화면에도 "잠정 기준" 표기를 넣었습니다.

## 데이터 결합 순서

```
① D3 전국초중등학교위치표준데이터 (CSV)
   → 경상북도만 필터 → 학교 뼈대 생성 (2~6, 12, 14, 15번 컬럼)

② D4 주소 파싱
   → 지번주소에서 읍/면/동 추출 → area_type, emd_code 채움 (7~9번)

③ D2 학교알리미 학생·학급 현황
   → 학교명+시군으로 ①과 매칭 → 16~21번 채움
   ※ 매칭 실패분은 반드시 별도 목록으로 남기고 수기 확인

④ 파생 계산
   → 24~26번 산출

⑤ 검증
   → 시군별 합계를 KESS 시군구 통계와 대조. 오차 1% 이내면 통과
```

**③의 매칭 실패가 반드시 발생합니다.** (분교장, 통폐합, 교명 변경, 괄호 표기 차이) 실패 목록을 `data/processed/match_failed.csv`로 남기고 수기 처리한 내역을 기록하세요.

## 최소 산출물

전체가 안 되면 **아래 조합만으로도 프로토타입은 돌아갑니다.**

```
year, school_id, school_name, level, sigungu_code, sigungu_name,
area_type, lat, lon, students_total, classes_total, source
```

12개 컬럼. D3 + D2 학교급 총계만 있으면 됩니다. 학년별(17번)은 시뮬레이터 정밀도를 위한 것이고, 지도 화면은 위 12개로 완성됩니다.
