# 다문화 학생 수 — 자료 형식과 채우는 법

빈 양식: `multicultural.template.csv`
채운 파일: `multicultural-<연도>.csv` 로 저장
심는 스크립트: `open api/bake-multicultural.mjs`

> **아직 자료가 없습니다.** 이 양식만 만들어 두었습니다.
> CSV를 채워 넣으면 화면의 「다문화 학생」 칸이 «자료 없음»에서 실제 수치로 바뀝니다.

---

## 1. 자동으로 받을 수 있는 길이 없습니다 (2026. 9. 3. 확인)

| 경로 | 결과 |
|---|---|
| **학교알리미 OpenAPI** | 공시 항목 29종에 다문화 없음 ❌ |
| **KOSIS** | 경북 도 단위 통계 **없음** ❌ — 시도가 각자 올리는 구조인데 경북은 올리지 않았습니다.<br>경북에서는 **경산시·상주시** 두 곳만 자체 통계연보로 올려 두었습니다 (22곳 중 2곳) |
| **EDSS 교육통계 OpenAPI** | 승인된 7개 서비스에 다문화 없음 ❌ |
| **KOSIS 전국 표** | `154/DT_MOGE_3021100046` 「초·중등학교 재학 국제결혼가정 자녀 및 외국인가정 자녀수」<br>초·중·고 × 국내출생/중도입국/외국인가정 시계열이 있으나 **전국 단위뿐**(시도 분류 없음) ⚠️ |

→ **사람이 받아서 CSV로 정리하는 수밖에 없습니다.** 특수학급 자료와 같은 방식입니다.

## 2. 어디서 받나

1. **교육통계서비스(KESS)** — `kess.kedi.re.kr` → 주제별 통계 → 다문화교육
   시도별 다문화 학생 수를 엑셀로 내려받을 수 있습니다. **매년 4월 1일 기준, 8월 말~9월 공표.**
   → `region` 에 `경북` 을 적어 도 단위로 채웁니다.
2. **경상북도교육청** — 시군·학년까지 필요할 때.
   이미 자료요청 목록 우선순위 2번에 올려 두었습니다
   (`경북교육청_내부자료_요청목록.md`).
   → `region` 에 시군 이름(`포항`, `울릉` …)을 적습니다.

두 자료를 **섞지 마세요.** 한 CSV에는 한 출처만 담습니다.

---

## 3. 컬럼

| 컬럼 | 형 | 값 | 설명 |
|---|---|---|---|
| `year` | 정수 | 2025 | 조사 기준 연도 |
| `region` | 문자 | `경북` 또는 시군 짧은 이름 | 도 단위면 `경북`, 시군 단위면 `포항`·`울릉` … (앱의 `SIGUNGU` 와 일치) |
| `level` | 코드 | `초` `중` `고` | 학교급 |
| `type` | 코드 | `국내출생` `중도입국` `외국인가정` | 교육기본통계의 분류를 그대로 씁니다 |
| `students` | 정수 | | 학생 수 |

- 인코딩: **UTF-8 (BOM 포함)**
- `계`·`합계` 행은 **넣지 마세요.** 화면에서 더해 씁니다 (두 번 세는 것을 막습니다).
- 값이 없는 칸은 **0이 아니라 비워 둡니다.** 0은 «없다»는 뜻이고, 빈칸은 «모른다»는 뜻입니다.

---

## 4. 심는 법

```bash
node "open api/bake-multicultural.mjs"
node "06. 실행계획(1)/prototype/test.js"
```

CSV가 없으면 아무 일도 하지 않고, 화면은 지금처럼 「자료가 없습니다」를 유지합니다.

---

## 5. 소수값 주의

시군·학년까지 쪼개면 한 칸이 1~2명이 되는 경우가 생깁니다.
**개인이 식별될 수 있는 값은 화면에 올리지 않습니다.** 도교육청에 자료를 요청할 때
마스킹 기준을 미리 합의하고, 마스킹된 칸은 **비워서** 받으세요.

## 6. 표현

다문화 학생은 **「지원 대상」이 아니라 「학생」**입니다.
화면 문구를 고를 때 결핍이나 문제로 읽히지 않게 합니다.
유형 구분(중도입국 등)은 지원 설계에 필요한 만큼만 씁니다.
