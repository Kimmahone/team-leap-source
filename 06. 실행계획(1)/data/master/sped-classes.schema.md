# 특수학급 학급 수 — 자료 형식과 만드는 법

파일: `sped-classes-2025.csv`
심는 스크립트: `open api/bake-sped-classes.mjs`

---

## 왜 이 파일이 따로 있나

특수학급의 **학급 수**를 주는 공개 API가 없습니다.

| 자료 | 특수학급 학생 수 | 특수학급 **학급 수** |
|---|---|---|
| 학교알리미 OpenAPI | ✅ (`sped`) | ❌ |
| EDSS 교육통계 | 학교·학년별 학생·학급은 있으나 **특수학급 구분 없음** | ❌ |
| **각급학교 일람표** (도교육청) | ✅ | ✅ |

그래서 해마다 나오는 일람표 엑셀에서 뽑아 CSV로 정리해 둡니다.
CI에 엑셀 해석기를 들이지 않으려고, **엑셀 → CSV 는 사람이 한 해에 한 번** 합니다.

---

## 컬럼

| 컬럼 | 형 | 설명 |
|---|---|---|
| `year` | 정수 | 조사 기준 연도 (예: 2025) |
| `level` | 코드 | `초` / `중` / `고` |
| `sigungu` | 문자 | 시군 짧은 이름. **`sigungu.json` 및 앱의 `SIGUNGU` 와 반드시 일치** (예: `포항`, `울릉`) |
| `schools` | 정수 | 그 시군·학교급의 학교 수 |
| `schools_with_sped_class` | 정수 | 그중 특수학급을 **둔** 학교 수 |
| `sped_classes` | 정수 | 특수학급 **학급** 수 |
| `sped_students` | 정수 | 특수학급 **학생** 수 |

- 인코딩: **UTF-8 (BOM 포함)**
- 1행 = 1시군 × 1학교급. 22시군 × 3학교급 = **66행**
- 집계값만 담습니다. **학교별 값은 담지 않습니다** — 개인이 식별될 여지를 만들지 않기 위해서입니다.

---

## 새 해 자료로 갱신하는 법

1. 경상북도교육청에서 **「○○○○년 각급학교 일람표(○○○○. 4. 1. 기준)」** 엑셀을 받습니다.
2. 시트별로 아래 열에서 값을 읽습니다. **해마다 열 위치가 바뀔 수 있으니 머리글을 먼저 확인하세요.**

   | 시트 | 시군 | 학교명 | 특수학급 **학급수** | 특수학급 **학생수(계)** |
   |---|---|---|---|---|
   | 초등학교 | `A`(교육청명) | `C` | `AB` (28번째) | `AT` (46번째) |
   | 중학교 | `A`(교육청) | `C` | `Y` (25번째) | `BB` (54번째) |
   | 고등학교 | `B`(시군) | `D` | `Z` (26번째) | `AK` (37번째) |

   > 위 표는 **2025년 파일 기준**입니다(0부터 세는 열 번호로는 초 27/45, 중 24/53, 고 25/36).
   > 머리글은 「학급구분별 학급수 → 특수학급」, 「학급구분별 학생수 → 특수학급」 아래에 있습니다.

3. 시군·학교급으로 합산해 위 컬럼 형식의 CSV를 만듭니다.
   시군 이름은 **「시」「군」을 떼어** 앱과 맞춥니다 (`포항시` → `포항`).
4. 파일 이름을 `sped-classes-<연도>.csv` 로 두고, `bake-sped-classes.mjs` 의 `CSV` 경로를 바꿉니다.
5. 심습니다.

   ```bash
   node "open api/bake-sped-classes.mjs"
   node "06. 실행계획(1)/prototype/test.js"
   ```

---

## 확인할 것

- 시군이 **22개**인지 (군위는 2023년 대구로 편입되어 경북 자료에 없습니다)
- 시군 이름이 앱의 `SIGUNGU` 와 **한 글자도 다르지 않은지**
- 순회학급 열은 2025년 자료에서 **전부 0** 이었습니다. 값이 생기면 컬럼을 늘리고
  화면에도 배치유형을 하나 더 적어야 합니다.

## 기준일 주의

이 자료는 **4월 1일** 기준이고, 화면의 다른 특수교육 수치는 학교알리미 **공시 시점** 기준입니다.
두 수를 **빼서 증감을 말하지 않습니다** — 그 차이가 실제 변화인지 조사 차이인지
이 자료만으로는 가릴 수 없습니다. 화면에도 같은 문장을 적어 두었습니다.
