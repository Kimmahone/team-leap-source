심볼이 뜻하는 것

  • 낮은 회색 지면 — 지금 서 있는 자리. 작아지는 학교.
  • 사이의 빈 공간 — 학령인구 감소가 만든 간극.
  • 호 — 도약. 간극 위를 건너간다.
  • 높은 주황 지면 — 도달하는 곳. 출발보다 높다.

감소를 그리지 않았습니다. 주제는 감소지만 브랜드는 대응입니다. 하강하는 그래프·우는 얼굴·빈 교실 같은 표현은 쓰지 않습니다.

06앱에 적용한 모습

앱 3종이 모두 이 모양을 공유합니다. 각자 만들면 서로 다른 물건 10개가 됩니다.

학급 자율 의사결정 보드 저장됨

안건 3건이 대기 중입니다. 투표를 시작하면 순서가 자동으로 섞입니다.

버튼 최소 높이 44px — 터치 목표 크기 기준. 포커스 표시 3px는 leap.css가 전역으로 처리합니다.

07파일

웹·앱에는 SVG를, 한글(HWP)·PPT·공문에는 PNG를 쓰세요. 한글은 SVG 삽입이 제대로 되지 않습니다.

brand/ ├─ brand-guide.html ← 이 문서 ├─ 브랜드 가이드.md ← 값을 옮겨 적을 때 쓰는 규격서 ├─ logo/ ← 웹·앱용 (SVG, 각 1KB 내외) │ ├─ leap-logo-horizontal.svg 기본 (밝은 배경) │ ├─ leap-logo-horizontal-dark.svg 기본 (어두운 배경) │ ├─ leap-logo-stacked.svg 세로 조합 │ ├─ leap-logo-stacked-dark.svg 세로 조합 (어두운 배경) │ ├─ leap-wordmark.svg 워드마크 단독 │ ├─ leap-mark.svg 심볼 단독 │ ├─ leap-mark-dark.svg 심볼 (어두운 배경) │ ├─ leap-mark-mono.svg 심볼 단색 (currentColor 상속) │ ├─ leap-badge.svg 앱 아이콘 96px │ └─ leap-favicon.svg 파비콘 32px └─ logo-png/ ← 한글·PPT·공문용 (PNG, 투명 배경, 20개) ├─ leap-logo-horizontal-{600,1200,2400}w.png ├─ leap-logo-stacked-{400,800,1600}w.png ├─ leap-mark-{256,512,1024}.png ├─ leap-badge-{256,512,1024}.png └─ leap-favicon-{32,64,128,256}.png
