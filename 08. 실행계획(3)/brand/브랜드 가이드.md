# TEAM LEAP 브랜드 가이드 (텍스트 규격서)

- v1.0 / 2026. 8. 2.
- 눈으로 볼 때는 `brand-guide.html`을 브라우저로 여세요. 이 문서는 값을 옮겨 적을 때 쓰는 규격서입니다.

---

## 1. 심볼

낮은 지면에서 출발해 간극 위를 호로 건너, 더 높은 지면에 닿는 형태입니다.

| 요소 | 의미 |
|---|---|
| 낮은 회색 지면 | 지금 서 있는 자리. 작아지는 학교 |
| 사이의 빈 공간 | 학령인구 감소가 만든 간극 |
| 호 | 도약 — 간극 위를 건너간다 |
| 높은 주황 지면 | 도달하는 곳. 출발보다 **높다** |

**감소를 그리지 않습니다.** 주제는 감소지만 브랜드는 대응입니다. 하강 그래프, 우는 얼굴, 빈 교실 같은 표현은 쓰지 않습니다.

### 도형 좌표 (viewBox 0 0 64 64)

```
낮은 지면  M7 52 H25              stroke #5A6672  width 6.5  round cap
높은 지면  M39 36 H57             stroke #CE6410  width 6.5  round cap
호        M16 46 Q32 -10 48 30   stroke #1B4FA0  width 7    round cap
```

선 세 개가 전부입니다. 폰트에 의존하지 않는 순수 도형이라 어떤 컴퓨터에서 열어도 같게 나옵니다.

## 3. 글자

웹폰트를 쓰지 않습니다. 외부 CDN 의존을 없애 보안성 검토를 통과하고, 인터넷 없이도 앱이 온전히 뜨게 하기 위해서입니다.

```
system-ui, -apple-system, "Segoe UI", "Apple SD Gothic Neo",
"Malgun Gothic", "Noto Sans KR", sans-serif
```

| 단계 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| display | 2rem | 700 | 앱 제목 |
| title | 1.375rem | 700 | 섹션 제목 |
| body | 1rem | 400 | 본문 (행간 1.65) |
| small | 0.8125rem | 500 | 보조 설명 |

워드마크는 `TEAM`을 500(회색), `LEAP`을 800(먹색)으로 씁니다. 자간 `0.045em`.

## 4. 사용 규칙

### 여백과 최소 크기
- 로고 주변에 **심볼 높이의 1/2**만큼 비웁니다. 그 안에 다른 요소를 넣지 않습니다.
- 심볼 최소 **20px**. 16px는 파비콘에서만 씁니다.
- 가로 조합 최소 폭 **140px**.

### 하면 안 되는 것
1. 가로세로 비율 변형
2. 회전·기울임
3. 임의 색상 지정
4. 대비가 낮은 배경 위에 얹기
5. 그림자·외곽선·그라디언트 추가
6. 조합 요소를 임의로 재배치

## 5. 파일

### 웹·앱용 — `logo/` (SVG)

| 파일 | 용도 |
|---|---|
| `leap-logo-horizontal.svg` | **기본** — 밝은 배경, 문서 머리말·웹 헤더 |
| `leap-logo-horizontal-dark.svg` | 어두운 배경 전용 |
| `leap-logo-stacked.svg` | 세로 조합 — 포스터, 리플렛 표지 |
| `leap-logo-stacked-dark.svg` | 세로 조합, 어두운 배경 |
| `leap-wordmark.svg` | 워드마크 단독. 심볼이 이미 근처에 있을 때만 |
| `leap-mark.svg` | 심볼 단독 |
| `leap-mark-dark.svg` | 심볼, 어두운 배경 |
| `leap-mark-mono.svg` | 단색. `currentColor`를 상속하므로 부모의 `color`를 따라감. 흑백 인쇄·각인·주색 배경 반전용 |
| `leap-badge.svg` | 앱 아이콘 96px |
| `leap-favicon.svg` | 파비콘 32px |

### 한글·PPT·공문용 — `logo-png/` (PNG, 투명 배경)

**한글(HWP)은 SVG 삽입이 제대로 되지 않습니다.** 공문·계획서·발표자료에는 PNG를 쓰세요.

| 파일 | 크기 |
|---|---|
| `leap-logo-horizontal-{600,1200,2400}w.png` | 가로 조합. 문서 머리말은 600w면 충분 |
| `leap-logo-stacked-{400,800,1600}w.png` | 세로 조합 |
| `leap-mark-{256,512,1024}.png` | 심볼 |
| `leap-badge-{256,512,1024}.png` | 앱 아이콘 |
| `leap-favicon-{32,64,128,256}.png` | 파비콘 |

PNG를 다시 만들어야 하면 `export-png.py`를 쓰세요. macOS 기본 도구(qlmanage, sips)만 써서 별도 설치가 필요 없습니다.

## 6. 앱에 넣을 때

**SVG 코드를 HTML에 직접 붙여 넣으세요.** 파일로 링크하면 앱이 단일 HTML로 성립하지 않습니다. 심볼은 이 세 줄이 전부입니다.

```html
<svg viewBox="0 0 64 64" width="32" height="32" aria-hidden="true">
  <path d="M7 52 H25"            stroke="#5A6672" stroke-width="6.5" stroke-linecap="round" fill="none"/>
  <path d="M39 36 H57"           stroke="#CE6410" stroke-width="6.5" stroke-linecap="round" fill="none"/>
  <path d="M16 46 Q32 -10 48 30" stroke="#1B4FA0" stroke-width="7"   stroke-linecap="round" fill="none"/>
</svg>
```

다크 모드까지 대응하려면 색을 CSS 변수로 빼세요.

```html
<path d="M7 52 H25"            stroke="var(--leap-gray)"       .../>
<path d="M39 36 H57"           stroke="var(--leap-amber-mark)" .../>
<path d="M16 46 Q32 -10 48 30" stroke="var(--leap-blue)"       .../>
```

## 7. leap.css와의 관계

이 문서의 색·글자·간격이 `apps/kit/leap.css`에 그대로 들어 있습니다. 앱을 만들 때 값을 손으로 옮기지 말고 변수를 쓰세요.

```css
color: var(--leap-ink);
background: var(--leap-blue);
padding: var(--leap-4);
```

색을 바꿔야 할 일이 생기면 `leap.css` 한 곳만 고칩니다.

다만 **`kit/leap.css` 는 원본이고, 각 앱 `index.html` 안의 블록은 사본입니다.** 앱을 파일 하나로 유지하기 위해서입니다. 원본을 고치면 앱 5종과 카탈로그의 블록도 함께 고쳐야 합니다.
