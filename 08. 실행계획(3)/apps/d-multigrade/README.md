## 왜 이 앱인가

**학령인구가 줄면 소규모학교가 늘고, 소규모학교가 늘면 복식학급이 늘어납니다.** 인과가 직선입니다.

두 학년을 한 교실에서 동시에 가르치는 일은 지금도 **종이에 손으로** 짭니다. 교사가 A학년을 가르치는 동안 B학년은 혼자 해야 하고, 이 교차를 40분 안에 짜맞추는 것이 복식수업의 전부입니다.

앱 A(순회교사 스케줄러)를 뺀 이유는 동아리에 사용자가 없어서였습니다. **복식학급 담임은 경북 소규모학교에 흔합니다.** 만든 사람이 곧 사용자가 됩니다.

## 가장 중요한 설계 결정

> **교사는 한 시점에 한 학년만 직접지도할 수 있다.**

이 규칙을 **경고로 잡지 않고, 어길 수 없게** 만들었습니다.

블록마다 학년별로 자유롭게 배정하게 하면 "3학년 직접 + 4학년 직접" 같은 불가능한 상태를 만들 수 있고, 그러면 경고를 띄워야 합니다. 대신 **성립 가능한 배치 네 가지 중에서만** 고르게 했습니다.

| 배치 | 첫째 학년 | 둘째 학년 | 선생님 |
|---|---|---|---|
| ㄱ학년 직접 | 직접 | 스스로 | ㄱ학년 곁 |
| ㄴ학년 직접 | 스스로 | 직접 | ㄴ학년 곁 |
| 공통 지도 | 함께 | 함께 | 두 학년 함께 |
| 둘 다 스스로 | 스스로 | 스스로 | 순회 |

**잘못된 상태를 표현할 방법 자체가 없습니다.** 앱 B에서 무기명을 구조로 보장한 것과 같은 방식입니다. 테스트가 이걸 고정합니다 — "두 학년 동시 직접지도인 배치가 목록에 없다".

## 대신 경고로 알리는 것

규칙이 아니라 **판단**이 필요한 것들입니다. 사정이 있으면 그대로 두어도 됩니다.

| 살펴볼 점 | 기준 | 왜 |
|---|---|---|
| 직접지도 시간이 치우침 | 두 학년 차이 10분 초과 | 한쪽이 방치되면 학부모 민원으로 이어집니다 |
| 너무 오래 혼자 있음 | 연달아 15분 초과 | 저학년일수록 15분을 넘기면 집중이 무너집니다 |
| 둘 다 스스로가 김 | 10분 초과 | 이 시간에는 아무도 직접 배우지 않습니다 |
| 스스로 할 거리 없음 | 간접 구간이 있는데 준비물이 빔 | **복식수업이 무너지는 가장 흔한 이유** |

마지막 항목이 핵심입니다. 복식수업이 실패하는 건 직접지도를 받는 학년 때문이 아니라, **혼자 해야 하는 학년의 할 거리가 없을 때**입니다. 그래서 준비물을 별도 탭으로 빼고 점검과 연동했습니다.

## 화면

| 탭 | 내용 |
|---|---|
| **수업 짜기** | 수업 개요 → (왼쪽) 시간 배치·구간별 활동·점검 / (오른쪽) 지도안 미리보기 |
| **학습지** | 학년별 학습지 문항 만들기. 오른쪽에 미리보기 |
| **준비물** | 스스로 할 거리 목록, 준비 여부 체크 |
| **보관함** | 저장한 차시. 이름으로 찾고 불러오기·복제·인쇄·지우기 |

「AI 초안 도우미」는 탭이 아니라 **머리 오른쪽 단추**입니다. 어느 화면에서나 열립니다.

### 왼쪽은 쓰는 곳, 오른쪽은 보는 곳 (v0.3)

수업 짜기와 학습지는 두 칸으로 나뉩니다. 왼쪽에서 고치면 오른쪽 미리보기가 **즉시** 따라옵니다.
오른쪽은 화면에 붙어(sticky) 왼쪽을 끝까지 따라다닙니다.

수업 개요는 다 적고 나면 **접어서 치울 수 있습니다.** 접으면 한 줄 요약만 남습니다.

### 학년 고르기는 토글 (v0.2)

학년을 **적지 않고 누릅니다.** 1~6학년 토글이고, 한쪽에서 고른 학년은 **반대쪽에서 눌리지 않습니다.**
같은 학년 둘은 복식학급이 아니기 때문입니다 — 배치 네 가지와 같은 방식으로, 잘못된 상태를 만들 방법 자체를 없앴습니다.

시작 화면과 「수업 개요」 양쪽에 있어서, 짜는 도중에도 바꿀 수 있습니다.

### 시간 배치표

40·45·50분을 5분 또는 **10분** 블록으로 나눕니다. 세 줄로 보여 줍니다.

```
         0–5    5–10   10–15  15–20  20–25  25–30  30–35  35–40
3학년    함께   직접   스스로 직접   스스로 직접   스스로 함께
4학년    함께   스스로 직접   스스로 직접   스스로 직접   함께
선생님   함께   3학년  4학년  3학년  4학년  3학년  4학년  함께
```

**맨 아랫줄이 이 도구의 요점입니다** — 그 시간에 선생님이 어디 계신지 한눈에 보입니다.

칸마다 색과 **글자를 함께** 넣었습니다. 색만으로 정보를 전달하면 접근성 심사에서 걸립니다.

#### 표에서 바로 바꾸기 (v0.2)

표 자체가 편집기입니다.

| 방법 | 조작 |
|---|---|
| **붓** | 배치 하나를 붓으로 고르고 칸을 누르면 그 자리에서 칠해집니다 |
| **드래그** | 붓을 켠 채 여러 칸을 훑으면 한 번에 칠해집니다 |
| **키보드** | 칸에 초점을 두고 `1`·`2`·`3`·`4` |
| **붓 끄기** | 칸을 누르면 아래 그 구간으로 내려갑니다 |

칠할 수 있는 것은 여전히 **성립 가능한 네 가지뿐**입니다. 붓 자체가 네 개라서, 드래그로도 잘못된 배치는 만들 수 없습니다.

드래그 도중에는 화면을 통째로 다시 그리지 않고 지나간 칸만 고쳐 칠합니다. 손을 뗄 때 한 번만 전체를 다시 셉니다.

#### 구간 길이 (v0.2)

한 칸을 5분으로 볼지 10분으로 볼지 고릅니다. 45분은 10분으로 나누어떨어지지 않아 그 토글이 **눌리지 않습니다.**
길이를 바꿔도 짜 둔 배치와 적어 둔 활동은 새 구간으로 옮겨 갑니다.

## 구간별 활동 — 누를 것 없이 죽 적는다 (v0.3)

v0.2까지는 **배치표에서 구간을 눌러야** 그 구간의 활동 칸이 아래에 나타났습니다.
여덟 구간을 채우려면 여덟 번 누르고 여덟 번 스크롤해야 했습니다. 이게 가장 큰 불편이었습니다.

이제 **모든 구간이 처음부터 펼쳐져** 있습니다. 위에서 아래로 죽 적으면 끝입니다.

```
0–5분    [공통 지도  ▾]                    선생님 — 함께
  3학년 [함께]  ┌────────────────┐   4학년 [함께]  ┌────────────────┐
                └────────────────┘                  └────────────────┘
5–10분   [3학년 직접 ▾]                    선생님 — 3학년
  3학년 [직접]  ┌────────────────┐   4학년 [스스로] ┌────────────────┐
                └────────────────┘                  └────────────────┘
```

- 줄마다 **배치 드롭다운**이 붙어 있어 여기서도 배치를 바꿉니다 (배치표·붓·키보드에 이어 네 번째 길)
- 줄 왼쪽 테두리 색과 **직접/스스로/함께 이름표**로 그 구간의 성격이 바로 보입니다
- 칸의 안내 문구가 역할에 따라 달라집니다
  - 직접 → "선생님과 무엇을 하나요?"
  - 스스로 → **"혼자서도 할 수 있는 것을 적어 주세요 (학습지·과제·읽기)"**
  - 함께 → "두 학년이 함께 무엇을 하나요?"
- 적는 만큼 칸이 늘어납니다

**배치표와 활동 줄은 이어져 있습니다.** 배치표 칸을 누르면 그 구간의 줄로 내려가 커서까지 놓입니다.
배치표는 한눈에 보는 곳, 아래 줄은 적는 곳입니다.

적는 동안에는 화면을 통째로 다시 그리지 않습니다. 미리보기·점검·구간 수만 따로 고쳐 그립니다.
그러지 않으면 **적는 도중에 커서가 튕깁니다.**

### 빠른 틀

| 틀 | 배치 |
|---|---|
| **교차형** | 공통으로 열고 닫고, 가운데는 번갈아 |
| **번갈아만** | 도입 없이 처음부터 교차. 교과가 완전히 다를 때 |
| **공통 중심** | 대부분 함께. 같은 교과·같은 주제일 때 |

틀을 바꿔도 **적어 둔 활동 내용은 지우지 않습니다.**

교차형으로 짜면 각 학년이 한 번에 **5분씩만** 혼자 있게 됩니다. 혼자 있는 구간이 서로 떨어지기 때문입니다.

## 미리보기

v0.1에서는 지도안을 보려면 인쇄 대화상자를 띄우는 수밖에 없었습니다.

이제 **오른쪽 칸에 A4 지도안이 그대로** 보이고, 왼쪽에서 무엇을 고치든 **즉시** 따라옵니다.
스크롤해도 화면에 붙어 따라다닙니다. 「학습지」 탭도 같습니다.

미리보기와 인쇄물은 **같은 함수(`printHTML` / `sheetHTML`)와 같은 CSS(`.sheet`)** 를 씁니다.
따로 만들면 반드시 어긋나기 때문입니다. `@media print` 안에는 종이 설정과 화면 숨기기만 남겼습니다.

오른쪽 칸에서는 `zoom` 으로 줄여 보여 주고, 「실제 크기」와 「창으로 크게 보기」로 키웁니다.
화면이 좁으면 두 칸이 위아래로 쌓입니다.

## 학습지 만들기 (v0.2)

복식수업에서 학습지는 곁들이가 아니라 **뼈대**입니다. 한 학년이 혼자 있는 동안 붙들고 있을 것이 없으면 그 수업은 무너집니다.

- 학년별로 한 장씩. 제목·안내문·문항
- 문항 유형 다섯 — **빈칸 / 서술 / 선택 / 활동 / 확인**
- 답 쓰는 칸 다섯 — 한 줄 / 여러 줄 / 네모칸 / 모눈칸 / 없음
- 위아래로 옮기기, 지우기, 반대 학년으로 복사하기
- 「준비물 목록에 넣기」로 준비물 탭과 연결

만드는 화면 옆에 **그 학년이 연달아 혼자 있는 시간이 몇 분인지** 함께 띄웁니다. 몇 문항이 필요한지 판단하라고요.

점검도 이 탭을 봅니다 — 한 학년을 10분 넘게 혼자 두면서 **그 학년 학습지가 비어 있으면** 따로 짚어 줍니다.

## AI 초안 도우미 — API 키 없이 (v0.3)

머리 오른쪽 **「AI 초안 도우미」 단추**로 엽니다. 탭이 아니라 창입니다.

v0.2에서는 Gemini API 키를 넣어 브라우저에서 곧바로 불렀습니다. **키를 걷어냈습니다.**
학교에서 키 발급이 막히는 일이 잦고, 공용 컴퓨터에 키를 남기는 것도 께름칙하기 때문입니다.

대신 **프롬프트를 주고 JSON을 받습니다.**

```
① 무엇의 초안?        [수업 설계] [학습지]  + 추가 요청
② 프롬프트를 AI에게    [프롬프트 복사] [프롬프트 파일로 받기]
                       → 쓰던 챗봇(ChatGPT·Gemini·클로드…)에 붙여 넣기
③ 결과 가져오기        JSON 파일 끌어다 놓기 / 파일 고르기 / 붙여넣기
④ 확인하고 받기        미리 보고, 무엇을 받을지 고르고, 「이대로 받기」
```

프롬프트에는 수업 개요가 **이미 들어가 있습니다** — 두 학년, 인원, 교과, 주제, 수업 시간, 구간 수,
그리고 이 앱이 지키는 규칙 전부. 교사는 복사해서 붙여 넣기만 하면 됩니다.

### 프롬프트가 두 가지인 이유

| | 넣는 것 | 받는 것 |
|---|---|---|
| **수업 설계** | 학년·교과·주제·구간 수 + 배치 네 가지 규칙 | `blocks` (배치와 활동), `prep` |
| **학습지** | 위에 더해 **연달아 혼자 있는 시간**과 짜 둔 수업 흐름 | `sheetA`, `sheetB` |

학습지 프롬프트가 「혼자 있는 시간」을 넘기는 것이 요점입니다.
그래야 AI가 **몇 문항이 필요한지, 어느 학년에 더 넣어야 하는지** 판단합니다.
"교사 도움 없이 풀 수 있는 것만 넣으라"고도 못 박습니다.

### 이 앱만의 규칙

> **AI가 보낸 배치라도 네 가지를 벗어나면 받지 않는다.**

사람이 못 만드는 상태를 AI라고 만들 수 있으면 이 앱의 핵심 설계가 무너집니다.
받은 JSON은 적용하기 전에 반드시 걸러 냅니다.

| 들어온 것 | 처리 |
|---|---|
| 목록에 없는 `kind` (예: 두 학년 동시 직접) | 「둘 다 스스로」로 바꾸고 **고쳤다고 알림** |
| 구간 수가 다름 | 이 수업의 구간 수에 맞추고 알림 |
| `blocks` 가 아예 없음 (학습지 초안) | **배치를 건드리지 않음** |
| 없는 문항 유형·답칸 | 기본값으로 되돌림 |
| 지시문 없는 문항 | 버림 |

테스트가 이걸 고정합니다 — "AI가 보낸 잘못된 배치는 끝내 들어오지 못한다".

### 초안은 초안이다

- **자동으로 덮어쓰지 않습니다.** 받은 초안을 먼저 보여 주고, 「이대로 받기」를 눌러야 들어갑니다.
- **무엇을 받을지 고릅니다** — 초안에 실제로 들어 있는 것만 골라 보여 줍니다.
- 배치나 학습지를 덮어쓸 때는 한 번 더 묻습니다.
- 받은 초안도 **적용 전에 미리 점검**해서, 직접지도 균형과 혼자 있는 시간을 보여 줍니다.

### 2. 미리보기를 읽을 수 없었습니다

### 3. 세 학년 복식 ★

v0.4 README 가 「확인이 필요한 것」에 적어 둔 항목입니다. 경북 소규모학교에는
세 학년을 한 교실에서 가르치는 학급이 실제로 있습니다.

**규칙을 표에서 함수로 옮겼습니다.** v0.4 는 배치마다 「a 는 direct, b 는 indirect」처럼
칸마다 역할을 적어 두었는데, 학년이 셋이 되면 그 표가 아홉 줄이 되고 한 줄만
빠뜨려도 조용히 어긋납니다.

```js
function roleOf(kind, w) {
  if (kind === 'common') return 'common';
  if (kind === 'roam')   return 'indirect';
  return kind === w ? 'direct' : 'indirect';
}
```

규칙은 여전히 하나입니다 — **직접지도를 받는 학년은 언제나 하나뿐.**
검사도 표를 세는 대신 이 규칙을 **두 학년일 때와 세 학년일 때 모두** 확인합니다.

셋째 학년은 **없으면 아예 안 보입니다.** 다시 누르면 빠지고, 빠질 때 그 학년만
남아 있던 배치는 「모두 스스로」로 돌아갑니다 — 아무도 없는 학년을 가르치게 두지
않기 위해서입니다.

## v0.4 — 짠 것을 실제로 진행합니다

v0.3까지 이 앱은 **지도안을 만드는 데서 끝났습니다.** 그런데 복식수업이 실제로 무너지는 자리는
계획이 아니라 **바꾸는 순간을 놓치는 것**입니다. 5분마다 두 학년 사이를 오가면서 시계까지 보고
있을 여유는 없습니다. 종이 지도안은 「무엇을 할까」는 알려 주지만 「지금 옮겨야 하나」는 말해 주지 않습니다.

### 1. 「수업 중」 화면

머리 오른쪽 **「수업 중」** 또는 점검 아래 **「수업 중 화면 열기」** 로 엽니다.

```
 4:52   이 구간이 끝나기까지
        0–5분 · 9:40–9:45 · 1 / 8구간
 ▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░░░░

 선생님은 지금  3학년 곁에

 ┌ 3학년  직접 ─────────┐  ┌ 4학년  스스로 ────────┐
 │ 받아올림 함께 풀기    │  │ 학습지 1~3번 스스로   │
 └──────────────────────┘  └──────────────────────┘

 다음 ▸ 10–15분 · 4학년 직접 — 선생님은 4학년 곁에
 [이어서] [다음 구간] [처음으로] [닫기]
```

| 정한 것 | 왜 |
|---|---|
| **수업 전체가 아니라 이 구간**의 남은 시간 | 전체 남은 시간은 교실 시계를 보면 압니다. 알 수 없는 것은 「자리를 언제 옮기는가」입니다 |
| **멈춘 채로 열립니다** | 열자마자 시간이 가면 준비할 틈이 없습니다 |
| **잠깐 멈춤**이 있습니다 | 실제 수업은 끊깁니다. 멈출 수 없는 타이머는 두 번째 시간에 버려집니다 |
| **다음 구간**을 미리 보여 줍니다 | 바꾸기 직전에 알아야 준비가 됩니다 |
| **다음 구간**으로 손수 넘길 수 있습니다 | 늘어지는 날이 있습니다. 계획대로만 도는 시계는 방해가 됩니다 |
| 끝나도 **저절로 닫지 않습니다** | 끝난 화면을 보고 교사가 닫는 편이 낫습니다 |

- 색은 시간 배치표와 **같은 것**을 씁니다. 짤 때 본 색과 진행할 때 보는 색이 다르면 머릿속에서 다시 맞춰야 합니다.
- 교실 뒤에서도 읽히도록 글자를 크게 잡았습니다.
- 구간이 바뀌면 **화면이 한 번 밝아지고** 짧은 소리가 납니다. 소리는 끌 수 있습니다.
  소리는 파일을 두지 않고 브라우저가 가진 것(WebAudio)으로 냅니다 — **여전히 나가는 요청이 하나도 없습니다.**
- `Space` 로 시작·멈춤, `Esc` 로 닫기.

### 2. 시작 시각을 적으면 진짜 시각이 붙습니다

수업 개요에 **시작 시각**(없어도 됩니다)을 적으면, 수업 중 화면과 **인쇄된 지도안**의 구간마다
`9:55` 같은 실제 시각이 함께 나옵니다. 종이를 들고 있는 선생님에게 「15–20분」보다 훨씬 빨리 읽힙니다.

자정을 넘겨도 터지지 않고, 적지 않았으면 **아무것도 지어내지 않습니다.**

### 3. 고친 것 — 수업 개요를 접으면 화면 전체가 죽었습니다 ★

v0.3에서 넣은 「개요 접기」에 버그가 있었습니다.

접으면 개요 입력칸들이 화면에서 사라지는데, 손잡이를 다는 코드가 **없는 칸을 잡으려다 그 자리에서 멈췄습니다.**
그 아래에서 붙던 것이 **하나도 붙지 않았습니다** — 붓, 배치표, 활동 칸, 저장, 인쇄, 그리고
**다시 펴는 단추까지.** 접는 순간 수업 짜기 화면이 통째로 굳었습니다.

```
Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
```

없는 칸은 조용히 건너뛰도록 고쳤습니다.

### 4. 검사가 이 버그를 놓친 이유도 고쳤습니다

147개가 통과하는데도 이런 버그가 배포까지 나간 데는 이유가 있었습니다.
**검사용 DOM 흉내가 `querySelector` 로 절대 `null` 을 주지 않았습니다.**

```
before  querySelector() { return makeEl(); }        ← 없는 것도 있다고 함
after   #id 는 그려 놓은 HTML 에 그 id 가 있을 때만 ← 없으면 null
```

흉내가 진짜보다 너그러우면, 화면에 없는 것을 잡는 코드가 검사에서는 멀쩡히 지나갑니다.
이제 접기 버그를 되돌려 놓으면 검사가 **실제로 실패합니다.**

### 5. 이 앱의 마크

**한 교실 안의 두 줄, 그 사이를 오가는 선생님.** 위아래 줄이 어긋나 있는 것은 일부러입니다 —
두 학년이 같은 때에 같은 것을 하지 않는다는 것, 그것이 복식수업의 전부입니다.

`kit/leap.css` 와 `kit/leap.js` 가 원본이고, `index.html` 안의 것은 **사본**입니다. 원본을 고치면 앱 안의 블록도 함께 고쳐야 합니다.

`index.html` 맨 아래 `window.__LEAP_TEST__` 훅은 점검용입니다. 브라우저에서는 아무 일도 하지 않습니다.

## 다음

1. **복식학급 담임이 실제로 한 차시를 짜 보기** — 구간별 활동을 죽 적는 방식이 실제로 편한지
2. 지도안·학습지를 종이로 뽑아 결재선에 올려 보기 — 서식이 학교에서 통하는지
3. **AI 초안 프롬프트를 여러 챗봇에 돌려 보기** — ChatGPT·Gemini·클로드가 각각 규칙을 잘 지키는지,
   JSON을 깨뜨리지 않는지
4. 좁은 화면(태블릿·휴대전화)에서 두 칸이 쌓였을 때 쓸 만한지
5. 3개 학년 복식(3복식)이 필요한지 확인 — 지금은 2개 학년만 지원합니다
6. 나온 요구사항 반영 → v0.4

### 확인이 필요한 것

- 학년 토글을 1~6학년으로 고정했습니다. 특수학급·유치 병설 등 **다른 표기가 필요한 학교가 있는지**.
- 학습지 문항 유형 다섯 가지로 충분한지 — 그림 그리기·붙이기 같은 저학년 활동이 빠져 있을 수 있습니다.
- 챗봇이 JSON 대신 설명을 섞어 보내는 일이 얼마나 잦은지. 지금은 앞뒤 설명이 섞여도 JSON만 골라내지만,
  아예 형식을 어기면 교사가 다시 물어봐야 합니다.

## 고친 것

### v0.3

- **AI 초안 도우미에서 API 키를 걷어냄.** 프롬프트를 주고 JSON을 받는 방식으로 바꾸고, 머리 오른쪽 단추로 옮김
- **왼쪽은 쓰는 곳, 오른쪽은 보는 곳**으로 나눔. 미리보기가 화면에 붙어 따라다님
- **구간별 활동을 전부 펼침.** 눌러야 나타나던 것을 없앰 — v0.2의 가장 큰 불편
- **보관함에 저장할 때 차시 이름**을 붙이게 함
- 준비물이 두 번 들어가는 문제 — 한글 조합 중 엔터를 거르고, 다시 그리기 전에 칸을 비우고,
  처리 중 두 번째 눌림을 무시하도록 고침
- 좁은 화면에서 배치표가 빠져나가 **페이지가 옆으로 밀리던 문제**를 고침
  (`.tlwrap` 에 `position:relative` — 표 안의 숨은 `<caption>` 이 절대위치라 잘리지 않고 있었음)
