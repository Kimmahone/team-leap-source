# 앱 모음 — TEAM LEAP가 만든 것을 한곳에

학령인구 대시보드, 교실도구, 연구원 1인 1앱을 **한 페이지에** 모았습니다.
계획서 과제 ④ 「교육용 웹앱스토어 구축 및 성과 확산 체계 마련」의 첫 판입니다.

## 왜 이 페이지인가

- 앱 카탈로그(`../index.html`)는 **교실도구**만 다룹니다. 대시보드와 연구원 앱은 주소가 저마다 달라
  「TEAM LEAP가 무엇을 만들었나」를 한 번에 보여 줄 곳이 없었습니다.
- 성과보고회에서는 **휴대폰으로 바로 열어 보게** 하는 것이 설명보다 빠릅니다. 그래서 모든 앱에 QR을 붙였습니다.

## 무엇이 있나

| 묶음 | 내용 |
|---|---|
| 학령인구 대시보드 | 데이터 플랫폼, 주간 뉴스 클리핑, 브리핑북 |
| 교실도구 | 카탈로그의 앱 전부. 문구는 카탈로그에서 그대로 옮겼습니다 |
| 연구원 1인 1앱 | 연구원이 각자 만든 앱. 다른 주소로 열립니다 |

- 위쪽 네 단추(**업무는 가볍게 · 수업은 풍성하게 · 데이터는 명확하게**)는 계획서의 L·E·A 갈래로 거릅니다.
- **QR** 단추를 누르면 큰 QR이 뜹니다. 발표 화면에 띄워 객석에서 찍게 할 수 있습니다.
- **QR 안내문 인쇄**는 A4에 모든 앱의 QR을 세 칸씩 담습니다. 맨 위 QR은 이 페이지입니다.

## 앱을 더하는 법

문서 안 `<script type="application/json" id="apps-data">` 에 한 줄을 더합니다. 화면 카드·QR·인쇄물·숫자가 모두 여기서 나옵니다.

```json
{"id": "my-app", "group": "members", "kind": "work",
 "name": "앱 이름", "lead": "무엇을 하는지 한두 문장",
 "who": "누구에게 필요한지", "by": "○○○ 선생님",
 "href": "https://주소/", "url": "https://주소/"}
```

- `group` — `analyze`(대시보드) · `tools`(교실도구) · `members`(연구원 앱)
- `kind` — `work`(업무) · `class`(수업·학급) · `data`(데이터)
- `badge` — 있으면 `use`(학교에서 쓰는 중) · `wip`(만드는 중) · `auto`(자료 자동 갱신)
- 한글 도메인은 휴대폰이 QR을 못 읽을 수 있어 `qr` 칸에 퓨니코드 주소를 따로 적습니다.

더한 뒤에는 `node test.js` 를 돌립니다. 교실도구 목록이 카탈로그와 어긋나거나, 사이트 안 링크가 파일에 닿지 않으면 빨갛게 됩니다.

## 지키는 것

- **바깥을 부르지 않습니다.** QR은 페이지 안에 붙여 넣은 qrcode-generator(Kazuhiko Arase, MIT)로 그립니다.
- 아무것도 저장하거나 보내지 않습니다. 밝기 선택만 이 브라우저에 남습니다(카탈로그와 같은 `leap-theme`).
- 연구원 앱의 문구는 TEAM LEAP 앱 개발 현황 시트(2026. 10. 7.)의 설명을 옮긴 것입니다. 각 앱의 저작권은 만든 사람에게 있습니다.

## 2026. 10. 11. 체험 안내

공동 교실도구 11개의 시작 화면과 대표 예시·입력 흐름을 점검하고, 앱별 실제 버튼명으로 체험 순서를 안내합니다. 연구원 외부 앱은 접속·대표 체험 확인만 하며 코드 수정은 제외합니다. VOCA HERO는 계정 준비 오류로 직접 시연에서 제외합니다.

## 2026. 10. 12. 대시보드 기본 접속 변경

대시보드 카드의 **김지원 버전 열기**와 QR은 [경북 학령인구 정책 플랫폼](https://population.gbeai.net/)으로 연결됩니다. **기존 김정준 버전** 단추는 [초기 구축본](https://team-leap.pages.dev/dashboard/)을 그대로 엽니다. QR 안내문에도 두 주소를 함께 적습니다. 같은 대시보드의 두 버전이므로 앱 개수는 늘리지 않습니다.

새 플랫폼의 지도·현황·동향은 로그인 없이 체험할 수 있습니다. 주간 브리프·정책 시나리오는 회원 메뉴이며, 회원 내부 기능의 동작 검증이나 전체 완성 판정은 포함하지 않습니다.

김정준 선생님이 초기 구축을 했으며, 새 플랫폼 크레딧은 디자인 박하은·프론트엔드 김정준·백엔드·DB 김지원입니다. 이전의 「김지원 보강 예정」 기록은 공개 버전 확인으로 갱신하고, 추가 보강·최종 마무리 여부는 작업 범위 확인 뒤 기록합니다. 세부 사항은 `대시보드_담당 변경 기록.json`에 남깁니다.

카드에 별도 접속 경로가 필요하면 `links`에 `name`(단추 이름)·`href`(접속 주소)·`url`(인쇄 안내문 주소)을 추가합니다. 기본 `href`·`url`은 기본 열기와 QR에 사용합니다.

## 2026. 10. 27. 최신 시트 반영

- 최신 시트 A1:L13의 주요 등록 앱 12개(대시보드 1·연구원 앱 11)를 반영합니다. 공동 교실도구 11개·참고 링크 2개와 합한 목록은 25개입니다. 등록 수를 완료 앱 수나 현장 효과로 계산하지 않습니다.
- 경북배움길은 공개 로드맵의 5학년·체험처·탐구 질문을 확인했고 현재 구글 시트 미연결/백업 자료 안내를 기록했습니다.
- 학교장 인증제는 공개 Google 로그인 첫 화면과 가입 안내만 확인했습니다. 내부 기능은 미확인으로 두고 가상 시연 계정 준비를 안내합니다. 기존 운영 앱 시험 입력 금지와 VOCA HERO 시연 제외를 유지합니다.
- 시트의 시연·현장 적용·최종본 체크와 학령인구 감소 연결은 12개 모두 미기록입니다. 미실시로 단정하지 않고 제작자 증빙으로 보완합니다.
