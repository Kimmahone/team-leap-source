# TEAM LEAP 앱 — 카탈로그와 5종

이 폴더가 **배포 단위**입니다. 통째로 복사해 주면 그대로 돌아갑니다.

```
apps/
├─ index.html      ← 앱 카탈로그 (여기서 시작)
├─ test.js         ← node test.js
├─ kit/            ← 공통 뼈대 (원본)
│  ├─ leap.css
│  └─ leap.js
├─ a-circuit/      ← 앱 A 순회교사 통합 시간표      v0.1
├─ b-classboard/   ← 앱 B 학급 자율 의사결정 보드   v0.2
├─ c-storybook/    ← 앱 C 지역 탐방 디지털 스토리북 v0.6
├─ d-multigrade/   ← 앱 D 복식학급 수업 도우미      v0.3
└─ e-together/     ← 앱 E 이웃 학교 함께하기        v0.1
```

- 실행: `index.html`을 브라우저로 엽니다. **설치·로그인·인터넷 모두 필요 없습니다.**

## 카탈로그가 지키는 것

카탈로그가 깨지는 방식은 정해져 있습니다. **링크가 죽거나, 앱은 올라갔는데 카탈로그에 적힌 판 번호가 옛것으로 남거나.** 둘 다 검사가 잡습니다.

| 검사 | 무엇을 막나 |
|---|---|
| 링크 10개가 가리키는 파일이 **실제로 있는지** | 앱 폴더 이름을 바꾸면 바로 걸립니다 |
| 적어 둔 판 번호가 **앱 화면과 같은지** | 앱만 올리고 카탈로그를 안 고치는 일 |
| 다섯 앱이 정말 **서버를 안 부르는지** | "어떤 자료도 외부로 전송하지 않습니다"가 거짓이 되는 일 |
| 다섯 앱이 정말 **파일 하나로 끝나는지** | "파일 하나만 보내도 됩니다"가 거짓이 되는 일 |
| 다섯 앱에 **인쇄 서식·저작권**이 있는지 | 카탈로그가 없는 기능을 광고하는 일 |

세 번째가 핵심입니다. 카탈로그에 "어떤 자료도 외부로 전송하지 않습니다"라고 적어 놓고 어느 앱에 `fetch`가 생기면 **카탈로그가 거짓말을 하게 됩니다.**

## 화면

| 자리 | 내용 |
|---|---|
| 표제 | 왜 이 앱들인가 — 학령인구 감소 → 소규모학교 증가 → 작은 학급·복식학급 |
| 앱 5종 | 한 줄 설명 · **이런 분께** · 특징 셋 · 화면 이름 · 열기/설명서 |
| 함께 지키는 것 | 설치 없음 / 이 기기 안에만 / 이름 안 받음 / 종이로 나옴 / 누구나 씀 / 검사가 지킴 |
| 나눠 주기 | 폴더째 복사, 앱 하나만 주기, 자료는 안 옮겨짐 |

앱을 늘어놓는 것만으로는 부족합니다. 교사가 **자기 것인지 3초 안에** 판단할 수 있어야 합니다. 그래서 카드마다 「이런 분께」를 넣었습니다 — *복식학급 담임. 지금도 종이에 손으로 짜고 계신 분*.

### 화면 전환을 앱과 함께 씁니다

다크 모드를 앱과 **같은 키(`leap-theme`)** 로 저장합니다. 카탈로그에서 바꾸면 앱에서도 유지됩니다. 제품군으로 보이려면 이런 데서 어긋나지 않아야 합니다.

## 종이 안내문

「안내문 인쇄」는 화면을 그대로 뽑지 않습니다. 카드가 잘리고, 무엇보다 **종이에서 링크는 쓸모가 없습니다.**

종이에는 「무엇을 하는 앱인지」와 「어떻게 여는지」만 넣었습니다. 검사가 이걸 고정합니다 — *"종이에는 링크를 넣지 않는다"*.

학교에 돌리거나 연수 자료로 붙일 때 쓰면 됩니다.

## 나눠 주는 법

1. `apps` 폴더를 **통째로** USB나 공유 폴더에 복사합니다.
2. 받은 분은 폴더 안 `index.html`을 브라우저로 엽니다.
3. 쓰고 싶은 앱의 「열기」를 누릅니다.

**앱 하나만** 주고 싶으면 그 앱 폴더의 `index.html` 파일 하나만 보내도 됩니다. 앱마다 필요한 것이 그 파일 안에 다 들어 있습니다.

자료는 **연 브라우저에만** 남습니다. 다른 컴퓨터로 옮기려면 앱 안의 「파일로 내보내기」로 저장한 뒤 저쪽에서 「파일에서 가져오기」 하세요.

## 공공데이터

앱 A · 앱 C · 앱 E 안에 **경상북도 학교 917곳**(초 474 · 중 260 · 고 183)이 **위도·경도까지** 들어 있습니다.
앱 A는 그 좌표로 **학교 사이 이동 시간**을 어림하고, 앱 C는 **우리 학교 자리**를 지도에 찍고,
앱 E는 그것으로 **어느 학교가 이웃인지**를 정합니다 — 시군 경계를 넘어서.

> 2026. 8. 3. 앱 E의 검사가 학교급별로 세면서, 문서 여섯 곳의 「초 473 · 고 184」가 실제 자료(**초 474 · 고 183**)와 어긋나 있는 것을 찾아 고쳤습니다. 합계 917이 맞아서 그때까지 아무도 몰랐습니다.

- 이름·주소: 교육부 「학교기본정보」 (교육정보 개방 포털 `open.neis.go.kr`)
- 위도·경도: 교육부 **학교알리미** (`schoolinfo.go.kr`) — 개방 포털에는 좌표가 없습니다
- 둘 다 **공공누리 제1유형(출처표시)** · 2026년 8월에 받았습니다
- **앱 파일 안에 담아 두었습니다.** 앱을 열 때 인터넷을 부르지 않습니다.
- 다시 받으려면 `open api/bake-coords.mjs` — 만드는 사람이 한 번 돌리는 것이고, 배포되는 앱에는 인증키가 들어가지 않습니다.

「어떤 자료도 외부로 전송하지 않습니다」는 그대로입니다. 공공데이터는 **가져다 구운 것**이지 불러오는 것이 아닙니다.
