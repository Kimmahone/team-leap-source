## 카탈로그가 지키는 것

카탈로그가 깨지는 방식은 정해져 있습니다. **링크가 죽거나, 카탈로그가 앱에 없는 것을 광고하거나.**
둘 다 검사가 잡습니다. 검사는 **말이 있는지가 아니라 그 말이 참인지**를 봅니다.

| 검사 | 무엇을 막나 |
|---|---|
| 링크가 앱마다 둘씩 가리키는 파일이 **실제로 있는지** | 앱 폴더 이름을 바꾸면 바로 걸립니다 |
| 열한 앱 화면에 **판 번호가 없는지** | 다 만든 도구가 스스로 시제품이라고 말하는 일 |
| 열한 앱이 정말 **서버를 안 부르는지** | "어떤 자료도 외부로 전송하지 않습니다"가 거짓이 되는 일 |
| 열한 앱이 정말 **파일 하나로 끝나는지** | "파일 하나만 보내도 됩니다"가 거짓이 되는 일 |
| 열한 앱에 **인쇄 서식·저작권**이 있는지 | 카탈로그가 없는 기능을 광고하는 일 |
| **이름을 받는 앱을 이름 대어 밝히는지** | 개인정보 안내가 거짓이 되는 일 〔2026. 8. 30. 추가〕 |
| 열한 앱의 **저장 창구가 같은지** | 한 앱만 저장 실패를 못 잡게 되는 일 〔2026. 8. 30. 추가〕 |
| 설명서에 적힌 **검사 개수가 실제와 같은지** | 문서가 조용히 낡는 일 〔2026. 8. 30. 추가〕 |
| 창을 열면 **초점이 그 안에 머무는지** | 「키보드만으로 조작됩니다」가 거짓이 되는 일 〔8. 30. 추가〕 |
| 뽑은 종이가 **저마다 다른 이름을 갖는지** | 내려받기 폴더에서 어느 것이 어느 것인지 모르게 되는 일 〔8. 30. 추가〕 |
| **적는 칸마다 이름이 붙어 있는지** | 읽어 주는 기계가 「편집란」이라고만 읽는 일 〔8. 30. 추가〕 |
| 내보낸 파일이 **어느 앱 것인지 말하는지** | 남의 앱 파일이 들어와 자료를 덮어쓰는 일 〔8. 30. 추가〕 |
| 앱 안에서 **설명서로 갈 수 있는지** | 「어떻게 쓰지」에 답할 길이 없어지는 일 〔8. 30. 추가〕 |
| **kit 의 토큰이 열한 앱과 같은지** | 원본이 낡아 베껴 간 화면이 깨지는 일 〔8. 30. 추가〕 |
| **본문 바로가기·44px 단추·인쇄 숨김**이 고른지 | 잔손질이 한 앱에만 들어가는 일 〔8. 30. 추가〕 |
| **탭이 주소에 남는지** | 새로고침이 첫 탭으로 되돌리고 뒤로 가기가 앱을 떠나는 일 〔8. 30. 추가〕 |

세 번째가 핵심입니다. 카탈로그에 "어떤 자료도 외부로 전송하지 않습니다"라고 적어 놓고 어느 앱에 `fetch`가 생기면 **카탈로그가 거짓말을 하게 됩니다.**

여섯 번째는 **실제로 그 일이 일어나서** 넣었습니다. 카탈로그가 「학생 이름을 받지 않습니다 — 이름 칸을
아예 만들지 않았습니다」라고 적는 동안 앱 G 가 상담을 위해 이름 칸을 넣었고, 검사는 **그 문장이 있는지만**
보고 있어 아무 말도 하지 않았습니다. 학교로 돌리는 종이 안내문에도 그대로 찍혔습니다.

## 화면

| 자리 | 내용 |
|---|---|
| 표제 | 왜 이 앱들인가 — 학령인구 감소 → 소규모학교 증가 → 작은 학급·복식학급 |
| 앱 11종 | 한 줄 설명 · **이런 분께** · 특징 셋 · 화면 이름 · 열기/설명서 |
| 함께 지키는 것 | 설치 없음 / 이 기기 안에만 / **열 앱은** 이름 안 받음 / 종이로 나옴 / 누구나 씀 / 검사가 지킴 |
| 나눠 주기 | 폴더째 복사, 앱 하나만 주기, 자료는 안 옮겨짐 |

앱을 늘어놓는 것만으로는 부족합니다. 교사가 **자기 것인지 3초 안에** 판단할 수 있어야 합니다. 그래서 카드마다 「이런 분께」를 넣었습니다 — *복식학급 담임. 지금도 종이에 손으로 짜고 계신 분*.

### 화면 전환을 앱과 함께 씁니다

다크 모드를 앱과 **같은 키(`leap-theme`)** 로 저장합니다. 카탈로그에서 바꾸면 앱에서도 유지됩니다. 제품군으로 보이려면 이런 데서 어긋나지 않아야 합니다.

## 종이 안내문

「안내문 인쇄」는 화면을 그대로 뽑지 않습니다. 카드가 잘리고, 무엇보다 **종이에서 링크는 쓸모가 없습니다.**

종이에는 「무엇을 하는 앱인지」와 「어떻게 여는지」만 넣었습니다. 검사가 이걸 고정합니다 — *"종이에는 링크를 넣지 않는다"*.

학교에 돌리거나 연수 자료로 붙일 때 쓰면 됩니다.

## 나눠 주는 법

1. `apps` 폴더를 **통째로** USB나 공유 폴더에 복사합니다.
2. 받은 분은 폴더 안 `index.html`을 브라우저로 엽니다.
3. 쓰고 싶은 앱의 「열기」를 누릅니다.

**앱 하나만** 주고 싶으면 그 앱 폴더의 `index.html` 파일 하나만 보내도 됩니다. 앱마다 필요한 것이 그 파일 안에 다 들어 있습니다.

자료는 **연 브라우저에만** 남습니다. 다른 컴퓨터로 옮기려면 앱 안의 「파일로 내보내기」로 저장한 뒤 저쪽에서 「파일에서 가져오기」 하세요.

「어떤 자료도 외부로 전송하지 않습니다」는 그대로입니다. 공공데이터는 **가져다 구운 것**이지 불러오는 것이 아닙니다.

## kit 은 원본입니다

`kit/leap.css` 와 `kit/leap.js` 가 원본이고, 각 앱의 `index.html` 안에 들어 있는 것은 **사본**입니다. 앱을 파일 하나로 유지하기 위해서입니다.

**원본을 고치면 앱 안의 블록도 함께 고쳐야 합니다.** 카탈로그도 마찬가지입니다.

> **2026. 8. 30. — 실제로는 반대로 흘렀습니다.** 열한 앱이 앞서 가고 kit 이 뒤에 남았습니다.
> `--leap-radius` 가 kit 은 10px 인데 열한 앱은 14px, 그림자도 다르고, 열한 앱이 쓰는
> `--grad-head`·`--solid-*`·`--tint-*` 가 kit 에 아예 없었습니다. `leap.js` 의 `update()` 도
> 옛 모양이었고 **그 옛 모양이 다섯 앱에 번져 있었습니다**(앱 H 의 되돌리기가 그래서 죽어
> 있었습니다). **JS·CSS 모두 열한 앱의 지금 모습으로 끌어올렸고, 검사가 어긋남을 잡습니다.**
> 앱만의 토큰(`--grad-win`·`--h0`·`--solid-blue`)은 kit 에 없어도 됩니다 —
> 막는 것은 **같은 이름이 서로 다른 값을 갖는 일**입니다.
