# 판 번호 이력 — v1 이전에 화면에 적혀 있던 것

〔2026. 8. 12.〕 **화면에서 판 번호를 전부 뗐습니다.** 이 문서가 그 기록입니다.

## 왜 뗐나

만드는 동안에는 판 번호가 쓸모가 있었습니다 — 「앱 D v0.5 에서 세 학년까지 됩니다」처럼
무엇이 언제 들어왔는지 가리킬 수 있었습니다.

그런데 **선생님에게는 뜻이 없습니다.** 도구를 고르러 온 사람에게 `v0.6` 은
「아직 덜 됐다」로 읽힙니다. 실제로는 아홉 앱 모두 교실에서 쓸 수 있는 상태이고,
자료도 전부 실적으로 채워졌습니다. **화면이 스스로를 시제품이라고 말할 까닭이 없습니다.**

「점검 264개 통과」를 메인에서 뺀 것과 같은 판단입니다(마스터 문서 참조) —
**만드는 사람에게만 뜻이 있는 숫자는 만드는 사람의 문서에 둡니다.**

## 남겨 둔 것 — 코드 주석의 이력

**코드 주석 안의 `〔v0.5〕` 표시는 그대로 둡니다.** 화면에 나오지 않고,
**왜 그렇게 만들었는지를 가리키는 유일한 실마리**이기 때문입니다. 이런 것들입니다 —

```js
/* 〔v0.5〕 미리보기가 **너무 좁았습니다.** 540px 칸에 A4(794px)를 0.57 배로 줄여 … */
// 시작 시각은 v0.4 에서 생겼다. 예전 차시에는 없으므로 빈 칸
i) save(function (x) { delete x.ai; });   // v0.2 의 API 키 설정 — 이제 쓰지 않는다
```

특히 **저장한 자료를 읽는 코드**에는 「이 칸은 v0.4 에서 생겼다」가 꼭 필요합니다.
그 표시를 지우면 왜 빈 칸을 견뎌야 하는지 알 수 없게 됩니다.
