## 왜 이 앱인가

앱 D(복식학급)는 「두 학년이 한 교실에 있을 때」의 도구입니다.
그런데 소규모학교 교사가 실제로 가장 많이 쓰는 시간은 **그냥 한 차시를 짜는 일**이고,
작은 학교일수록 그 일을 **혼자** 합니다. 나눠 맡을 동학년이 없습니다.
학년마다 교사 한 명이 전 교과를 짜는 학교에서, 지도안은 늘 밀립니다.

「인공지능 활용 선도교사」 연수의 **수업설계안 실습 앱**과 양식이 같지만,
그쪽은 실습용이고 이쪽은 **학교에 나가는 것**이라 지켜야 할 것이 다릅니다.

## v0.5 — 시간 띠, 이 앱의 얼굴 (2026. 8. 6.)

### 1. 시간 띠 ★

앱마다 **「그 앱이 무엇인지」를 한눈에 말하는 자리**가 하나씩 있습니다.
앱 A 는 주간 시간표, 앱 B 는 로고의 도약 궤적을 그대로 쓴 진행바,
앱 D 는 시간 배치표, 앱 G 는 히트맵.

**앱 F 에는 그것이 없었습니다.** 이 앱의 마크가
「한 장 안에 나뉜 도입·전개·정리, **막대 길이가 곧 시간**」인데,
정작 화면에는 숫자와 진행바 하나뿐이었습니다.
**마크가 말하는 것을 화면이 말하지 않고 있었습니다.**

```
┌──────┬───────────┬───────────────────────┬──────┐
│관심갖기│  계획하기   │       탐색하기          │정리하기│
│ 5분  │   10분     │        20분            │ 5분  │
└──────┴───────────┴───────────────────────┴──────┘
   전체     모둠            모둠·개별            전체
```

- **칸의 폭이 곧 그 단계의 시간**입니다. 40분이 눈앞에 통째로 놓입니다.
- **색은 학습 형태**입니다 — 종이에 찍히는 색과 **같은 값**입니다.
  화면에서 본 색을 종이에서 다시 만납니다.
- **남은 시간은 빗금**으로 남습니다. 아직 안 쓴 자리가 눈에 보입니다.
- **칸을 누르면 그 단계로 갑니다.**
- 무슨 색이 무엇인지 아래에 **글자로도** 적습니다(원칙 4).

### 2. 걸음 표시

세 걸음이 각각 **얼마나 채워졌는지** 위에 늘 보입니다.
채운 걸음은 번호가 체크로 바뀝니다 — 「어디까지 했더라」를 사람이 기억하지 않아도 됩니다.

```
✓ 개요            ✓ 흐름              3 평가·유의사항
  성취기준 1개       4단계 · 40/40분      평가요소를 적어 주세요
```

### 3. 종이 마무리 셋

| 무엇 | 어떻게 |
|---|---|
| **꼬리말** | 가운데 → **오른쪽**. 가운데에 두면 「본문의 일부」처럼 보입니다. 「학교 안에서 쓰는 자료입니다」는 뺐습니다 |
| **개요의 결이 달랐다** | 성취기준·도구·분석만 점을 찍고 주제·질문·의도는 맨 글자였습니다. **여섯 칸 모두** 점으로 |
| **도구·역할이 한 줄이었다** | 「도구 A · 역할 B」로 붙어 있어 어디까지가 도구인지 안 갈렸습니다. **줄을 나눴습니다** |

## v0.4 — 현장에서 인쇄해 보고 짚어 준 것들 (2026. 8. 6.)

가로·세로로 실제로 뽑아 보고 나온 것들입니다.

| 무엇이 문제였나 | 어떻게 고쳤나 |
|---|---|
| **설계 탭이 너무 길었다** — 여덟 마디를 한 화면에 넣어 평가까지 한참 굴려야 했음 | 걸음을 셋으로 — **① 개요 ② 흐름 ③ 평가·유의사항**. 오른쪽 종이는 **세 걸음에 모두** 붙어 있고, 걸음마다 「다음 →」 단추가 있습니다 |
| **글자가 잘렸다** — 가로판의 도구·역할 줄이 칸 안에서 끊김 | 흐름 칸을 **늘되 줄지 않게**(`flex:1 0 auto`). v0.3 은 줄어들 수 있게 두었고, **늘어나는 것과 잘리는 것은 한 몸**이었습니다 |
| **얼룩덜룩했다** | 회색이 세 가지(`#EDF1F6`·`#F5F7FA`·`#F7F9FC`)였습니다. **하나**로 줄이고 선도 한 굵기·한 색으로 |
| **소제목이 넓고 헐거웠다** | 색 점과 넓은 여백을 걷어내고 **밑줄 한 줄**로. 글자·줄 간격·표 안쪽을 함께 조여 같은 내용이 더 작은 자리에 |
| **표가 깨졌다** — 「초등학교 5학 / 년」 | 머리 표의 **칸 폭을 못박음**. `table-layout:fixed` 라 그냥 두면 열두 칸이 똑같이 나뉩니다 |
| **학습 형태가 안 갈렸다** | 전체·모둠·짝·개별에 **각각 다른 색**. 색만으로 말하지 않도록 **글자를 함께** 답니다(원칙 4) |
| **평가가 심화부터였다** | **기초 → 기본 → 심화**로. 왼쪽에서 오른쪽으로 **올라가는** 순서라야 「이 아이를 어디까지 데려갈 것인가」로 읽힙니다. 종이와 입력 화면이 같은 순서입니다 |
| **활동이 서술문이었다** | 「~합니다」 → **「~하기」**. 예시안 19군데를 고치고, AI 프롬프트에도 못박았습니다 — *지도안은 읽는 글이 아니라 **보는 표**입니다* |

### 인쇄해 보고 또 나온 것 넷

화면에서는 멀쩡한데 **종이에서만 보이는** 자리들이었습니다.

| 무엇 | 왜 그랬나 |
|---|---|
| **소제목이 커다란 흰 상자였다** | 종이의 소제목이 `h2.sec` 였는데, 입력 화면의 카드 규칙 `.sec{background·border·border-radius·padding:18px 20px·box-shadow}` 을 **그대로 뒤집어썼습니다.** `.page h2.sec` 가 더 구체적인데도 소용없었습니다 — **선언하지 않은 성질은 낮은 규칙이 이깁니다.** 이름을 `psec` 로 가르고, 그 안에서 배경·테두리·그림자를 **스스로 끄게** 못박았습니다 |
| **과정중심평가와 유의사항 사이의 네모** | 위와 같은 원인입니다. 두 소제목이 각각 흰 카드가 되어 그 사이에 상자 모서리와 그림자가 남았습니다 |
| **머리 표가 아래로 처져 보였다** | 이름표(8.6px)와 값(9px)의 크기가 다른데 둘 다 위로 붙여 두어 밑선이 어긋났습니다. 머리 표는 한 줄짜리라 **가운데**가 맞습니다. 개요 표는 값이 여러 줄이므로 이름표를 **위**에 둡니다 |
| **오른쪽 테두리가 잘렸다** | 인쇄에서 안쪽 여백을 0으로 두어 표의 오른쪽 선이 인쇄 경계에 딱 붙었습니다. **0.6mm** 만 남기니 선이 온전히 찍힙니다 |

### PDF 파일 이름 ★

브라우저는 **문서 제목(`document.title`)** 을 파일 이름으로 씁니다. 그대로 두면
열 장을 뽑아도 열 장이 모두 「수업 설계안 만들기 — TEAM LEAP.pdf」였습니다.

```
차시안_사회_2. 우리 지역의 국가유산_2026-08-06.pdf
차시안2_과학_3. 식물의 구조와 기능_2026-08-06.pdf
단원안_국어_4. 주장과 근거를 판단해요_2026-08-06.pdf
```

인쇄하는 **동안만** 제목을 바꾸고 `afterprint` 로 되돌립니다 — 안 되돌리면
브라우저 탭 이름이 파일 이름인 채로 남습니다. 파일 이름에 못 쓰는 글자(`/ : * ? " < > |` 등)는
걷어내고, 단원도 주제도 비어 있으면 「설계안」으로 둡니다.

### 곁들여 — 일곱 앱의 머리를 하나로

**처음으로 · AI 초안 · 밝게/어둡게** 순서로 맞췄습니다. 앱 F 의 AI 초안은
탭에서 머리 단추로 옮겼습니다 — AI 초안은 설계의 한 걸음이 아니라
**언제든 부르는 도우미**이기 때문입니다.

그리고 **「화면 전환」을 걷어냈습니다.** 무엇이 바뀌는지 말해 주지 않는 말이었습니다.
이제 단추가 **지금 누르면 어떻게 되는지**를 스스로 말합니다 —
「어둡게 보기」를 누르면 어두워지고, 단추는 「밝게 보기」로 바뀝니다.
일곱 앱 · 카탈로그 · 활용 가이드 · 메인 페이지가 **모두 같은 말**을 씁니다.

## v0.3 — 다 적고 나서야 무엇이 나오는지 알던 것을 고쳤습니다

현장에서 온 것들을 반영했습니다. 하나씩 적어 둡니다.

### 1. 왼쪽은 쓰는 곳, 오른쪽은 나올 종이 ★

v0.2 는 「종이로 내기」가 **따로 있는 탭**이었습니다. 그래서 한 쪽에 안 들어간다는
것을 다 적은 뒤에 알았고, 그때는 이미 **지울 것을 고르는 일**이 되어 있었습니다.

이제 한 글자 적을 때마다 오른쪽 종이가 함께 바뀝니다. 위에는 늘
「**A4 가로 1쪽**」처럼 몇 쪽짜리인지 적혀 있고, 줄여서 맞췄으면
「글자 92%로 맞춤」이라고 밝힙니다.

> 글자를 칠 때 화면을 통째로 다시 그리면 **커서가 튑니다**(마스터 7장 함정 7번).
> 그래서 값이 바뀔 때는 **오른쪽 종이만** 갈아 끼웁니다.

### 2. 가로와 세로, 두 양식 ★

연수 제출 양식은 **A4 가로 한 쪽**이지만, 학교 결재는 **세로**로 도는 일이 많습니다.
같은 자료 하나에 두 양식을 입힙니다. 양식이 늘어도 만드는 쪽은 그대로입니다.

| | 가로 | 세로 |
|---|---|---|
| 흐름 | 단계 카드가 **옆으로** (연수 양식의 배치) | 표가 **아래로** (표가 스스로 쪽을 넘김) |
| 평가·유의사항 | 아래 두 칸에 나란히 | 차례로 |
| 쪽수 | **1쪽** | 차시안 1쪽 · 2차시·단원안 **2쪽까지** |

**약속: 개요 · 수업 · 평가가 모두 그 안에 들어갑니다.** 넘치면 글자를
한 단계씩 줄여서라도 넣습니다. 어림하지 않고 **실제로 그려 놓고 높이를 잽니다** —
글자 수로 어림하면 표가 몇 줄로 접히는지를 알 수 없어 늘 틀립니다.

### 3. AI 초안 — 프롬프트 생성기입니다 ★

API 키를 쓰지 않습니다. 학교에서 키 발급이 막히는 일이 잦고, 공용 컴퓨터에
키를 남기는 것도 께름칙합니다.

```
① 개요를 적는다            (교과·학년·성취기준만 있어도 됩니다)
② 프롬프트를 복사한다       → 쓰던 챗봇에 붙여 넣기 (ChatGPT · Gemini · 클로드 …)
③ 돌아온 JSON 을 붙여 넣는다
④ 「무엇이 들어올지 보기」   → 확인하고 「이대로 받기」를 눌러야 들어갑니다
```

**받아들이기 전에 반드시 거릅니다.**

| AI 가 이렇게 주면 | 이렇게 합니다 |
|---|---|
| 시간 합이 200분 | 비율을 지켜 **40분에 맞춰 넣고**, 무엇을 고쳤는지 화면에 적습니다 |
| 없는 학습 형태(`텔레파시`) | 「전체」로 되돌리고 그 사실을 적습니다 |
| 없는 탐구 유형 | 「구조화된 탐구」로 되돌립니다 |
| 흐름이 하나도 없음 | **받지 않습니다** — 종이의 가운데가 통째로 빕니다 |
| 앞뒤에 설명이 섞임 | `{ }` 부분만 찾아 읽습니다 |

프롬프트에 **「학생 이름을 쓰지 마세요」**를 못박아 두었습니다.
앱 밖으로 나가는 유일한 길목이기 때문입니다.

사람이 못 만드는 상태를 AI 라고 만들 수 있으면, 「시간이 넘치는 수업안은
만들 수 없다」가 무너집니다.

### 4. 차시안(1·2차시)과 단원안 ★

블록 수업이 흔해졌는데 v0.2 는 **한 차시 길이만** 알고 있었습니다.

- **차시안 1차시** — 초 40 · 중 45 · 고 50분
- **차시안 2차시(블록)** — 그 두 배
- **단원안** — 차시 묶음마다 **탐구 유형**(구조화된 → 안내된 → 개방형).
  뒤로 갈수록 학생 주도성이 커지게 두는 것이 연수 예시안의 얼개입니다.

### 5. 과목·학년·성취기준을 토글로 ★

학교급 · 학년 · 학기 · 교과를 눌러서 고릅니다. **목록에 없으면 직접 적습니다**
(중·고등학교 교과, 창의적 체험활동, 통합교과 등).

### 6. 성취기준 611건을 앱 안에 담았습니다 ★

**v0.2 의 「굽지 않는다」를 뒤집었습니다.** 그때 이유는 「수천 줄이고 개정 때마다
낡는다」였는데, 실제로 세어 보니 **초등 611건**이고 성취수준 A·B·C 까지 139K 입니다.

그리고 굽지 않아 **잃고 있던 것**이 컸습니다. 붙여 넣게 하면 코드와 문장만 들어오고,
**성취수준 A·B·C 는 어디에서도 오지 않습니다.** 그 셋이 그대로 기초·기본·심화
피드백이 되는데, **교사가 가장 오래 붙들고 있는 칸이 그것**입니다.

```
[4사06-01] 을 고른다
   → 성취수준 C → 기초 피드백
   → 성취수준 B → 기본 피드백      「피드백 채우기」 한 번
   → 성취수준 A → 심화 피드백
```

**이미 적은 줄은 덮지 않습니다.** 공들여 적은 것을 단추 하나로 날리면
다시는 그 단추를 안 누릅니다.

> 낡는 문제는 굽는 스크립트로 답합니다 — `node bake-standards.mjs`.
> 개정되면 원본을 바꿔 한 번 돌리면 됩니다. 앱 A·C·E 의 학교 좌표와 같은 방식입니다.

### 7. AI·디지털이 양식의 축입니다 ★

연수 양식(KERIS)의 네 블록을 그대로 따랐습니다.

| 블록 | 무엇 |
|---|---|

### 8. 예시안 셋 ★

채워진 것을 한 벌 열어 **내 수업으로 고쳐 쓰는** 것이 가장 빠릅니다.

| 예시안 | 무엇 |
|---|---|
| 초등 사회 4학년 | 우리 지역의 역사 조사하기 · 1차시(40분) · A4 가로 |
| 초등 과학 5학년 | 잎이 하는 일 · **2차시 블록(80분)** · A4 세로 |

여는 순간 **지금 것을 보관함에 자동으로 넣습니다** — 잃지 않습니다.

### 9. 만들며 고친 것 셋

| 무엇 | 왜 그랬나 |
|---|---|
| **꼬리말이 평가표 글자 위에 겹쳤다** | `position:absolute` 로 띄웠기 때문입니다. 자리를 차지하는 요소로 두고 `margin-top:auto` 로 바닥에 붙였습니다 — **겹칠 수 없는 구조**가 되었습니다 |
| **짧은 설계안이 종이 위쪽에만 붙어 나왔다** | 인쇄에서 종이의 높이를 0으로 풀어 버려 흐름 칸이 늘어나지 않았습니다. `mm` 로 제 높이를 돌려주었습니다 |
| **백지가 한 장 더 나왔다** | 인쇄 높이를 **딱** 맞췄더니 반올림 1px 때문에 넘쳤습니다. 3mm 적게 잡습니다 — 제출물에 백지가 끼는 것이 가장 나쁩니다 |

## 그대로 둔 것 — 이 앱의 심장

### 시간이 넘치는 수업안을 **만들 수 없습니다** (마스터 원칙 8번)

> 40분짜리 종이에 47분이 적히는 일 — 지도안이 현장에서 안 지켜지는 첫 번째 이유입니다.

경고로 잡지 않습니다. **구조로 막습니다.**

- 남은 시간이 0이면 **「+ 단계」 단추가 잠깁니다.**
- 시간 칸은 `max = 지금 값 + 남은 시간` 입니다. 넘겨 적으면 **값 자체가 되돌아갑니다.**
- 남은 시간은 화면 위에 **붙어서 따라다닙니다.** 「저장할 때」 알면 늦습니다.
- 학교급이나 차시 수를 바꾸면 **비율을 지켜 그 자리에서 다시 나눕니다.**
  나머지는 마지막 칸이 받습니다 — 반올림을 나눠 담으면 합이 1~2분씩 어긋납니다.

**모자란 것은 막지 않습니다.** 일부러 여백을 두는 수업도 있습니다.

### 학생 이름 칸이 없습니다 (원칙 3번)

평가에도 「누구를」이 아니라 **「무엇을 어떻게」**만 적습니다.
가장 확실한 증거는 저장 구조입니다 — **학생 하나하나를 담을 자리가 아예 없습니다.**
검사가 이걸 고정합니다(`[9]`). 그래서 개인정보 영향평가 없이 학교에 나갈 수 있습니다.

### 보관함 — 파일 한 번 열었다고 쌓아 둔 것이 사라지지 않습니다

예시안을 열 때도, 보관함에서 열 때도, 파일을 불러올 때도
**먼저 지금 것을 보관함에 넣습니다.** 보관함은 보관함을 품지 않습니다 —
품으면 한 번 저장할 때마다 자료가 두 배로 불어납니다.
