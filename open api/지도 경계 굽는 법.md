## 1. 왜 지도 API 가 아닌가

처음 이유는 「인터넷을 안 쓴다」였습니다. 알아보다가 **더 결정적인 것**을 찾았습니다.

> **카카오맵·네이버지도 API 는 행정구역 경계 폴리곤을 주지 않습니다.**
> 지도 API 가 주는 것은 배경 타일과 마커·검색·경로입니다.
> 시군을 색칠하거나 경계를 그리려면 **API 를 쓰든 안 쓰든 경계 파일을 따로 구해야 합니다.**

그러면 남는 물음은 「배경 타일이 필요한가」 하나뿐인데, 우리 지도에는 도로도 건물도 항공사진도
필요 없습니다. API 를 붙이면 아래를 떠안고 얻는 것이 **쓰지도 않을 배경 그림**입니다.

| | 지도 API | 경계 파일을 굽기 |
|---|---|---|
| 경계 폴리곤 | **안 줌** (따로 구해야 함) | 이게 그 파일입니다 |
| 인터넷 | 볼 때마다 필요 | 만들 때 한 번 |
| 원칙 1번 (외부 CDN 0) | **위반** | 지킴 |
| 인증키 | HTML 안에 노출됨 | 없음 |
| `file://` 로 열기 | **안 됨** — 키에 도메인을 걸어야 하는데 도메인이 없음 | 됨 |
| 학교 망에서 외부 도메인 차단 | 빈 화면 | 무관 |
| 보안성 검토 | 외부 호출 항목에 걸림 | 걸릴 것 없음 |
| 비용 | 무료 한도 있음, 넘으면 과금 | 없음 |

> 웹에 올려 도메인이 생기면 API 를 **쓸 수는 있습니다.** 다만 위 표에서 뒤집히는 칸은
> 「`file://`」 한 줄뿐이고, **경계 폴리곤을 따로 받아야 한다는 것은 그대로**입니다.
> 그리고 학교에 나가는 것은 여전히 zip 파일입니다.
>
> 참고 — 대시보드 사이드바의 **학구도안내서비스**는 이미 바깥 링크입니다.
> 진짜 지도가 필요한 사람은 그쪽으로 보내면 됩니다.

## 2. 어디서 받나 — 쉬운 순서

`business.juso.go.kr`(행안부)은 신청 후 **처리를 기다려야** 하고 인증 절차가 많습니다.
급하면 아래 순서로 가세요.

### ① GitHub `southkorea/southkorea-maps` — 로그인 없이 즉시 (지금 쓰는 것)

```
https://github.com/southkorea/southkorea-maps
  └ kostat/2018/json/skorea-municipalities-2018-geo.json     (17MB, WGS84)
```

곧바로 받으려면:

```bash
curl -L -o kr-muni.json \
  https://raw.githubusercontent.com/southkorea/southkorea-maps/master/kostat/2018/json/skorea-municipalities-2018-geo.json
```

- **원자료는 통계청 SGIS, 공공누리 제1유형**입니다 (같은 폴더의 `LICENSE.md` 에 적혀 있습니다).
  누가 올린 것이 아니라 **공공 자료를 옮겨 둔 것**이라 출처표시로 쓸 수 있습니다.
- **이미 WGS84(위경도)** 입니다 — 좌표계 변환이 필요 없습니다.
- 기준연도가 **2018** 입니다. 시군 경계 자체는 그 뒤로 바뀐 것이 없습니다
  (군위는 경계가 아니라 **소속**만 바뀌었고, 굽는 스크립트가 빼 줍니다).

### ② VWorld · 국가공간정보포털 `nsdi.go.kr` — 가입은 필요하지만 승인 대기는 없음

「행정구역시군구_경계」로 찾으면 SHP 이 나옵니다. 즉시 다운로드됩니다.

### ③ 공공데이터포털 `data.go.kr` — 파일데이터라 신청 승인이 필요 없음

「국토교통부_행정구역시군구_경계」 로 검색. **오픈API 가 아니라 「파일데이터」** 를 고르세요.
오픈API 는 활용신청 승인을 기다려야 하지만, 파일데이터는 로그인만 하면 바로 받습니다.

### ④ 통계청 SGIS `sgis.kostat.go.kr` — 원본. 최신 연도가 있음

자료제공 → 통계지리정보 → 경계 파일.

### ⑤ 행안부 도로명주소 `business.juso.go.kr` — 가장 최신이지만 가장 느림

「구역의 도형 / 시군구」. 매월 갱신되어 통폐합 반영이 가장 빠릅니다.
**신청이 처리되면 이걸로 다시 구우면 됩니다** — 스크립트가 그대로 받습니다(아래 4장).

## 3. SHP 을 받았다면 — GeoJSON 으로

①은 이미 GeoJSON 이라 건너뛰어도 됩니다. ②~⑤는 대개 SHP 입니다.

```bash
# 먼저 어떤 속성 칸이 있는지 봅니다 (칸 이름이 출처마다 다릅니다)
npx mapshaper 시군구.shp -info

# 위경도로 바꾸고 GeoJSON 으로
npx mapshaper 시군구.shp -proj wgs84 -o format=geojson gyeongbuk.json
```

**좌표계를 꼭 확인하세요.** 국내 SHP 은 대개 **EPSG:5179(UTM-K)** 입니다.
숫자가 `128.7` 이 아니라 `1094372` 같으면 아직 안 바뀐 것입니다.

경북만 걸러 내거나 점을 줄이는 일은 **하지 않아도 됩니다** —
`bake-boundary.mjs` 가 알아서 합니다.

## 4. 굽는 스크립트가 알아서 하는 것

`open api/bake-boundary.mjs`. **mapshaper 도 turf 도 안 씁니다** — 노드 기본만으로 합니다.

| 하는 일 | 내용 |
|---|---|
| 시도 고르기 | 코드가 **37**(통계청 계열) 또는 **47**(행안부·국토부 계열)로 시작하는 것. 둘 다 받습니다 |
| 속성 칸 찾기 | `name` · `SIG_KOR_NM` · `sigungu_nm` … 있는 것 중에 씁니다 |
| **군위 빼기** | 2023. 7. 1. 대구광역시 편입. 두면 지도에만 있는 시군이 하나 생깁니다 |
| **포항 합치기** | 자료에는 남구·북구로 쪼개져 있습니다. 학교 목록은 「포항」 하나 |
| 이름 다듬기 | 「안동시」 → 「안동」 |
| 점 줄이기 | Douglas-Peucker, 허용오차 0.0016도 (경북 폭의 약 1/900) |
| 잡티 버리기 | 가장 큰 섬의 1/400 보다 작은 조각. 화면에서 한 점도 안 됩니다 |
| 접기 | 첫 점만 절대값, 그다음은 차이값. 64KB → **29KB** |
| 심기 | 네 파일의 표시 사이를 통째로 갈아 끼움 |

**화면 좌표로 미리 옮기지 않습니다.** 네 곳의 지도가 크기도 범위도 다르기 때문입니다 —
대시보드는 620×470 전도, 앱 E 는 우리 학교를 가운데 둔 반경 지도, 시군 상세는 한 시군만 확대.
미리 옮기면 그중 하나에만 맞습니다. 위경도로 담고, 각 앱이 제 투영으로 폅니다.

### 다시 구운 뒤 반드시

```bash
node test.js        # 루트에서. 네 파일의 경계가 글자 하나까지 같은지 봅니다
```

「네 곳의 경계가 글자 하나까지 같다」·「군위군이 들어 있지 않다」·「시군 22곳이 다 있다」가
여기서 걸립니다. **한 곳만 다시 구우면 나머지가 조용히 낡습니다**(마스터 함정 13번).

## 5. 굽고 나서도 지켜야 할 것

- **색만으로 말하지 않기** (원칙 4번) — 면에 색을 칠하더라도 시군 이름은 글자로 남깁니다.
- **인쇄** (원칙 5번) — 브라우저가 배경색을 빼고 찍습니다. 면 색이 사라져도 읽히도록
  경계선을 `stroke` 로도 긋습니다.
- **울릉** — 경도 130.9도라 같이 그리면 육지가 납작해집니다. 별도 상자를 유지하세요.
- **시군 면에 값을 칠하지 마세요(코로플레스 금지).** 시군 넓이는 학교 수와 아무 상관이 없습니다.
  넓은 봉화가 진해 보이면 없는 뜻이 생깁니다. 값은 원 넓이가 나릅니다.

## 6. 안 하는 편이 나은 것

- **지도 이미지 한 장을 base64 로 넣기** — 용량은 더 크고, 확대하면 깨지고, 시군을 누를 수 없습니다.
- **읍·면·동 경계까지 받기** — 단순화해도 수백 KB 입니다. 학교 917곳을 이미 점으로 찍고 있어서
  시군 단위면 충분합니다.
