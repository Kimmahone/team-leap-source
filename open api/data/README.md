# `open api/data/` — 받아 온 원자료를 두는 곳

**여기 있는 것은 재료입니다. 앱에 들어가는 것이 아닙니다.**
앱 안에 들어가는 것은 굽는 스크립트가 만든 결과뿐이고, 이 폴더는 **배포 대상이 아닙니다**
(`배포 묶기.command` 는 `index.html` · 대시보드 · `apps/` · `brand/` 만 담습니다).

---

## 행정경계 파일은 여기에 넣으세요

```
open api/data/시군구경계.geojson      ← 이름은 아무거나 괜찮습니다
open api/data/시군구경계.zip          ← SHP 묶음이면 풀지 않고 그냥 두어도 됩니다
```

그리고 굽습니다.

```bash
cd "학령인구감소"
node "open api/bake-boundary.mjs" "open api/data/시군구경계.geojson"
node test.js        # 네 곳이 같은 자료를 쓰는지 확인합니다
```

**SHP 으로 받았다면** GeoJSON 으로 한 번 바꿔야 합니다. 방법은 `../지도 경계 굽는 법.md` 3장.

```bash
npx mapshaper "open api/data/시군구경계.shp" -proj wgs84 \
  -o format=geojson "open api/data/시군구경계.geojson"
```

경북만 걸러 내거나 점을 줄이는 일은 **하지 않아도 됩니다** — 굽는 스크립트가 알아서 합니다.
시도 코드는 **37**(통계청 계열)과 **47**(행안부·국토부 계열)을 둘 다 받습니다.
