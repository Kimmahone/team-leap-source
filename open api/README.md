## 두 곳을 씁니다. 헷갈리기 쉽습니다

| | 교육정보 개방 포털 | 학교알리미 |
|---|---|---|
| 주소 | `open.neis.go.kr` | `www.schoolinfo.go.kr` |
| 인증키 | 32자리 16진수 | 32자리 16진수 (**모양이 같습니다**) |
| 학교 이름·주소 | ○ | ○ |
| **위도·경도** | ✗ 없음 | **○ `LTTUD` · `LGTUD`** |
| 지금 쓴 것 | **이름·학교급·주소** | **위도·경도** |

두 키는 **생김새가 똑같아 서로 바꿔 쓰기 쉽습니다.** 확인하는 법:

```bash
# 학교알리미 — 성공하면 resultCode:success
curl "https://www.schoolinfo.go.kr/openApi.do?apiKey=<키>&apiType=0&sidoCode=47&sggCode=47170&schulKndCode=02"

# 교육정보 개방 포털 — 성공하면 INFO-000
curl "https://open.neis.go.kr/hub/schoolInfo?KEY=<키>&Type=json&pIndex=1&pSize=1&ATPT_OFCDC_SC_CODE=R10"
```

## 다시 굽기

학교는 통폐합·개교가 잦습니다. 학년도가 바뀌면 다시 받는 편이 좋습니다.

```bash
node "open api/bake-coords.mjs" <학교알리미 인증키>
node "open api/bake-coords.mjs" <학교알리미 인증키> --curl   # 사내망 인증서 문제가 있을 때
```

인증키 받는 곳: `schoolinfo.go.kr` → OPENAPI → 로그인(소셜) → 마이페이지

66~69번 물어 1~2분 걸립니다. 한 번 실패한 요청은 세 번까지 다시 물어봅니다.
그래도 못 받으면 **이미 앱에 있던 좌표를 그대로 둡니다** — 한 번 실패했다고
그 시군 학교들의 좌표를 통째로 버리면 안 됩니다.

`bake-coords.mjs` 는 **세 앱을 모두 고칩니다.** 한 곳만 고치면 나머지가 조용히 낡습니다.

돌린 뒤 점검:

```bash
cd "08. 실행계획(3)/apps"
for d in a-circuit c-storybook e-together; do (cd $d && node test.js | tail -1); done
```

검사가 좌표를 봅니다 — 경북 밖으로 튄 것이 없는지, 울릉이 동해 먼바다에 있는지,
학교를 고르면 시군 한가운데를 쓸 때와 거리가 달라지는지.
앱 E 의 검사는 **학교급별로 세어** 초·중·고 수가 맞는지까지 봅니다.

## 중요 — 인증키는 앱에 들어가지 않습니다

굽는 일은 **만드는 사람이 한 번** 하는 것입니다. 학교에 나가는 `index.html` 에는
인증키도, 서버를 부르는 코드도 없습니다. 앱은 여전히 파일 하나로 끝나고
인터넷을 쓰지 않습니다. 검사(`apps/test.js`)가 이것을 고정합니다.

애초에 브라우저에서 부를 수도 없습니다. 학교알리미는 CORS 머리를 주지 않아
`file://` 로 연 페이지에서는 요청이 막힙니다.
